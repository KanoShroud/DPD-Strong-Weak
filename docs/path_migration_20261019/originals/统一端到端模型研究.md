## 1. 当前研究定位与进展

### 1.1 要解决的实际问题

当前先研究四个同步单天线站、已知两个未知波形源的强弱重叠定位：在有限观测与计算预算下，提高弱源及双源恢复可靠性，或减少同等可靠性所需耗时。未知源数、频谱—位置对应及原端到端系统属于后续扩展，不是当前方法必须保留的前提。

G8将研究重点从站间主导源交换转向强弱重叠源定位。输入带限和方法适配后，G10-R2中的AP、NOMP与SBL能可靠处理所测场景。R3在新布局复现了联合AP的效率收益，也发现单候选流程的可靠性短板；下一步需要在保留低成本的同时减少错误候选。既有网络和物理模块按需复用，不要求新方法沿用端到端结构。

研究顺序是：明确场景困难，建立合理的常规参照，再验证针对性改动。已有联合优化、逐源处理和学习辅助物理定位均可借鉴；方法贡献需要说明场景机制、算法差异及实际收益。保证基线正常工作的迁移与数值修正归入适配，针对剩余困难的算法改动单列比较。文献依据见[综述方案的研究定位与方法章节](端到端多源定位_文献综述与方案建议.md)。

### 1.2 现在走到了哪里

- 已打通多条神经网络与物理定位接口，完成数值、梯度和恢复流程检查；性能由对应实验单独评价。
- G2—G5在各自结构与解码条件下获得过定位反馈收益；这些结果保留，不推广为任意统一结构都应受益。
- G5联合选峰缓解重复定位，后续身份评分修补未形成稳定净收益；频谱—位置对应仍需系统处理。
- G6支持用相干物理信息补充源身份，并将完整频带报告与定位用途分开；精修和反馈仍有取舍。
- G7在干净初始化的小区域体系中支持逐源条件输入，但额外反馈未形成稳定收益，局部精化未超过共同候选；硬级联仍有空间定位和成本优势。
- G8首轮及R1—R6完成：统一逐源投影改善两种重叠情形，新投影评分仍有搜索漏峰；旧DPD/HR谱的搜索结论不能直接外推。见[G8详细方案](#e2e-g8)。独立全K测试仍未执行。
- G9至R3保留充分常规搜索的恢复证据，停止无实际剪枝收益的区域上界规则；当时的成本判断保留为历史条件结论。见[G9](#e2e-g9)。
- G10-R1完成常规方法适配与正式比较：AP早期输出已满足当前典型场景的可靠性要求，SBL聚合未产生主任务净收益。后续不再预设常规方法需要长时间才能定位，见[最新结论](#g10-r1)。
- G10-R2带限全批已回读：轻量单候选AP、原NOMP和SBL均可靠定位本批双源，SBL的求解成本更高；旧全频开发中的多候选可靠性收益未复现，见[带限比较](#g10-r2-band)。
- G10-R3已完成共同停止及正式独立比较。联合AP保留效率收益，但两AP在同一新布局出现弱源错误候选；原NOMP的可靠性更好，见[当前结论](#g10-r3)。

## 2. 任务定义与数据接口

### 2.1 观测与当前工程基准

| 项目 | 当前G10配置 |
|---|---|
| 观测 | 四个同步单天线站，未知波形混合IQ；50 MHz采样、8192点，记录时长163.84 μs |
| 信号与传播 | 独立BPSK/RRC，零中心、同12.5 MHz带宽；自由空间相对幅度与基带时延模型 |
| 公共处理 | 保留±7 MHz频点，沿用原FFT尺度；不降采样、不逐站混合功率归一化 |
| 接收质量 | 弱源四站平均带内SNR为6 dB；固定弱源和噪声，强弱功率差为0、3、6、9、12、15 dB |
| 输出范围 | 已知K=2，估计两个二维位置；孤立源对照使用K=1 |
| 搜索区域与网格 | ±1000 m，最大站间基线1000 m；统一20 m初始网格，各方法保留登记的连续精修 |
| 数值与数据角色 | 物理求解使用FP64/complex128；开发数据用于核验和校准，新布局与随机实现用于冻结后的独立比较 |

G7网络体系作为历史基础保留：既有记录4096点，输出K=0/1/2/3及逐源频谱—位置；粗DPD为19×41×41、50 m间距，细DPD为201×201、10 m间距，候选采用每槽Top5及局部窗口，网络使用FP32。原大区域、warm-start先导和干净初始化体系分别追溯，不与当前G10配置混用。当前配置及修订见第8章。

### 2.2 输入身份与表示

样本以底层IQ场景ID为主键。粗图、细图、标签、候选和缓存都应回指同一场景；同一场景的不同表示或扰动变体不得跨训练与验证集合。

需要区分全频细DPD、预测频带生成的DPD和真值频带辅助DPD。真值频带可用于登记的监督训练或单列诊断，不能混入可部署推理。空间坐标使用米，图像索引与坐标映射必须随网格一起登记。

原项目outputs仅作冻结参考；本工作树新产物写入outputs_e2e。读取、快照、校验和运行预检按[AGENTS.md](AGENTS.md)与[运行基础说明](运行基础说明.md)执行，不在每个新方案重复整套工程规则。

### 2.3 对外结果与内部表示

当前已知双源任务输出两个无序位置。源数估计和频谱—位置绑定属于后续扩展；历史联合模型仍按原任务同时报告源数、逐源频谱和位置。扩展到空场时输出空集合，同频同属性源按无序集合评价。

Heatmap、offset、source query、定位权重和物理位置谱是不同实现中的内部表示。已完成Gate按其原接口保留，新方案是否采用这些模块由方案明确，不把某一内部结构永久写成任务目标。

频谱报告描述完整占用，定位权重描述观测的使用方式；若采用权重，不把它当作另一份频谱报告计算F1。联合输出也不自动等于端到端训练：应具体说明哪些参数被定位损失更新、哪些候选和解码步骤不求导。

### 3.2 按错误发生的位置确定下一步

1. **计数或前端漏源**：有没有为弱源留下有效表示？少报一个源时，末端评分本身无法补回完整输出。
2. **候选遗漏**：在一对一条件下，候选能否同时覆盖所有真实源？不能把几个源共用同一个候选算成全部覆盖。
3. **候选选择和关联错误**：已有合适位置，却选了错误峰或绑定了错误频带，应先检查匹配与几何一致性。
4. **精修破坏正确解**：原候选已较准，后续窗口评分或位置更新反而造成跳峰，应保留原解作为可选输出。
5. **观测利用不足**：若主要限制来自强源主导、带外噪声或局部污染，再研究频率/站点权重及更合适的物理后端。
6. **成本过高**：比较完整输入处理、候选、求解与解码成本，不只看网络前向或缓存后的训练速度。

这份错误分类用于选择诊断重点。G7暴露了局部重定位损失，G8—G10进一步转向混合观测的物理求解。当前已知K=2，重点是候选搜索、连续精修和完整成本；完全重叠源的区分依赖跨站空间信息及多源模型。

### 3.3 尚未闭合的论文证据

强弱重叠场景已完成多轮方法比较。R3独立复核支持联合AP相对交替AP提效，但未建立相对原NOMP的整体优势。当前缺口是如何减少单候选的错误区域选择，同时保留低成本；下一轮应先用小范围机制对照确定改动，再开展新的独立确认。

当前候选主张是降低计算成本，而非已证实的可靠性提升。论文需把未知波形消元、交替与联合更新的差别、实际调用量和完整耗时联系起来，并用独立结果及消融支撑。未知源数、频谱绑定和深度学习不必同时纳入；仿真记录长度与质量条件应明确列为研究假设。

## 4. 基础联合系统与候选改进

### 4.1 场景核验后再选择系统改动

当前轻量AP的数据流为：

> 混合IQ → 公共带限 → 第一源定位 → 第二源条件搜索 → 双源联合精修 → 两个位置。

各候选位置的未知波形系数由同一观测重新拟合，比较时保持物理目标一致。交替AP逐源更新位置，联合AP同时更新两个位置；共同停止精度和成本定义见8.10。历史联合网络的数据流为“混合IQ及物理表示→逐源表示／定位候选→频谱—位置关联→源数及逐源联合输出”，留作后续任务扩展的基础。

### 4.2 可选模块与对应问题

| 模块 | 何时研究 | 需要分开的比较 |
|---|---|---|
| 轻量频谱—位置关联 | 两个输出集合分别可用，但对应不可靠 | 固定频带与位置，比较轻量匹配和所提关联 |
| 逐源观测加权 | 各源需要的频段不同，公共处理损害弱源 | 固定后端，比较频带规则、公共学习与逐源处理 |
| 多源物理求解 | 简化位置扫描受强源支配 | 与适用的自适应或联合估计代表比较 |
| 站点可靠性 | 同一源在各站的可用信息不同，或有实际局部污染需求 | 规则式与学习式站点处理，兼顾剩余几何信息 |
| 局部精修 | 候选覆盖足够，但细位置误差仍显著 | 保留原候选，对比精修前后的净收益和长尾 |
| 定位反馈 | 已有结构有效，仍需验证联合更新 | 同前向、同初始化和解码的停止梯度/反馈配对 |

表中模块是研究选项，不是当前并行任务。采用加权时核对频点映射、归一化和相位结构；采用关联时先确认候选覆盖。真值辅助诊断用于估计改进空间，实际方法排名只使用可获得的观测与先验。

R3只比较轻量求解流程，不新增网络、计数头、辅助loss或更大空间表示。

### 4.3 文献如何落到实施中

- 联合任务与逐源输出：借鉴R38及R14/R18/R25/R49，落实同一次集合匹配。
- 学习与物理接口：借鉴R17、R39—R43，保留跨站时延信息并重新训练或校准适配版本。
- 几何关联：按需要借鉴R45/R46或多候选TDOA方法，核对短记录和单源主导条件。
- 物理性能参照：优先R02；若主张涉及联合稀疏能力、多频效率或其他扩展，再选择R07、R33等代表。

## 5. 对照、评价与实验约定

### 5.1 按主要主张选择少量对照

G10-R2已完成八类方法的带限比较。R3聚焦单候选交替AP、单候选联合AP、原NOMP和修复起点覆盖后的多初值联合ML，以区分联合精修的效率收益与求解方式的差异。SBL和GA保留已有结果，不在本轮重复运行，也不将其旧样本成绩混入新样本排名。

模块比较固定输入、源数、初始候选、物理目标和数值精度，只改变待研究的更新方式。完整方法比较统一混合IQ、观测长度、搜索范围、初始网格及可用先验，允许登记的原生搜索和连续精修。当前K=2是所有方法共用的已知条件；真实位置、逐源波形及对应关系仅用于生成和离线评价。

若后续恢复频谱—位置联合任务，硬级联的关联对照只使用预测输出和混合观测；同一次源匹配同时评价位置与频谱。

### 5.2 公共评价协议：EVAL-20261011-v2

#### 5.2.1 适用范围与审批边界

本协议经用户于2026-10-10批准，属于后续Gate共用的评价约定，不新增实验Gate，也不占用G8-R编号。当前先用于已知两源的短记录强弱重叠定位，评价“相同完整耗时下更可靠，或同等可靠性下计算成本更低”。一个共同流程处理部分与完全重叠，不向算法提供重叠类别。

2026-10-11用户批准将主成功尺度设为r=0.02R，并重算近期保存结果。定义R=max_{i<j}||s_i-s_j||，即最大站间距离。当前站位为(500,0)、(0,500)、(-500,0)、(0,-500)m，R=1000m，r=20m；500m是布站圆半径，相邻站距约707.1m，均不作为本协议R。成功条件为欧氏位置误差≤20m，不是每个坐标误差≤20m。

2%是本项目确定的精度要求，并非DPD通用标准。各实验预先登记强弱源定义、时间预算、重复规模及最小实用改善量；更换站位时按同一定义重算R，并报告米制门槛。2026-10-11的授权仅用于离线重评，后续实验按各自审批执行。历史合同、原始报告及Ho教授交流报告保持原样，新口径结果另存。

#### 5.2.2 核心指标与用途

| 指标 | 定义及作用 |
|---|---|
| 弱源定位成功率 | 在距离门槛r内获得有效一对一匹配的弱源场景数／全部含弱源的评价场景数；强源同样统计 |
| 双源同时成功率 | 两个真实源均在r内获得不同预测位置匹配的场景数／全部双源场景数 |
| GOSPA | 综合评价真实与预测位置集合，越小越好；强弱源不人为加权 |
| 未截断RMSE | 按5.2.3的平方距离最优配对，汇总所有有效配对的平方误差后开方；分别报告整体、强源和弱源，不先剔除大误差样本 |
| 误差CDF及P95 | 展示误差分布与长尾；CDF使用固定的平方距离配对，不随横轴门槛重新配对 |
| 完整耗时与计算复杂度 | 与各基线直接比较实际处理时间和运算量，结合定位质量判断收益 |

成功率表示在规定条件和精度要求下稳定找回源的程度，不是算法的自报置信度。弱源成功率和双源同时成功率为重点，GOSPA、RMSE和误差分布提供互补解释，不另加权合成一个总分。误差门槛r与GOSPA截断距离c分开定义，可以相同，但不要求相等；暂无明确应用门槛时用预先登记的距离尺度及完整CDF展示，不事后挑选有利门槛。

#### 5.2.3 一对一匹配与误差汇总

真实位置记为p_i，预测位置记为q_j，d_ij为两者的欧氏距离，单位m。所有方法使用相同坐标、单位和匹配规则；真值仅用于离线评价，不进入搜索。

| 用途 | 匹配规则 |
|---|---|
| RMSE、强弱源误差与CDF | 最小化未截断距离平方和，即代价C_ij=d_ij²，求最优线性分配 |
| GOSPA | 按原指标的截断距离代价及未匹配惩罚求解，不能直接复用RMSE的配对 |
| 成功率与距离门槛内召回 | 先最大化d_ij≤r的有效一对一匹配数；数量并列时最小化有效配对的距离平方和，再用固定索引顺序消除并列，不优先照顾弱源 |

匹配求解可继续使用`scipy.optimize.linear_sum_assignment`；“平方距离”是代价，“匈牙利匹配”是求解思路，两者并不冲突。当前SciPy实现为改进的Jonker–Volgenant算法，论文统一表述为最优线性分配。

RMSE计算为sqrt(全部有效配对的d²之和／有效配对数)，不平均各场景RMSE；当前两源且每次均输出两个位置时，分母为场景数的两倍。固定配对的CDF与逐门槛重新匹配的成功率回答不同问题，不将后者称为同一组固定误差的CDF。完全并列时的逐源归属依赖固定规则，不能据此宣称恢复了信号身份。以后扩展频谱—位置联合任务时，同一对源的位置与频谱必须在同一次联合匹配中同时合格。

#### 5.2.4 GOSPA与历史口径衔接

当前沿用p=2、alpha=2、c=100m；仅将成功门槛r改为20m，不联动修改GOSPA截断距离。c截断大误差，不能区分所有远距离失败；因此GOSPA不替代未截断RMSE和长尾分布。跨场景默认报告逐场景GOSPA的算术平均值，不与均方根GOSPA混用。

历史实现`第四章代码/s2g3_composability.py`的`matched_distances`先最小化距离和，再计算RMSE；新协议改用平方距离和。历史结果保留原口径，新比较的全部方法按同一新规则计算；若补算旧预测，须另存带协议版本的派生报告，不覆盖旧报告。

历史GOSPA总分符合其登记公式，但`missed_count`与`false_count`只记录数量差，远距离错配被计入截断定位项。新报告若展示漏源／虚假位置分解，按alpha=2的部分匹配解释计算：距离达到或超过c的配对按未匹配处理，每个未匹配真实源或预测位置贡献c²/2；三项在平方代价层面相加后开方。历史分项不直接改名为该分解。只报告总分时，也要标明p、c、alpha。

#### 5.2.5 失败、场景与统计

- 强弱源按生成身份及预先登记的全网接收质量口径确定，不按预测顺序或算法估计强度认领。研究强源干扰时保持弱源接收质量和噪声条件一致。
- 已知K阶段各方法最终输出数量按共同任务规定，不能把大量内部候选当最终位置提高召回。无输出、少输出及预算耗尽的场景保留在成功率分母中；缺失源记失败。时间截止时已有有效结果，按截止时结果评价；无结果按空预测集合计算GOSPA。
- RMSE只对确有位置配对的输出计算，同时报告配对覆盖率和无有效输出比例；无配对时记为不可计算，不填0。不截断大误差，不只报告成功样本RMSE。缺失输出存在时，有限误差CDF标明覆盖范围，不能把缺失样本默默删去并画成完整成功率曲线。
- 按记录长度、重叠、功率差、源间距及几何条件分层，主次分组在运行前确定。门槛较大、两个容许区域重叠时，位置达标不等于已证明近源分辨或属性身份正确。
- 使用同场景配对比较和重复随机实现，报告不确定性区间；同一布局的扰动或重叠变体按组处理。调参数据与独立验证分开，test封存规则不变。
- 未知K、空场与三源属于后续任务；届时补计数、漏检、虚警及固定虚警下的弱源召回，不将当前已知K成功率称为完整盲检测能力。

#### 5.2.6 耗时、复杂度与判定

完整在线耗时从输入IQ到最终位置输出，包含必要的IQ/FFT准备、候选生成、搜索准则计算、评分、投影／字典更新、连续精修、解码及数据搬运；真值匹配与离线评价不计入部署耗时。相同硬件、精度与计时边界下测量，GPU运算正确同步，预热与重复计时一致；分别报告平均值和P95，保留超时与失败。离线预计算及缓存建设单独列出，说明复用范围；不把依赖当前IQ或迭代状态的计算移到免费离线阶段。

计算复杂度必须与基线逐项比较，统一使用站数L、采样点数N、源数K、实际评分点数Q和迭代次数I等符号，区分预处理、搜索、更新和精修。自适应算法同时登记实际评分／迭代次数，说明减少网格计算是否抵消了新增判断开销；相同大O阶不等于相同耗时。内存不作为主要研究效果指标，既有RAM／显存上限仍作为工程运行约束。

主要比较为固定r下的“弱源／双源成功率—完整耗时”曲线，并辅以“GOSPA—耗时”及RMSE、强源表现、复杂度表。达到相同成功率所需的耗时，仅在各方法实际达到的共同范围比较；不能外推未达到的目标，不能靠放宽本方法r获得加速。最小实用改善量及强源／长尾可接受变化在正式比较前批准，不因单项指标变好就判整体通过。

#### 5.2.7 文献依据与实施前核验

- Bai等，2023，[TDOA positioning accuracy analysis based on time difference direction-finding in distributed high-frequency surface wave radar](https://doi.org/10.1049/rsn2.12437)，第2节将两测量站的连线称为基线；该文R_i表示目标至站距离，不能与本项目R混用。
- [Evaluation of Time Difference of Arrival (TDOA) Networks Performance for Launcher Vehicles and Spacecraft Tracking](https://doi.org/10.3390/aerospace7100151)，2020，第4节以最大基线描述TDOA网络尺度。参考这一尺度约定，本项目明确采用最大站间距；论文不构成“2%为通用成功标准”的依据。
- Wang等，2017，[Performance Analysis of the Direct Position Determination Method in the Presence of Array Model Errors](https://doi.org/10.3390/s17071550)，第7节Definition 2：按位置误差范数门槛定义成功概率；二维形式sqrt((dx²+dy²)/2)≤Delta等价于欧氏距离≤sqrt(2)Delta。借鉴评价定义，具体阈值自行登记，不直接移用其误差分布近似。
- Ma等，2019，[TDOA source positioning in the presence of outliers](https://doi.org/10.1049/iet-spr.2019.0020)：以RMSE和定位误差CDF评价定位；其“全局收敛成功率”另指异常TDOA识别，不与本协议定位成功率混用。
- Rahmathullah等，2017，[Generalized optimal sub-pattern assignment metric](https://arxiv.org/abs/1601.05585)，Definition 1及Proposition 1：有限位置集合的度量和alpha=2时的定位／漏检／虚警代价分解。
- Kuhn，1955，[The Hungarian method for the assignment problem](https://doi.org/10.1002/nav.3800020109)：最优一对一分配的求解基础；距离平方是本协议对RMSE选定的代价。

v1指标已用于G9；v2离线重评由`统一模型代码/gates/g9/probes/reevaluate_baseline.py`实施，新增20m阈值内的一对一匹配，保持原RMSE和GOSPA计算。已检查边界、输出交换、匹配冲突和空输出。冻结的旧运行入口仍复现v1；后续新Gate须明确接入v2，不以修改旧源文件改变历史合同。此次结果见7.12及实验记录。

## 7. E2E-G9：强弱重叠源的可靠性—耗时验证

G9及R1—R3已完成。本章保留共同求解器修复、充分搜索和区域上界验证；旧配置的恢复率与耗时不替代G10完成适配后的方法比较。

### 7.1 目标与审批范围

2026-10-10用户批准。孤立弱源能够较可靠定位时，加入强源后，比较常规搜索和响应变化引导搜索，判断能否在相同时间内更少漏源，或以更低耗时达到相同可靠性。G8负责发现问题，G9开始验证方法，不要求保留原E2E网络。

Codex完成实现及开发集核验，正式新检查集由用户在PyCharm运行。累计计算上限8小时，短测后实测估算；超出不自动缩减对照或放宽预算。未读取封存test，无网络训练、未知源数、特征值聚类和增益失配扩展。

### 7.2 配对场景与数据边界

四个同步单天线站、已知K=2、匹配直达传播。沿用±1000m区域、100MHz采样及12.5MHz标称带宽的独立BPSK/RRC信号。位置连续取样，站点最小距离150m、源间距至少300m，先研究干扰而非近源分辨。宽带跨站时延保留逐频率响应，不采用整带单一导向向量。

开发16布局；新检查32布局、每布局2组独立波形与噪声，部分/完全重叠、全网平均接收功率差6/12dB、4096/16384点，共512条混合记录。强弱按全网模型平均接收功率定义，不强迫每站同时占优。角色、布局和波形种子分离，前缀长度比较使用同一完整记录。

固定弱源和噪声逐样本不变，只改变强源振幅。12dB档保留同一强源、弱源各自单独存在的对照，弱源单独对照同时适用于6dB档；6dB强源单独表现不从12dB对照外推。不按定位结果删除检查样本。

开发阶段以共同单源参照依次检查弱源平均带内SNR=0/3/6dB，选择两种记录长度均达到90%成功率的最低档。若均不满足，输出SCENARIO_NOT_READY并停止正式比较，不自动增加SNR或降低门槛。

### 7.3 共同求解器与唯一核心改动

共同目标为消去未知逐频源系数后的最小二乘残差。传播响应a_f=exp(-j2πfd/c)/d，已有源形成P_f=I-A_f A_f^+；新增位置评分为Σ_f |(P_f a_f)^H(P_f x_f)|²/||P_f a_f||²。分母接近零时不计该频点，数据与候选同时投影。解析位置梯度须与独立有限差分核验。

| 方法 | 候选发现 | 共同部分 |
|---|---|---|
| A | 50m粗网格、多初值AP | 相同物理评分、L-BFGS-B连续精修、交替更新和回访 |
| B | 当前得分优先的区域细分，兼顾全局探索 | 同A |
| C | B增加投影后响应的空间变化排序 | 同A；新增计算计入预算 |

初版固定5个相隔至少30m的候选初值、最多5轮交替更新，连续精修每次最多30次迭代；第3、5轮允许共同回访。B/C每次最多细分48个区域，每4次有1次选择未细分的大区域探索；其余按得分排序。C加入权重0.25的响应变化排序，不在检查集调整。

C以投影响应u=P a的二维导数构造变化量：Σ_d (||∂_d u||²/||u||²−|u^H∂_d u|²/||u||⁴)，跨频平均并乘区域半宽平方，再转为候选排名。这去掉纯整体相位/幅度变化，不把变化量当有源概率或漏峰上界。B为删除该项的直接消融。区域探索、精修和回访不只给C使用。

普通DPD和DPD-HR保留为完整方法参照，采用各自评分及Powell局部求解；HR开发校准J=2/4/8、相对加载1e-4/1e-2，按平均GOSPA选定，不使用真值频带。先比较上述方法；块NOMP/贝叶斯代表在本轮形成值得继续的证据后另行安排，不将本轮视为完备文献竞赛。

### 7.4 评价与时间预算

执行5.2公共协议。主恢复尺度r=100m，补充30/50m与未截断误差CDF；GOSPA p=2、alpha=2、c=100m。统计强弱源和双源成功率、RMSE、P95、完整耗时及复杂度。100m不是最终应用精度承诺。

开发集A标准流程实测中位耗时为每种长度的T0；预算为0.5T0/T0/2T0，在新检查前冻结。A开发计时每例最多40秒，记录是否预算耗尽，不把限时结果称为全局最优。正式每方法运行到2T0，从同一有时间戳的输出轨迹读取三档截止结果；未形成输出按空集计分，截止后完成的更新不回填之前的成绩。计入预处理、响应变化判断、投影和精修，另报实际评分/响应点数及更新次数。

开发集从A/B中按双源成功率、再GOSPA选一个主要常规对照；C同时与B作直接消融比较。新检查按布局进行配对区间，分记录长度、功率差与重叠报告。主判读预算为T0，其余预算展示曲线。

值得追加投入的参考：同预算弱源和双源成功率均提升约10个百分点，或达到相同可靠性完整耗时减少至少20%；核对强源成功率下降不超过2个百分点、整体RMSE及P95恶化不超过10%，并报告配对区间。等可靠性比较仅在共同达到的范围内，预登记50/70/80/90%尺度。证据不足与明确退化分别报告，不因任一单项过线自动宣布论文成立。

#### 8.9.7 开发结论与接续方向

#### 8.10.9 正式独立结论：联合精修更省计算，错误候选仍限制可靠性

### 8.11 G10-R4：近邻方法核验与扩大比较准备

#### 8.11.1 已批准并完成的范围

已完成原文—现有实现差异、候选贡献和后续比较清单，并更新文献分类。现行目录保留R117多频二维BNOMP-CB和R118 QNOMP期刊版，不再单列预印本。完整证据见[精读报告](outputs_e2e/literature/g10_r4_nearest_20261016/AP_NOMP近邻文献精读与方法差异.md)。2026-10-17用户进一步批准实现、有限短测和正式成本估算；正式扩大比较由用户确认预算后运行。

#### 8.11.2 研究判断

R117已覆盖未知逐频源系数、二维离网位置、残差发现和逐源回访，是比普通一维NOMP更直接的参照。当前NOMP对消元后的局部目标求Newton导数，并更频繁地重估全部系数，与R117固定当前系数的位置偏导及重估时序不同。后续需要登记这项差别，不将当前版本直接改称原论文复现。

R118已包含发现中和末端联合BFGS；原生模型是已知导频、每路径标量增益。当前未知逐频波形需要块化推导，原文的CFAR、正则化、信道外推和角簇重加权不自动引入，统一引用期刊版。

AP多候选联合流程仍是主候选；NOMP_JOINT恢复为扩大比较中的固定候选，与原NOMP并列，不能凭一批没有增益就永久删去，也不预设它必然有收益。两个算法可以共同进入论文，是否分别构成贡献取决于具体差异和稳定价值。

#### 8.11.3 本轮只回答三个问题

1. 按R117对应流程实现的BNOMP，与项目现有NOMP有什么实际差别？

#### 8.11.9 BNOMP慢收敛机制核验（已完成）

本轮只查清：慢收敛主要来自固定系数Newton本身，还是停止容差、局部步长退出和数值保护。复用停止核验的8条观测，不增加布局或新随机实现，不改其他方法和冻结代码。

固定五项诊断：原规则仪表化复跑；能量容差分别放宽一档、两档；仅关闭局部小步长提前退出；仅把局部位置目标改为每个试探位置重新估计当前源系数。最后一项单列为消元更新诊断，保留原文的候选发现和循环后联合系数重估时序，不悄悄替换BNOMP_REF。

先核验固定版本的轨迹复现、消元梯度与Hessian、同一目标下的下降接受及输入身份；再记录实际循环、导数调用、数值保护触发、最终目标、位置与耗时。停止参数只作敏感性对照，不按真值为各样本挑选。准备排期30分钟，单例正常完成后检查是否继续，不启动正式扩大比较。理论上比较固定系数曲率与消元后的曲率，检查未知波形可以吸收的响应变化是否导致位置更新过小。

本轮已完成。原固定系数版本的微小位置更新不是步长封顶、正定保护或回溯造成；放宽能量停止损失定位能力，取消小步长退出只减少了外循环数，实际计算反而增加。单独改为局部消元更新后，保持本批成功数并显著减少导数调用与耗时。原版本逐轮轨迹复现通过，冻结代码和结果未改；精确配置、结果及证据见[实验记录](实验结果记录.md#g10-r4-adaptation-20261017)。

原因可由位置—波形耦合解释：波形系数取当前LS解时，两种位置梯度一致，而消元Hessian为固定系数Hessian减去一个半正定Schur修正。固定系数将本可由未知波形吸收的响应变化计入位置曲率，在部分几何方向产生很小的Newton步。该解释已由独立导数核验及隔离更新对照支持；详细推导见本次结果目录的`回读分析与机制推导.md`。

后续不再为这批样本扫描停止参数。BNOMP_REF保留原文对应更新，现有NOMP保留消元更新；本次诊断用于解释两者差异，不增加一条功能重复的正式主算法。消元和Schur补是已有工具，针对本场景的机制与稳定价值仍需扩大验证。正式停止/成本报告协议及预算另行确认，本轮不替换冻结基线、不启动正式比较。
