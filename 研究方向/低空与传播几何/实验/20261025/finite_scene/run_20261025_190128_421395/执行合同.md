# 有限立面与可见路径：固定小场景核验

2026-10-25。用户批准按下一步建议执行。目标是将路径生成闭合到同一有限几何环境，检查此前独立指定反射/遮挡的缺口；不运行定位排行榜，不保证每个位置唯一，不将新增第二立面诊断直接冻结为论文主场景。

## 运行前固定

- 五站XY沿用近期模型核验，同高z=4m。为检查前一步合理共面部署，暂不重新扫站高。
- 主立面A：x=-250m，y∈[-200,200]m，z∈[0,60]m；辅助立面B：y=-550m，x∈[-300,200]m，z∈[0,60]m。它们是合成的有限竖直矩形薄面，不代表实测街区/完整建筑体。
- 三个固定级别：无面正对照、仅A、A+B。B为事前登记的最低阶结构对照，用于检查其他反射面能否提供被遮挡链路的可见绕路，不依据定位成绩移动墙面。
- 位置采用前一轮4个XY=(80,60)、(-120,140)、(520,80)、(-460,-120)，离z=4安装面30/75/120m的12个位置。额外保留先前的源B=(-80,-100,69)m与约75m外替代位置作为诊断，共14个位置。先前源A=(-460,-120,34)m已包含，不重复计数。各位置不要求事后强行保留4LOS；产生的3LOS、空链路、多个可见反射均如实报告。
- 每级别检查14×5=70条源—站链路，合计210条。不是独立蒙特卡洛试验，不统计定位成功率。

## 几何生成规则

- 同一个不透射平面面片既参与遮挡，也参与反射，双面可反射。
- 直达仅在源—站线段不与任何有限面片相交时存在。
- 一次镜面反射必须：源和站在反射面同侧；镜像线交点在线段上且落在有限面片内部；入射和出射段不被其他面片挡住；满足长度与反射角定律。
- 枚举所有面片的合法一次反射，不只保留有利路径。无直达、也无合法反射时，该源—站链路就是零路径。面片边界接触、共面退化单列，不能静默当成功。
- 无穿透、无绕射、无漫散射、无地面反射、无二次以上反射。此为有限阶几何光学机制模型，不称完整电磁仿真或一般低空传播模型。面片的选择性删除/吸收与实际材料特性不在本轮验证范围。

## IQ及数值检查

- 对每级别的固定原双源位置，合成5站×1024点无噪IQ，采样率50MHz；使用原保存的两个独立未知带限波形系数和非DFT频点（±6.25MHz），不向任何定位器提供该真值。没有运行定位器。
- 生成系数为直达1/L、反射-0.5/L，仅作一致性测试。未知链路系数的估计权限不改变；不把-0.5当实测材料常数，不加入射频载波或速度。
- 时域逐路径合成与频域传递因子合成独立核对；源叠加、互易性、原折线长度/反射定律、有限面片边界和其他面遮挡都有测试。
- 对旧原位置与替代位置，只查在**同一已固定环境**下的完整路径数量及共同时间移位等价是否还成立。结果不推广为未知环境的盲唯一性，不能只在同地图中比较后宣布无地图消歧。
