# C1—C3逐篇精读：环境学习、反射绕射与TDOA图一致性

日期：2026-10-25。范围：主体、正文附录、参考文献逐页通读；不是全文翻译，也不是算法复现。页码均为PDF物理页码，必要时附印刷页码。C1有1页出版社封面，因此PDF页码不等于论文页码。

## 先看结论

三篇文献说明：**“看不到直达路仍可定位”在合适条件下已经实现，但条件并不相同。** C1依赖可分离脉冲、无遮挡初始化与轨迹连续性；C2依赖阵列DOA、预先重建的环境地图和时序积累；C3研究无固定参考的TDOA图，却明确指出回波也可能完全满足循环一致性，而且“某条边没有该源的合法候选”尚不是本文已经解决的问题。

对当前分布式单天线、未知数据波形、静态多源、无地图的候选方向，三篇均不是可直接替换接口的完整解法；但**无共同参考、几何一致性筛选、反射路径分组、缺边图合成等概念已有明确先例，不能重新包装成核心创新。** 剩余问题必须具体落到：在各源不同的可见站子集上，怎样区分真实LOS支持与自洽的回波支持，以及这需要什么可检验的信息条件。

## C1：PEEL——联合定位与结构学习

**原文：** Toros Arikan et al., “An architecture for passive joint localization and structure learning in reverberant environments,” *JASA*, 153(1), 665–677, 2023. [DOI](https://doi.org/10.1121/10.0016999)。Zotero：`DEZW8S7U`，PDF附件：`KA22KI9Q`。

### 1. 实际解决的问题与信息权限

- 单个移动声源，三维水声环境；接收器位置已知、至少4个，允许各接收器是全向水听器，而非必须阵列（PDF2–4，Table I）。
- 声速已知恒定；环境静态；主要反射面为平面，**数量已知、位置和方向未知**；利用一阶反射模型，实验保留部分未建模反射。
- 发射是**已知周期的确定性脉冲**。PDF5明确区分：若脉冲持续时间短于多径间隔，不必知道波形；若脉冲重叠但匹配滤波后可分离，就必须知道波形。周期还须长于信道有效长度。
- **不是任意未知连续通信波形的盲定位。** 原文结论也把通信信号/船舶连续特征及同步作为后续挑战（PDF11，§V）。
- Algorithm 1明确要求初始化时所有接收器均有未遮挡LOS（PDF6）。随后才建立与发射器的同步、初步地图，再处理遮挡。不能把“运行过程中允许遮挡”写成“从完全遮挡状态无先验初始化”。

### 2. 方法链与推导内容

1. GCC-PHAT/TDOA网格定位得到粗位置；已识别LOS峰与预测TOF的差建立同步。
2. 用同步后的回波到达时刻生成等距离椭球；反射面是这些椭球的公切平面。COTANS通过法向角和距原点距离构造Hough式累加器，找反射面。
3. PSO同时更新反射面参数与声源位置，内部仍用TOA幅度累加准则。以Kalman常加速度模型预测下一时刻，并把下一轮位置搜索限制在预测附近。
4. 结合预测距离的幅度衰减识别遮挡，建立遮挡体，再跑第二遍，把被遮挡的LOS项从评分中移除（PDF5–9）。

正文式(3)是各路径延时脉冲之和，路径幅度可以为零；式(6)是接收幅度在预测到达时刻的累加，作者明确称为启发式指标，不是推导出的通用联合ML。

附录A完整推导椭圆/椭球切平面的法向表示。例如原点居中的旋转对称椭球在其角度约定下，有式(A12)：

$$
\rho(\theta,\phi)=\sqrt{c^2\cos^2\phi+a^2\sin^2\phi}.
$$

其价值是避免随机采样椭球表面生成切平面，再进行旋转和平移；**这是给定源粗位置及TOF后的几何子步骤，不是未知地图、未知轨迹的全局可辨识性定理。** 附录B为标准PSO更新（PDF12–14）。

### 3. 实验实际支持什么

水箱实验：4接收器，280kHz高斯脉冲，声速1485m/s，128粒子、每位置5000轮PSO，0.5mm局部搜索网格；搜索盒边长6mm、中心是预测位置（PDF9）。遮挡情形首遍RMSE3.9mm、第二遍2.7mm；无遮挡4站1.5mm；10种随机接收器布置的模拟为2.6mm（PDF9–11，Table II）。这些是其水箱和多时刻轨迹结果，不能换算成单记录RF定位精度保证。

作者明确指出：源进入遮挡区后停止、突然转弯可能使方法失效；任意未知环境和位置会有无穷多解，静态环境与轨迹连续性是消歧的重要信息（PDF2、11）。

### 4. 对当前课题的用途与边界

**可借鉴：** 识别当前模型中缺失的物理路径；显式说明利用何种额外信息使问题可解；不把不存在的LOS硬塞进评分。 

**不可作为现有约束下直接基线：** 用了当前用户排除的跟踪，以及周期可分离脉冲/启动无遮挡条件。若将来单独转为运动源环境学习，才应重新纳入主要近邻。

**分类建议：** `环境与传播结构 / 多径辅助环境学习`，可交叉放入`问题边界 / 跟踪与额外先验`；不放入“严格盲静态多源DPD”主基线类。

## C2：DRA-SSL——反射与绕射感知的多声源定位

**原文：** Inkyu An, Youngsun Kwon, Sung-eui Yoon, “Diffraction- and Reflection-Aware Multiple Sound Source Localization,” *IEEE Transactions on Robotics*, 38(3), 1925–1944, 2022（2021 online）。[DOI](https://doi.org/10.1109/TRO.2021.3118966)。Zotero：`KWYHC2TF`，PDF：`VYY5HM68`。

### 1. 输入不是分布式单天线IQ

- 一个机器人上8通道立方体麦克风阵列，也验证32通道球阵；用DAS/EB-MVDR先估计多条到达方向（PDF3–4、16）。
- **环境地图已预先获得：** IMU＋3D LiDAR＋SLAM生成点云，再重建三角面和障碍物棱边；运行时还需机器人自身位置（PDF4–5，Fig.2–3）。未知声源并不意味着无地图。
- 不使用发射数据波形作为匹配模板；声源为语音与拍手。但具有方向估计、环境几何与时序先验，不能与只给单天线盲IQ的方法等信息比较。
- 支持静态与移动多声源。方法设置P个粒子滤波器对应P个源，再检测其活动状态；不是证明任意未知源数的自动发现与唯一定位（PDF8–10）。

### 2. 核心方法与公式

在2562方向球面网格中每帧取4个高能DOA及功率（式1）。从接收器反向发射声学射线；已知面法向决定镜面反射方向；沿障碍棱边结合UTD/Fermat原则生成绕射锥上的射线（PDF4–7）。绕射触发采用接近棱边的角度指标，阈值0.984；每次生成5条绕射线，保留1秒内的射线路径。

用粒子到某条路径中最近线段的距离建立高斯打分（式8–9）；再对允许参与的路径取均值作为似然评分（式10），与前一时刻权重相乘并归一化（式11）；重采样后依据粒子协方差行列式判断是否汇聚。路径按加权接近概率分配到某个源（式12），防止各滤波器反复利用同一批路径（PDF9–11）。

这里的“似然”是为射线聚集构造的统计评分，**不等于从多源RF未知波形观测模型精确消元所得的似然**。论文没有给出无地图、无DOA或镜像歧义下的可辨识性定理。

### 3. 实验与不能照搬的数字

48kHz、512采样点，DOA/射线10.67ms更新；定位每200ms一次、每滤波器200粒子，利用历史路径与粒子状态（PDF9、11）。7m×7m×3m与7m×3.5m×3m室内实测，有静态2/3声源、移动2声源、遮挡和吸声材料变化（PDF12–18）。两移动源平均距离误差0.7689m和0.7246m（Table II）；这是**平均欧氏误差而非RMSE**。

论文完整表格与正文已视觉核对。PDF14正文中NLOS片段把RA-SSL和DRA-SSL的两个误差值重复列出，又声称31%/26%改进，存在内部数值不一致；其超过100%的“improvement”也不是通常以基线误差为分母的下降百分比。因此本笔记只采用明确的绝对值及指标定义，不复述这些百分比作为证据。

消融总体显示在其已知地图场景加入绕射可改善结果；并不证明只凭额外射线就总能消除NLOS歧义。结论指出：平滑障碍对无限楔UTD近似不利，缺少可反射/绕射障碍的室外场景不适合，强混响及过多声源仍会使方法退化（PDF19）。

### 4. 对当前课题的用途与边界

**可借鉴：** 实际NLOS不只有镜面反射，可能含绕射；“多源会使每源获得的有效观测变少”是明确机制；源—路径关联必须显式处理。

**不宜引入本轮主线：** 在不引入阵列与地图的约束下，无法直接调用其反向射线入口。也不应为追逐“无人机遮挡”一次加入SLAM、三维地图、绕射、动态跟踪等所有模块。

**分类建议：** `环境与传播结构 / 地图辅助反射绕射定位`；交叉`跨领域方法 / 声学多源与路径关联`。不是公平的同输入RF基线。

## C3：一致TDOA的图论框架

**原文：** Martin Kreißig, Bin Yang, “A graph theoretical framework for consistent time differences of arrival,” *ITG-Fachtagung Sprachkommunikation*, Bochum, 6–8 October 2010, Paper 38, 4 pages. [作者机构全文](https://www.iss.uni-stuttgart.de/forschung/publikationen/kreissig_itg10.pdf)。Zotero：`W7YUTHCP`。

### 1. 来源核对

该Zotero条目有题录/网页链接，但本轮检查时**没有PDF附件**。已从斯图加特大学作者站取得排版完整的4页，保存`C3_kreissig_itg10.pdf`与`C3_source.json`，未写入或改动Zotero。现有题录的`Conference on Natural Language Processing`与PDF页脚不符，正确会议如上；分类不能把它当成NLP论文。

结构预检脚本因PDF带加密标记给出`UNAVAILABLE`，不是`PASS`。PyMuPDF可无口令正常读取并渲染4页；全文逐页读过，关键页2–4视觉核对。保留这一工具限制，不把“预检不可用”等同于“未读到全文”，也不伪造检查通过。

### 2. 数学内容与DATEMM关系

每个接收器为顶点，每对候选TDOA为边权集合；从每个集合中选一个值组成权向量w。设A为边×点关联矩阵，Bf为基本环路矩阵。连通图M点N边有（PDF2，式3–4）：

$$
\operatorname{rank}A=M-1,\qquad
\operatorname{rank}B=N-M+1,\qquad
B_f^T w=0.
$$

最后一个条件等价于w属于A的列空间，即存在到达时刻向量t使w=At。只检查N−M+1个基本环路，不必枚举所有环。任意生成树均可，不要求星型公共参考站。

本文明确是DATEMM 2006/2008的理论整理与扩展，而不是独立首次提出无参考多源匹配。两条路线为（PDF3–4）：

- Top-down：找连通分量、生成树、基本环路，搜索满足环约束的权值组合。
- Bottom-up：一致三元组→四元组→共享三元组融合→补缺边；DATEMM是这一类。

**关键物理限制在原文中已经说得很清楚：** 若某个站的传播时延加了回波额外延迟α，那么w变为w+αa_i，仍在A的列空间。多个站都换成镜像路径也一样。循环一致性是TDOA代数一致性，不是真实直达传播的充分条件（PDF3，P2/P3与Fig.5）。作者建议定位后比较预测TDOA残差来拒绝部分假一致图。

### 3. “缺图/无共同参考是否已经解决”的准确回答

**已经覆盖：** 不完全接收器对图、任意生成树、连通分量处理、不依赖单一公共参考站；这些不是我们的新贡献。

**没有在这4页内完成：** 页4明确说TD要求每条被纳入的边对该源都有合法权值；如果某个候选集合根本没有合法值，如何处理仍待研究。BU中是否复用三元组/子图以免漏掉一致图也尚未完成讨论。没有噪声性能实验，没有物理缺LOS情况下多源恢复的普遍保证；更完整TD合成算法指向其参考文献[7] *Efficient synthesis of consistent graphs*, EUSIPCO 2010，本次未借题自动扩展为另一次精读。

**重要区分：** “观测图中某对站没有测量”与“这对站有很多峰，但其中没有源q的合法LOS峰”不同。前者可以显式删边；后者需要同时判断源、路径、有效边，且错误回波仍可能整体一致。不能由本文的缺边图框架直接宣称后者已解决；反过来也不能忽略DATEMM已有不完整图处理，把所有缺失支持问题都说成空白。

### 4. 对候选目标的直接约束

**事实：** 原文已给出镜像路径保持循环一致性的机制。

**本项目推论：** 在固定真实站坐标下，几何拟合残差能排除一部分假图，但若整套路径等效于某个允许搜索区内的虚拟源，该残差仍可能很小；应先构造这种反例，而非默认加几何后真值唯一。这个反例判断不是该4页论文已证明的所有情形定理。

**建议：** 最小核验应分别检查“循环不一致可剔除”“循环一致但几何不符”“循环与几何都吻合的虚拟源”三类；为每源保留足够且几何有效的LOS支持，或者明确增加什么环境先验。无额外信息仍出现等价解时应收缩场景，而不是不断加强优化器。

**分类建议：** `核心方法基础 / TDOA图一致性与源关联`，交叉`可辨识性与歧义 / 镜像路径与缺失支持`。
