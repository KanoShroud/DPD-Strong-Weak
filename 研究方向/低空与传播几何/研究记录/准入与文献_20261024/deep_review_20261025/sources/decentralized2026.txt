of any dedicated server for aggregating intermediate estimates
and for ﬁnal position determination; (ii) The method allows
saving network trafﬁc which is classically used for transmitting
the raw samples between the central server and APs; (iii) The
method avoids leaking or disclosing the position information
which is usually consider private and sensitive information, by
using directly the UE rather than any dedicated and external
server to determine the UE position.
