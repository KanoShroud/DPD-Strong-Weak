# 低空盲多源部分LOS定位：深入调研判断与Zotero分类建议

2026-10-25｜文献与原理核查，不含新定位实验｜分类仅提出建议，未写入Zotero。

## 1. 结论

**应用问题真实；受约束版本存在可解的理论和方法基础；但当前候选还不能确认创新重合度低。** 本轮最重要的发现是：早期声学文献已经明确处理“同一参考站适合源A、不适合源B”“不同源缺失不同测量边”“无需共同参考站”“一致的反射伪解”等问题。不能只在近期RF/DPD论文内判断新颖性。

建议保留候选，不立即正式立项。其表述需要从“逐源选可靠站并施加几何一致性”，收紧为：

> 在同步单天线站接收未知、同时混合的多个辐射源时，部分源—站直达路径实际缺失。不给算法逐源干净参考和源—路径标签，哪些位置仍能辨识？合理的时延关联与联合多径估计之后，还剩下什么必须针对混合观测处理的困难？

这是一项待验证的研究问题，尚不是提出算法。低空是需求来源，不是单凭应用名称成立的新颖性。论文应解决其中一个明确增量，不同时加入未知源数、异步、运动、地图学习和神经网络。

## 3. 问题是否真实：成立，但要区分传播机制

### 3.1 低空NLOS不是假造困难

[Briso等，TVT 2020](https://doi.org/10.1109/TVT.2020.2968136)，§II测量设置及结论，使用无人机发射机与地面接收机，在建筑遮挡下测量1、4、12、24 GHz传播。其场景中，较低频段绕射显著，较高频段多径更突出。由此可以支持低空源—站几何改变传播状态；不能据此宣称所有频率或环境都服从同一分界。该研究使用连续波和接收功率测量，**不能提供我们的宽带时延/混合定位性能证据**。

[Dickerson等，ICC Workshops 2025](https://doi.org/10.1109/ICCWorkshops67674.2025.11162218)的正式记录已核定，库中已有。其实测覆盖不同高度和带宽，支持NLOS、几何和天线方向性影响UAV定位。此前准入记录侧重同题预印本；后续引用优先使用这个正式版本，不自动假定预印本扩展内容与会议版完全相同。

[A2G公开数据，Data in Brief 2025](https://doi.org/10.1016/j.dib.2025.112086)提供3.6 GHz、10/15 m高度、多环境的CIR、GPS与时间。可辅助确定多径参数范围，**不是多站同步、同时多源、严格盲IQ数据**，不能直接拼接后称真实多源定位验证。

### 3.2 源相关遮挡与整站异常不同，但这个动机已有先例

不同源在同站的传播状态不同，在几何上合理。整站丢弃确实可能丢掉另一源的有用观测。然而DATEMM的图9已经明确展示：选定同一个参考节点，会浪费另一源不完整图中的信息。所以“逐源而非整站处理”是应采用的设计要求，不是足够独立的贡献。

还应分清：纯衰减/零增益、LOS消失但保留反射、回传样本污染、相关峰漏检。它们的物理模型和可用信息不同，不能统一成一个bad-link标签。

### 4.1 必须纠正的一种推理

DATEMM虽然在模型中假设所有LOS存在，但其实现已经允许不同源缺不同边，并有无统一参考站的图合成。因此不能使用以下论证：

“论文假设都有LOS → 我们有缺LOS → 所以必须新算法。”

正确核验是：物理直达路径缺失引入的反射候选，是否使其已有缺边处理出现额外且可重复的失败；失败是否能被合理阈值、定位残差筛选或充分子集搜索解决。否则只是适用范围扩展或常规适配。

### 4.2 一致性并不等于真实性

DATEMM §VI-D已经指出零环和是必要而非充分条件，并展示镜像传播产生的一致假图。我们的后续推导不能把这一观察当成新定理。若提出新的判据，需要说明它额外利用哪些真实可得信息、在什么条件下消除哪类歧义；不能只在仿真里排除一切共同反射面，让假峰天然不一致。

## 5. 是否真能解决

应分成三层：

1. **有干净/可分离波形或已知反射几何：已有方法证明若干受约束问题可解。** 这提供方法基础，不等于我们的更弱先验问题也有同样保证。
2. **未知波形、有限稀疏信道：可辨识性需要条件。** 单输入盲解卷积的互素性、激励/频谱条件、尺度和平移规范不能省略；多源还存在源排列和混合分解歧义。
3. **任意未知多源波形＋任意逐链路频率响应＋未知LOS集合：不保证可解。** 任意信道能吸收位置的时延变化。必须限制路径/频率依赖、明确保留的LOS几何信息或给出可用环境约束。

据此，“真能够解决”目前最多可以表述为**存在有希望且应先验证的受约束版本**。没有新的可辨识证明和机制测试，就不能承诺候选一定能形成低风险SP论文。

建议下一个最小核验先固定已知两源、同步、近静止片段；波形未知且不向算法提供源标签。站数不固定为四；每源可用直达几何、有限路径数/结构需在无噪声模型中明确。三维既要检查垂向信息，也要检查全局镜像解。局部Fisher信息满秩只表明局部条件，不能替代全局唯一性。

不要求引入地图；若没有地图仍不可辨识，不能偷偷向算法加入真值反射面。是否接受有限地图先验要另作研究决策。

## 6. 相对哪些强方法才有说服力

| 参照 | 用途 | 公平性要求 |
|---|---|---|
| 共同信息下的有限路径联合ML，AP/VP求解 | 排除只是旧模型遗漏路径或求解不足 | 同路径上限、波形/增益权限、几何与优化精度；不提供正确LOS集合 |
| DATEMM类全站对多峰关联＋正常位置精修 | 检查是否只是常规关联问题 | 允许缺边、多个源各自参考、已有残差筛选，不强迫使用错误的统一参考站 |
| 已关联TDOA的鲁棒/低秩恢复与NLOS方法 | 区分前端关联错误和后端几何估计误差 | 真值关联只作oracle诊断；常规比较必须包含关联成本与错误 |
| 共同/私有稀疏、二元几何约束近邻 | 排除换正则项或简单重新命名 | 先审全文；如果需要CSI/AOA，只作信息条件匹配的支线或结构对照 |

近期已经在库中的SP2025 NLOS误差界、TAP2019 NLOS定位等无需重复导入；它们处理已形成的时延测量，不证明从混合IQ恢复源身份已经解决。不能只比较容易失配的“整站删除”。

## 7. 当前贡献主张的风险分级

| 候选主张 | 本轮判断 |
|---|---|
| 从强弱源转到无人机/低空 | 应用变化，不构成独立算法贡献 |
| 每源选择不同站，不用一个公共参考站 | 已有直接近邻，重合风险高 |
| 时延零环和、图关联、低秩补缺、共同/私有稀疏 | 已有方法，不能单独主张 |
| 两源未知波形下联合拟合多径并交替优化 | 合理基线；单纯扩写未知量/使用AP不够 |
| 在明确部分LOS条件下，给出混合观测的位置可辨识条件或可验证的歧义排除规则，并形成更有效估计 | 值得保留的候选增量；目前未证明，也未确认近邻已经排除 |

最后一项不要求一切数学工具原创，但必须有一项具体、能够改变算法的结果。若常规方法已能满足需求，应关闭该增量，不再堆模块。
