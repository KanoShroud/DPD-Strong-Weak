# 物理约束有效性小核验

2026-10-25，沿用用户批准的后续检查：寻找有实际依据、能排除错误路径解释的结构。只诊断，不把任何新约束直接冻结为正式主模型。

1. 复用上一轮全部540条路径条件和全部替代根，统计未知支持域内替代解的NLOS超额长度；报告原始分布，不按结果挑选一个阈值宣布成功。
2. 对上一轮固定选择的case135完整IQ反例，分别检查原解释和替代解释的两条NLOS能否满足同一个未知平面的镜面路径长度。两种解释允许各自拟合一个平面，因为地图未知；先验证共享平面的时延结构是否足够，不将该测试冒充完整场景光线追踪。
3. 平面法向单位化；所有源及站必须处于平面同侧；反射点位于有效镜面线段；回代折线长度、反射方向定律。源位置和既有路径长度不优化。固定32个随机初始法向、种子20261025，每个最多2000函数调用；单例约束求解未找到解只报告未找到，不宣称无解。不按是否有利追加初值。
4. 所有迭代尝试与最优合法结果保存。正对照使用预先构造的共享垂直平面x=-900m，两个反射链路固定为源0—站0、源1—站4，检查求解和原方程。测试成本不是DPD运行时间。
5. 逐链路未知常复系数、未知波形和独立源保留。不增加已知高度、幅度排序、地图、导频或轨迹；不把实际可见性、材料系数、额外路径自动设成已验证。
6. 核对既有原文关于直达/最强/最先到达、低空遮挡传播及保证条件；公开网页仅补充来源，不把室内结论定量外推低空。

完成即报告哪个约束有依据、哪个只是新增假设，以及当前证据是否足以进入性能实验。不启动新算法、正式批次或Zotero改动。原始证据前后SHA一致，所有新输出位于本项目新目录。
