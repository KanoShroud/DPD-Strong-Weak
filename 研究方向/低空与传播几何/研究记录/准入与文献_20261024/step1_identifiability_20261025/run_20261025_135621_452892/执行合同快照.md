# 第一步：五站、每源三条直达链路的模型与歧义核验

2026-10-25。用户已批准：直达为主、少量反射、无地图；5个固定单天线站，允许高度差；悬停/缓慢运动短记录；从每源3个直达站开始；已知双源、独立未知数据波形、完全频带重叠。定位而非跟踪，不给真实高度、导频、波形、路径标签或地图。

本轮只执行原计划第一步。不启动36条混合/72条孤立性能比较，不修改旧G11定位器、不写论文、不改Zotero。

## 模型约定

- 三维固定源与固定同步站作为准静态核验起点。所有长度米、时间秒、频率Hz。
- 每源在3站有一条直达，在另外2站有一条较弱反射；第一组不额外叠加LOS站的弱反射。这个子类满足少量反射，不代表全部城市信道。
- 各路径复系数未知、带内常数。没有精确距离衰减先验；真实波形不提供已知时间原点。
- 未知NLOS路径长度只受比直线距离长、有限反射阶数等约束。默认不假定全部反射来自同一个可估计平面。共享反射面是更强结构，不能悄悄作为免费信息。
- 无噪声诊断甚至可给定真实LOS集合，用于验证：即使源和路径已分对，位置能否确定。oracle不进入任何性能排名。

## 冻结的小范围检查

1. 推导3个直达站的距离差Jacobian，检查秩和等距离差轨迹；全站对不能把2条独立约束变成3条。
2. 预先指定3组源站构型，在20—120m高度内跟踪等距离差曲线，不按定位结果挑构型。
3. 在首组构型用两个独立带限连续波形，显式构造两套位置、波形时间原点和NLOS延迟，比较5站双源混合IQ。相同有限观测窗直接取样，不使用DFT循环平移。
4. 检查未知正超额时延是否吸收位置信息；给出可实现单次反射路径的几何点。该检查不等于完成一套共享建筑场景的全局光线追踪。
5. 只作诊断正对照：同一5站系统中把某源直达数改为4或5，检查局部秩和合法全局候选。不是擅自把用户主场景改成4/5条LOS。
6. 检查静止及慢速的位移/多普勒相位上界，给出适用尺度，不把短记录自动当作无多普勒。

## 输出与停止规则

- 输出坐标、距离差、秩/奇异值、IQ差异、反射长度可行性、运行源码哈希、环境和图表；不计算定位成功率或声称新算法优势。
- 构造替代解释允许使用真值，因为这是不可辨识反例证明，不是可部署定位器。没有使用真值给定位算法“修答案”。
- 若在允许模型内存在连续等价解，说明该模型不能保证三维唯一性；停止进入算法排行榜，报告最小条件缺口。
- 不由一个反例断言全部无地图多径定位不可解，不把4LOS局部满秩写成全局唯一，不把计数结论当创新。
- 本目录保存源码与合同；每次运行新建`run_时间戳`，保留失败尝试，不覆盖。
