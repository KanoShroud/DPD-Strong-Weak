# 多径 DPD（当前研究方向）

研究四站、二维、同频混叠的两个非合作未知波形源定位。当前主范围为0/1/2条反射；算法不获知真实反射条数、真实时延或波形，不使用“直达功率大于反射总功率”的先验。

当前先完成近邻全文核验和问题定位，文献由用户手动补入。现有多径DPD作为候选与参照保留；风险选模及统一正则化尚未确立新增收益。目录调整不放行正式批次，也不代表现有定位失败已解决。

## 运行

使用 `D:/Software/anaconda3/envs/PyTorch/python.exe`，工作目录为项目根。单条入口要求显式传入项目内含`iq`字段的NPZ，观测须符合现有四站、8192点、50MHz采样、12.5MHz有效带宽协议：

```powershell
& 'D:/Software/anaconda3/envs/PyTorch/python.exe' -X utf8 '研究方向/多径DPD/运行入口/定位已保存观测.py' --input '<项目内观测路径>' --method MP
```

方法可选MP、FLOOD、XIA；不得将其当成任意采样条件的通用定位器。旧批量实验只作证据保留，不以本次整理自动续跑。新实验在本方向`实验/`下建阶段/日期轮次；当前源码不从实验目录或另外三个研究方向加载。
