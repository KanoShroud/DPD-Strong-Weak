# 从固定几何位置到真正盲的共同DPD：有限短测

2026-10-29，依据用户已批准多轮推进。前置模型诊断：有限IQ并不严格满足逐频对角传播，但固定真信道的位置精修没有显著失稳；该oracle结果不能替代未知信道算法。故仅做一次常规盲后端验证，不修窗、不换数据、不扩大模型。

数据：两个既有布局×实现0、5×直达/两反射，8条有噪双源观测。Fs50MHz/N8192、B12.5MHz、公共频带与矩形记录不变。已保存CC_ABS/GEO_ALL位置作为唯一共同位置起点；不重新排序到真实源、不用真路径/增益/波形。所有条件统一允许每链路两条反射，包括直达控制。

求解仅接受(p_initial, frequencies, observed_spectra)：
1. 对每个候选位置用常规对齐后的秩一估计初始化跨站复增益，再联合拟合两源LOS位置/增益；波形每频点自由消元。保留该LOS结果作为常规直接定位参照。
2. 复用既有seed_paths：在估计波形上按正额外时延搜索反射，直达功率大于反射总功率；接受后必须降低同一个波形消元目标。
3. 复用已检查的受约束Gauss–Newton后端（boundary_update.run），正常60轮上限及既有停止条件；不因成功率调整循环。输出几何、LOS-DPD、MP-DPD三阶段，以未截断位置RMSE为主。

保留阶段目标、位置、估计通道、停机原因、实际耗时及输入身份。核对新频率轴上的代表性Jacobian差分、消元直接计算一致性、接受目标单调下降、物理可行性及真值只进入离线匹配。只因实现错误修复；若正确实现仍退化，不马上增加起点或路径搜索档位。

若盲多径后端稳定改善，再冻结流程做独立有限复核并核对最近邻贡献；若退化，优先区分未知信道拟合和频域近似影响。若进一步处理必须改变原先明确的波形先验、窗口/模型选择或研究对象，则暂停向用户解释决策，不自动重启已终审停止的边界加速路线。
