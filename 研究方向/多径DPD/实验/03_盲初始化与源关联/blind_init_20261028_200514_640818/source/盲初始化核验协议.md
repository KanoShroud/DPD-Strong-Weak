# 仅凭观测的最小初始化核验

2026-10-28，用户批准回到观测驱动起点主线。本协议先于本轮求解冻结；只做四条理想频率观测，不启动有限记录或有噪大批次。

## 输入和信息边界

- 复用structure_20261027_202324_816706的两构型、波形及信道；每构型双源LOS-only与原两反射配对，删除反射不改变LOS、波形和功率，无额外噪声。
- 96个原Gauss–Legendre频率点、原非均匀频率观测、不增加Hann或新的频带。欧氏频率残差是本轮诊断准则，不解释为实际有限IQ似然。
- 求解接口只收y、f和公开配置。站点、已知源数2、搜索方域[-3000,3000]m、最多两反射、相邻路径BΔτ范围[3,20]及DRR>0为公共条件；不提供真位置、比特、路径增益、真实DRR=6dB或真实延迟。
- 无反射和两反射组使用相同求解器，均允许最多两反射。统计评价在求解器返回后进行，源标签按最小平方距离匹配。

## 唯一初始化流程

1. 对每个位置补偿几何时延，求五站样本相关矩阵最大特征值；这等价于该位置下未知常复站增益、未知波形的最佳单源秩一拟合。不是利用生成器的1/d幅度。
2. 全域20m网格固定错开半格，节点[-2990,2990]，避免旧位置恰好落网格；保留3个相隔至少100m的首源候选。100m只是候选去重约定，不作为真实源最小间距先验。
3. 各首源按拟合贡献扣除，再以同一评分找3个第二源候选，排除距首源100m内点。共9对，每对在原混合观测上做未知LOS增益/波形联合位置精修（TRF，最多100次函数计算）。保留原LOS拟合目标最好的3对；不要求其收敛后才继续，也不以误差淘汰。
4. 用各对的观测估计波形，在每站尝试反射延迟字典，BΔτ步长0.25、最多两条/源，候选增益对该站共同LS重估；只接受残差下降且LOS功率大于反射和的路径。两路径按时延排序并检查相邻间隔[3,20]。未选中路径保留零幅度占位，不伪造已识别路径。
5. 以实际反射比值坐标做同一多径目标的阻尼Gauss–Newton更新，逐步核对原目标、位置范围、路径间隔及严格功率约束；最多60个外层步，每步最多12次阻尼试探，不继续加预算。使用波形消元的两项精确残差雅可比；阻尼线性子问题与分块位置约化等价。保留3分支原目标最低的终点，完整输出所有分支和停止原因。

本流程是常规初始化能力检查，不称论文新方法。残差扣除、有限候选和路径匹配是否可靠就是待检验问题，不预定其成功。
