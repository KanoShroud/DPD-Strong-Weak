# 条件后续：跨阶数及总反射功率核验

本协议在48条旧观测仍运行时登记，不据新条件的结果选参数。只有旧批正确性、数值停止、位置长尾及成本复核支持继续，才执行；否则保持未运行。未知阶数及跨阶数设计来自用户既有授权。

冻结reference.py及全部阈值、容量64、拟合器、频率、预处理与盲前端。使用原预定布局20和40的源站几何，不根据本批成绩选几何；仅新的波形、噪声与信道实现。小批只核验可迁移性，不冒充完整几何泛化或高置信统计。

每几何一个新实现：固定种子2026103022+10000*布局编号。条件为L=0、1、2、4、链路阶数不一致MIX，以及L=4且反射总功率/LOS功率为1.2的HIGH。共12条观测。普通非零条件总反射/LOS功率固定10^(-0.6)，MIX中非零链路同样固定；零链路单列。HIGH每条仍弱于LOS，反射总功率超过LOS，不给估计器总功率值或其排序。

生成器预制每链路4个相干延迟副本，归一化时延槽位[3,7,11,15]+U(0,0.5)，槽位间隔至少3.5/B；1路径使用一个预抽取槽位，2路径使用首末，4路径使用全部。MIX按预定循环[0,1,2,4]配置10条链路，形成链路阶数差异。此固定槽位只是可复现的生成设置；每源同波形、各链路随机复增益，无墙面或反射地图。生成时延范围与槽位均不传入定位器。

保持50MHz/8192点、BPSK/RRC、带宽12.5MHz、无Hann及原带限。主六条件共享同一LOS、波形、噪声、相位及路径候选池，复增益模随总功率规范化；记录单源LOS带内SNR。路径数与总能量分开控制；1与多路径的时延跨度不能完全相同，报告这一差异，不把所有变化只归因条数。

每条均从原IQ重新执行既有CC峰→有界几何关联→盲增益初值→LOS拟合→冻结未知阶数参照，不沿用旧几何输出或真实波形。计入前端、搜索、联合拟合与记录成本。真值只在所有决策完成后计算匹配RMSE；不按中间位置最佳时刻输出。
