## 1. 本轮要回答的问题

原局部公式在小扰动时成立，但固定清单下的完整噪声变化仍预测不准。本轮用实际幅度的噪声和完整重新定位，检查能否得到有用的位置风险曲线，不按旧32条的真值调修正系数。

保持二维、五站、双未知同频源、原采样率/记录长度/频带、无Hann、单条反射不强于LOS、未知路径数和时延的合同。冻结原前端、增径、搜索、投影、300轮和1e-7停止尺度；不改Xia，不加混合初始化，不启动640条。

## 2. 估计对象及一个重要区别

令 A_k(Y) 为冻结盲定位器最多接受 k 个反射增量时的两个位置，k=0,…,64。若原停止提前发生，就输出原终态。A_64 是原完整流程。原代码阈值只依赖当前 step，而不依赖最终 cap，所以完整轨迹前缀可用于评价这些政策；运行前核对该条件。

这是一组**固定容量上限政策的完整自适应估计器**。每次运行仍自行发现路径。它不是“保持原数据那份反射清单”的局部估计器。不能直接将旧局部风险数值与本轮预测作同一估计目标的误差排名。

使用无序双源损失 L(a,p)=min_perm sum_q ||a_q-p_perm(q)||²/2，风险差 Δ_k=E[L(A_k(Y),p)-L(A_64(Y),p)]，负值表示期望位置MSE较低。估计的是平均风险，不是单条观测的事后最优模型。

## 3. 拟合伪世界与有限噪声计算

按预先固定的编号，使用旧32条中各条件 R00：L0、L2、L3、HIGH。条件名仅用于登记，不传给求解器。完整参照必须正常增径停止且通过原WIDE适用性检查；不合格的donor保存原因并不建立伪世界，不换一个有利编号。HIGH_R00的旧严重失败预期会使其不适用，不能从报告中消失。

由估计终态 x_W 和当前观测计算 s_hat(f)=H(x_W,f)^+ y(f)、mu_hat(f)=H s_hat，噪声方差沿用带外估计。把mu_hat放入原有效频点，其余频点设零，酉IFFT得到长度8192的拟合均值。每个副本生成全记录独立圆对称复高斯噪声 CN(0,sigma_hat²)，而不是直接给原有噪声观测再加噪声；不重采样频率或打乱跨站关系。

每个副本只把IQ交给原 solve_iq，重新估计噪声、盲初始化、发现路径、联合拟合。估计位置、波形和支持只用于生成伪世界及求解后的评价，绝不作为求解初值。拟合均值的带外为零是伪世界假设，并不声称等于原非周期BPSK记录的真实均值。

Delta_hat_k^*=mean_b [L(A_k(Y_b^*),p_hat_W)-L(A_64(Y_b^*),p_hat_W)]。

所有cap共享同一副本，报告配对Monte Carlo标准误。B=16仅用于有限校准和成本评估，不保证分辨很小的风险差。不得用同批65个cap的最小均值宣称实际选模成功。

## 4. 参照误差不会因为bootstrap自动消失

设真实分布为P、拟合分布为Q，真实位置p、拟合位置q。在两个估计器采用共同且稳定的源标签时，d_q(Y)=L(A_k,q)-L(A_64,q)，则

Δ_P(p)-Δ_Q(q) = (E_P-E_Q)d_q(Y) + (q-p)^T E_P[A_k-A_64]。

第一项是伪世界的分布误差；第二项是参照位置误差与方法差异的耦合。一般匹配损失仍可用加减同一项的恒等分解，但标签切换时不能直接使用上述向量形式。本轮单元测试验证稳定标签恒等式，实际评价始终用精确两排列匹配。

因此bootstrap可以反映有限非线性和路径选择，却不能保证修正未知的参照偏差；未知频点波形是大量干扰参数，现有一般文献的渐近保证不能直接搬来。

## 5. 执行顺序和门禁

1. 单元核查：FFT/噪声尺度、精确匹配、风险差恒等式、前缀政策、中文入口和冻结身份。任何工程错误保留记录，修复不得改科研规则。
2. 每个适用donor先做2个副本（种子[2026110341,条件索引,副本编号]）。保存完整原始输入、求解过程、失败及累计成本。
3. 只有全部短测返回原正常停止、正确性检查及终态驻点通过，且按最慢条件单副本成本估计完整48副本总耗时不超过1小时，才自动补足每个适用donor16个副本。数值/流程异常不删除、不换种子、不放松阈值，停止自动扩展并回读。
4. 超过1小时则交付可恢复一键入口，不自动扩量。实际累计达到1小时也在当前副本结束后停止；用户续跑不能越过科学门禁。
5. 完成后先冻结全部预测，再读取旧R01–R07的评价真值，离线计算相同cap政策的条件风险曲线。它们并非新布局或未见研究数据，只是排除donor的条件转移诊断；每条件7次、小样本，不能宣称独立论文验证或选择器泛化。

本轮不预设新的风险选择器。只有数值正确、有限噪声风险有可分辨性、伪世界与条件验证无明显冲突且成本可接受，才形成下一阶段建议。否则保留负面结果，说明需要哪项实质决策；不自动增加B、调权重、改前端或继续扩大。

## 6. 文献依据与边界

- Cunen et al., Model Selection via Focused Information Criteria for Complex Data in Ecology and Evolution, 2019，https://doi.org/10.3389/fevo.2019.00415 。已核对§3.1及§5：宽模型充分性是风险解释前提；不能用“拟合很好”自动证明位置参照正确。
- Dæhlen, Hjort, Haff, Accurate bias estimation with applications to focused model selection, Scandinavian Journal of Statistics 51(2), 724–759, 2024，https://doi.org/10.1111/sjos.12696 。已核对摘要及§3 bootstrap段：偏差项需要足够精度；文中针对特定渐近偏差系数的巨大B例子不是本DPD的样本量要求。没有复现其高阶偏差公式，也未声称全文精读。
- Garcia-Angulo, Claeskens, Bootstrap for inference after model selection and model averaging for likelihood models, Metrika 88, 311–340, 2025，https://doi.org/10.1007/s00184-024-00956-2 。本轮仅取得官方摘要，文中保证有适用区域条件，不作为本DPD算法的现成定理或原版复现。

重采样、配对Monte Carlo、聚焦MSE均为既有工具。可能的场景化增量仍需定位收益与同信息近邻证据，不能把这次算法回放本身包装为新理论。
