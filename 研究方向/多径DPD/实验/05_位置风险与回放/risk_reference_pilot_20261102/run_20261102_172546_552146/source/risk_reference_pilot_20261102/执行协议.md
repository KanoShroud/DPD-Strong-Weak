# 位置风险参照核验：协议与有限短测

2026-11-02，按用户本轮批准执行。仅核查观测驱动风险计算及有限短测，暂不执行重复噪声正式校准或640条验证。

## 固定边界

保持现有二维、五同步单天线站、双未知同频源、原始8192点IQ、有效频带、无Hann、初始化、路径选择和求解器不变。原求解器只读导入，所有输出写本目录新时间戳子目录。允许支付完整参照成本，当前不主张净加速。真值不进入风险或敏感性接口，只在最后评价。

## 次序与规模

1. 对已有可行版12条及未见L3两条记录的LOS、全部增项状态和终态做身份、维数、有限性、驻点及边界审计。旧状态不修改，未合格状态单列。
2. 预定L20_L0、L20_L2、L20_L3、L20_HIGH四条，每条比较LOS与完整未知阶数终态，共8个状态。选择依据是无反射、开发阶数、未见阶数、总反射超过直达四类条件，不读取定位误差筛选。边界或非驻点状态不套内部点公式，也不替补有利样本。
3. 核对非零残差实际目标Hessian、观测—梯度交叉导数、零残差GN极限、固定线性风险恒等式。有限差分步长预定1e-4、5e-5（原无量纲优化坐标），不以RMSE调节。列尺度仅用于数值条件检查，不删弱方向或加正则掩盖病态。
4. 若导数及局部条件通过，仅对L20_L0、L20_L3的LOS/完整模型做固定支持、估计状态暖启动的局部扰动短测：每模型先一次基点求解，再对同一估计噪声方向的正负0.1倍扰动各求解一次，最多12次求解。沿用原300次上限、原1e-7验收与所有约束。不是盲定位重跑、不是独立RF样本、不是完整风险校准。不执行新路径搜索。
5. 汇报风险差诊断、参照误差、边界、不稳定导数及成本；依据实测提出重复校准预算，等待用户确认，不自动扩批。

## 理论口径

采用实化观测z=sqrt(2)[Re(y);Im(y)]，复噪声方差sigma2对应Cov(z)=sigma2 I（在当前白噪声模型下）。令r(theta,z)=P(theta)z，P是波形最小二乘消元的正交投影，F=0.5 r^T r。该未归一化目标与冻结求解器的F/||y||²具有相同位置极小点；在驻点处敏感性相同。使用未归一化形式避免把与观测有关的分母漏进交叉导数。

g=F_theta，H=F_theta,theta，J=r_theta。利用P=P^T=P²，g_z=J^T。内部非退化局部驻点的真实目标敏感性为L=-UNIT E_p H^{-1}J^T。H必须包含非零残差曲率，不能替换为均值切空间GN；零残差时两者才一致。H由解析g中心差分取得，检查对称性、两步长稳定性及尺度化正定性。边界状态不使用本内部点公式，不新增KKT模块。

两源局部固定标签的插件分数为Rhat_M=(||pM-pW||²+2 sigma2 <LM,LW>-sigma2 ||LW||F²)/2。W是观测估计的完整模型，不是真值。该式在正确固定仿射模型下对应已有focused-risk/SURE恒等式；实际非线性、同数据估计设计、自适应支持、参照偏差时这里只是待校准分数，不能称无偏风险或误报保证。负分数保留。参考模型自身偏差不假定为零，不能用同一参照相减自动消除它。

## 事前数值门槛与结果解释

- 原驻点门槛保持1e-7。边界距离1e-8用于识别内部点，不放宽原约束。
- H对称相对误差<1e-4、两步长H相对变化<1e-3；尺度化最小特征值须>最大绝对特征值的1e-9；两步长位置敏感性相对差<1e-2。
- 观测交叉导数中心差分相对误差<1e-5；零残差H与GN相对误差<1e-4。
- 线性合成20000重复、固定种子2026110201，仅检验公式；均值差<6配对标准误，不算定位样本。
- 局部暖启动短测记录中心位置响应与预测差，预定相对差<10%作为试验性局部线性验证门槛；微小响应、基点漂移及不收敛均单列，不用真实位置选结果。原状态与诊断重拟合状态不能混入正式成绩。
- 公式通过不等于模型正确；当次分数与单次真值误差同向不等于风险校准；局部暖启动通过不等于盲全流程成功。实际重复校准需要新噪声和新波形/信道分层设计，下一关另行冻结。
