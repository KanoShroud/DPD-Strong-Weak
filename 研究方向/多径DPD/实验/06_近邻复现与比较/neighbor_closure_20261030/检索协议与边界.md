# 近邻收口检索协议与执行边界

日期：2026-10-30；目标不是泛写定位综述，而是审查“单天线分布站、未知同频双源、无地图有限复多径、几何初始化后原IQ联合拟合”的最接近场景与方法。

## 检索轴

1. 场景：direct position determination / direct localization / geolocation，multi-source / cochannel / unknown waveform，multipath / NLOS。
2. 求解：joint waveform channel location，maximum likelihood，variable projection，EM / SAGE，blind demixing / blind deconvolution。
3. 先验：single antenna / distributed receivers，known pilot / unknown data，known reflector / unknown environment，cyclostationary / PARAFAC。
4. 出版范围：优先IEEE与Elsevier；为防遗漏保留Sensors、IET及相关基础数学来源，不把非首选出版社一律排除。

`collect.py`登记12个初始Crossref查询，`extend.py`登记5个补充查询。初始并发触发7项HTTP429，改为降低请求速率后这7项全部成功；不是忽略失败。最终17组525返回记录，按DOI或标题去重461条。另有精确标题/DOI核验，不与主题检索次数混算。

## 纳入与排除

- A：同场景或联合波形/信道/位置框架，必须按正文核对，不只比标题。
- B：多峰关联与盲初始化，允许TDOA/测距形式不同，但注明信息差别。
- C：已知导频、阵列、多普勒、地图、RSS、可分循环频率等信息条件不同的定位方法；保留用于说明边界，不强行加入同信息排名。
- D：变量消元、EM/SAGE、盲解混与可辨识性基础；原有工具不作为首创。
- GNSS已知码、RF静默目标雷达、轨迹跟踪、RIS/指纹地图、纯图扩散定位不扩成新研究分支。关键相近者仍登记排除理由，而非仅按应用名称排除。

阅读层级单独记录：全文精读、定向公式核读、复用历史全文记录、出版社/作者摘要、元数据。下载/提取全文不自动等于读完。Demissie2011文本提取乱码，判断其模型前提采用渲染第2页，不采用乱码文本。

## 证据与可复查性

- `search_raw.json`、`search_extended.json`：原查询、HTTP状态、完整返回。
- `snowball_extended.json`：补充引文链返回。
- `nearest_metadata.json`、`last_branch.json`：正式DOI/出版源核验。
- `zotero_inventory.json`：只读顶层记录快照，895条；可能含用户原元数据，不以它替代正文。
- `local_fulltexts.json`、`public_fulltexts.json`、`source_identity.json`：本地/公开全文路径与状态，PDF身份。
- `neighbor_matrix.json`、`近邻文献矩阵.md`：46项最终分层及证据级别。
- `未入库文献与链接.md`：16项尚未匹配入库的链接；正式版优先。
- `geometry_identity.json`：100个代数身份测试，不是定位实验。

限制：专用学术检索MCP未提供；通用预检脚本返回NOT_ENOUGH_DATA，直接requests的Crossref和OpenAlex实际可达。未宣称使用付费全文数据库的完整检索。公开全文SAGE下载遇到证书错误，保持TLS核验；Elsevier部分页面403，改用出版社可见内容或作者稿，阅读范围仍标明。

## 结束条件与后续更新

此次完成“可执行的近邻版图”，不是证明全球不存在重合论文。主线已覆盖场景、联合估计、初始化、跨谱/张量与盲解混五条相邻路线；最后扩展的文献均能归入这些分支，没有据此新增实验场景。

后续只在新论文同时匹配关键未知量/观测条件、或给出可以替代当前关键步骤的算法时升级为核心近邻。其他新引用补到矩阵即可，不自动推翻已完成的模型/数值核验。投稿前再按正式题目做一次更新检索，不把每轮算法验证都变成重新选题。
