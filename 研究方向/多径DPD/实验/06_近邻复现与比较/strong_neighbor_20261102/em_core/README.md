## 数据与目标约定

`operators[C,D,N]`把每个分量所属源的N维共同波形映射到D维复观测；`source_index[C]`决定共享关系；`gains[C]`为未知复增益。单源所有路径共享同一个波形；两个源各有独立未知波形。站局部分量可在不属于该站的观测行置零，对应原文逐站增益估计。

固定算子与增益时，构造`A=[sum(gT)_source0, sum(gT)_source1]`，由观测y最小二乘估计波形。估计器接口没有真位置、真波形、真路径数参数；这里算子及分量数量为小型公式测试的给定设计，不代表正式盲定位允许已知实际路径拓扑。

残差目标`F=sum|y-sum(mu)|²`，不含噪声除数。固定E步的代理`Qtilde=sum|zhat-mu_new|²/beta`，省略与新参数无关的协方差常量。加权Cauchy–Schwarz给出：

`F_new <= Qtilde_new`，`F_old = Qtilde_old`，因此`F_new-F_old <= Qtilde_new-Qtilde_old`。

仅在M步真正降低这个代理时才保证观测目标不增。`waveform_surrogate_ls`解代理共同波形子问题；`waveform_ls`解原始观测式(43)，两者不是同一个子问题。增益/波形交替LS单调不等于全局最优，秩亏时返回秩与最小范数解，不用正则化隐藏退化。

## 单元核验

`selftest.py`固定随机种子，检查单源/双源共同波形与独立`np.linalg.lstsq`参考、正规方程、逐站增益、交替LS每半步不增、E分量和为观测、协方差PSD与总噪声约束、100个随机候选下的代理差上界、共享波形M步单调、每路径自由波形与共同波形并非同一模型、秩亏报告和非法beta拒绝。生成`test_*/result.json`并记录源码与原文哈希；这些是公式检查数量，不是定位案例数。
