# Xia公开信息重建：固定实现约定 v1

2026-10-27，用户授权：无法获得作者代码时，依据相关文献与DSP通行做法选择最合理实现。不再等待作者，不追求按结果选配置。以下约定在新性能短测之前冻结；是公开信息重建，不声称作者实际代码如此。

## 原文明确参数

5个同步单天线站，二维6×6km²，参考站原点；BPSK、900MHz载频、采样1MHz、符号率200kbps、2000点；1000初始均匀粒子；Δh400m；Γ=diag(100,100)m²；初始评分后执行两次重采样评分。表I延迟0/3/8/11/13/21μs和相对幅度0/−7/−15/−22/−24/−19dB。

## 不确定项的唯一主实现

| 项目 | 固定选择 | 原因/依据 |
|---|---|---|
| 波形 | 独立等概率±1符号，每符号重复5点；每源独立0…4点的符号时钟偏移 | 矩形脉冲是无需滚降参数的标准初始BPSK模型；MathWorks rectpulse |
| 非整数时延 | 有符号FFT轴上exp(−j2πfτ)，观测按原式(4)构造 | DFT移位定理；明确是循环频域信号模型，不假称非周期有限窗实测 |
| 相位 | 各源各站直达相位独立U(−π,π)，反射额外相位同分布；单记录固定 | 最小未知相位补全；不额外加入未指定的Rayleigh幅度或Doppler |
| 路径幅度 | 表I幅度按10^(dB/20)，乘同链路LOS幅度 | 保持表I相对强度，不逐次把总多径功率归一化；G增加时允许总功率变化 |
| G含义 | 总路径数，G=1为LOS；G=3使用0/3/8μs三条路径 | 表I含直达的六路径与图2 G=1…6的最简一致解释；非作者确认 |
| 大尺度损耗 | 原式(17)，各源各站独立5dB标准差阴影 | 论文明确参数；相关性未指定采用独立基线 |
| 功率与噪声 | P1=1，P2=10^(−SIR/10)。SNR为目标LOS分量的五站平均接收功率与噪声功率之比 | 明确的接收SNR标定；不把发射功率与绝对接收噪声未经链路预算直接相比 |
| 公共尺度 | 原绝对复增益全部除以同一个sqrt(mean_m|g_1m|²)；两源共用同一因子 | 仅数值单位变化；保留源/站相对损耗。等价于在原绝对单位按目标平均LOS功率设置公共噪声方差 |
| 噪声 | 各站独立CN(0,σ²)，σ²=10^(−SNR/10)；不由混合观测重估 | 不随干扰强度或增反射而增大噪声，避免measured混合功率造成混杂 |
| 部署 | 每个独立实现中，其余4站及2源独立均匀取自[−3000,3000]²；无成绩筛选、无最小间距筛选 | 原文只给随机区域，采用最少额外约束的分布；固定布局不替代随机实验 |
| 输出关联 | 完整双源按平方误差最小一对一匹配，分别报告目标及另一源；另存原始第一峰的目标误差 | 解决无标签输出；原文j=1关联未明确，不能只取真值最近候选 |
| 未完成轮次 | 若已有完整双源估计，下一轮失效时保留最近一次完整估计；否则报告缺失 | 确定性输出保护，不改变评分、阈值、抽样或停止轨迹；不选误差更小的一轮 |

σ²等价标定说明：设原目标平均直达功率为A，噪声绝对方差取A/10^(SNR/10)，再将所有观测除sqrt(A)，即得上述归一化模型。没有逐站混合RMS归一化，也没有分别归一化两个源。SNR是给定部署和阴影下的受控接收条件；不代表固定热噪声下距离衰落造成的全部SNR变化。SIR仍为发射比，实际各站/站平均接收SIR随构型变化，需保存。

## 不增加的处理

无Hann、无额外带限、无RRC、无对角加载/谱除法正则化、无额外精修、无峰值后备替代。只保留已批准≤0停止解释和第五直方图格的数学精确端点。其他真实超阈值或空第二簇不静默修正。

后续轮次保持最近完整输出是本次补全的输出约定，报告同时列出原终态完整数，避免该约定掩盖轨迹失效。

## 本轮固定短测

- 基础随机实现12个，编号0…11，主种子2026102707；部署、符号、信道、标准噪声独立生成。
- 每实现G=3，SNR=−10/5/20dB，SIR=−3/+3dB：72次。
- 同实现G=1、SNR5dB、SIR3dB：12次直达控制。
- 总84次，跨条件复用基础实现；噪声仅按SNR缩放，改变SIR只缩放源2。
- 不是1000次正式统计。不挑最好布局，不调整以上约定；若大量缺失，先如实给出可输出数与条件RMSE，不发布全样本RMSE或声称达到原曲线。
- 结果保存所有状态、输出保护是否触发、逐源误差、实际接收SIR、噪声功率、时间及SHA。短测后才判断是否值得正式1000次。
