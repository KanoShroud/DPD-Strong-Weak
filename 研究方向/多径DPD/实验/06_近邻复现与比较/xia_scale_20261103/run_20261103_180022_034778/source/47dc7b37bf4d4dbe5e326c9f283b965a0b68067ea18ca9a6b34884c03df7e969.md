# Xia原生随机搜索的公开尺度适配

2026-11-03；用户批准后、首条新定位之前冻结。本轮只改变全域候选覆盖预算，保留原评分、十箱阈值、聚类和两次高斯重采样。不是新定位方法或独立测试集。

## 尺度推导

参考站差时 t_m(p)=(||p-r_m||-||p-r_0||)/c 全局满足 |Δt_m|≤2||Δp||/c。有效基带频率 |f|≤B/2。因此候选距离≤r时，几何补偿相位差≤2πBr/c。

固定数值分辨设计常数为相位变化≤π/2，取 r=c/(4B)。固定首轮双源邻近覆盖失败上界 δ=0.05，不按本批误差选择这两个常数。它们是公开设计选择，不是理论唯一最优参数。

边长D=6000m的正方形内任意点（含边角），半径r的圆与区域交集面积至少πr²/4。令 a=πr²/(4D²)，首轮均匀独立抽取M粒子，两个任意固定域内源各有邻近粒子的失败概率不超过 2(1-a)^M。故 M=ceil(log(δ/2)/log1p(-a))。使用项目c=299792458m/s、B=12.5MHz，不使用真实位置、反射数、时延、20m成功门槛或此前真值剖面宽度。

此界只保证首轮邻近覆盖：不保证正确峰排序、两不同候选、聚类存活、最终成功或全局最优，也不约束反射幅度/相位。两个球不需要独立。95%是在抽样前关于随机池的概率界，固定种子后不叫定位置信度。高斯后续两轮没有全域覆盖界。

400m是源簇分割尺度，10m是局部重采样标准差；本次均保留原值，不用同一比例缩放。沿用原3轮同一粒子数，不改变输出保护规则；严格终态主报告，最近完整输出另列。采用与旧批同seed规则，完整失败保留，不换seed重试。

原有限傅里叶和采用8倍FFT表和8阶局部Taylor数值计算，不改变统计评分。精确算术余项按原系数L1范数给界；浮点误差另外与原直算比较。四个R00旧1000候选及旧各轮的阈值mask、直方图、聚类轨迹和位置必须一致；新每轮另抽样及检查高分点与原直算。数值检查不通过即停，不以放松误差门槛继续。

准备、候选生成、评分、阈值、聚类及保存均计入批次成本；额外正确性检查单列。该数值加速不列论文算法创新，也不混同与其他定位方法的速度排名。

1. 新目录冻结源码、原32条输入和合同身份；编译、Ruff、公式/数值核自测及1000点全流程一致检查。
2. 先运行L0/L2/L3/HIGH各R00的4条尺度适配短测。先保存估计，再读真值评价。完整初始随机池不写巨型JSON：保存种子、每轮RNG状态、全池坐标/评分SHA、直方图、保留候选NPZ及最终决定，可按快照重建全池。

5. 支持原合同恢复，跳过已完成条目，保留中断账本。若已保存32条完整，默认只回读，不重复定位。没有640条、新场景、新先验、新风险规则或共同前端EM。

首轮邻近覆盖改善不等于整条流程充分适配。若覆盖正确仍失败，应按原筛选/聚类/重采样证据判断，不无限加粒子或免费接入我们的前端。固定400m/10m并非宣称最优；是否进一步改动须有明确机制，不能根据本批RMSE扫参。
