# 四站2.4GHz物理单位比较

本目录保存2026-11-04批准的新实验，独立于旧五站删通道配对。正式3120条在用户运行一键入口前不会启动。

## 固定设置

- 四角单天线站(±3000,±3000)m，二维双源、搜索域±4500m。
- 载频2.4GHz、天线0dBi、温度290K、噪声系数5dB，功率W/dBm、复基带sqrt(W)。
- 每个构型按自由空间损耗分别设定两源Pt，使各自四站平均直达**名义**带内SNR6dB；Pt在20次重复和13条件中固定，实际有限记录SNR另存。
- 50MHz、8192点、BPSK10MBd/RRC0.25，不加Hann，±6.25MHz有效频带。
- 无/单/双/三反射共13条件，具体时延和rho见protocol.md；每条反射弱于直达，但允许反射功率和大于直达。
- 正式全内/全外/混合各4个构型，每构型20个独立波形/信道/噪声实现；开发1/1/2各1实现，共52条。跨rho共享实现用于配对，不等于52个独立场景。
- 生成几何筛选规则及种子完整保存在contract.json，不根据定位结果挑选。

## 方法与文件

scene.py仅负责数据与配置；adapters.py按四站/新边界实例化冻结算法；runner.py仅向估计器传IQ及公共参数；correctness.py为数值单元核验；release.py检查短测后是否可放行；report.py只回读结果。

GEO/LOS是完整多径DPD的前端阶段，分别报阶段累计耗时；MP为完整自然停止总耗时。Flood重做自己的提峰/三站候选/运输关联/精修。Xia保留自己的随机搜索/评分/聚类/重采样，不接我方前端。Xia每轮10582497粒子，全池参与计算，只压缩保存为RNG状态/哈希/输出以便重建。原高斯重采样允许域外点，不暗中裁剪。

## 运行入口与恢复

入口位于项目`研究方向/有限记录DPD/运行入口/G11/四站2p4GHz多径完整比较一键运行.py`。需release.json明确formal_allowed=true才能运行；它不会为满足一键交付而跳过科学门禁。默认一次连续运行所有正式方法，不分第二次点击。已完整保存的案例在恢复时核对SHA后跳过；部分方法已保存则只补未完成方法。若恰在决策与校验旁车之间意外退出，会安全停止并要求核验，不静默接受不完整证据。

原五站和旧算法源码不变。运行中禁止改本目录Python、protocol.md或contract.json；入口会检查身份，防止混入新参数。

## 证据边界

正确性测试包含频域精确直达模型下、真值邻域初值的局部数值控制，不是全局盲定位保证。所有真实短测输入均非周期物理波形且只由观测初始化。无效数值结束与缺失位置如实报告；缺失不填零，未收敛但有限的位置仍保留在RMSE中。

正式耗时必须按构型类别与条件分层外推，开发1/1/2与正式4/4/4权重不同，不能直接以开发总耗时乘60。最终交付说明将以审计后的分层预算为准。
