# S1-G4：候选权重的无调参可行性检查（执行前登记）

仅在run_v2数学门通过后执行。不是定位性能实验，不选择最优lambda。

对任意接收反射分量d=bD_tau s，有|<W_m,d>|<=||W_m|| ||d||；所以lambda>=max_m||W_m||同时覆盖任意数据依赖波形方向，不需要固定字典。单位酉频域AWGN下||W_m||²/sigma²~Gamma(F,1)，用4站Bonferroni、alpha=.05得到保守界。

从六已见银行读取原生成噪声方差，仅作理论诊断。不得把该真噪声方差给实际定位器，也不把此事件称为整个非凸定位算法的误报率或RMSE保证。对同12条件的每条真实反射，报告该界/分量频域范数；>1意味着在孤立已知方向、无噪声的软阈值小模型中会被完全收缩，不等于实际混合算法必然删该径。

固定原子字典的比较界sigma*sqrt(log(K/alpha))仅解释为何现有小阈值不能直接搬来；K=8*(8192-1)，不把它作为当前未知波形算法的已校准lambda。保存所有结果，不扫alpha或权重找优势。

若通用保守界会大幅收缩现有有效反射，停止直接部署这条lambda规则，报告需要针对条件模型进一步定标或重新选择估计准则的科学取舍。不得通过经验降低常数继续跑定位。
