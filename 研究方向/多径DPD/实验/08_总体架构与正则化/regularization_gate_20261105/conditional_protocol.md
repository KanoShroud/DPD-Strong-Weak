# S2-G3：固定信道的噪声约束最小反射分量

前一观察门结果：24条既有盲LOS中仅6条L0满足原总噪声半径，18条多径均不满足；没有因LOSR=0而直接关闭全部多径。此结果只支持进入条件数学门，不支持定位性能。

固定H、c_q=sum_ml|b_mql|，求V=min_S sum c_q||S_q||，约束RSS<=delta²。波形子问题凸；使用惩罚形式0.5RSS+lambda*R的单调残差寻找约束乘子。lambda上界由零组KKT最大相关/c解析给出，区间二分，不按RMSE选lambda。无惩罚组先以原逐频点LS投影消去；lambda=0、零解、LS不可行和边界单列。

每个正则子问题使用两源精确组坐标下降，每组用标量单调根求解；原始/对偶间隙作为停止条件。最多1000循环，间隙<=1e−9*数据能量；外二分最多50次，RSS相对数据能量误差<=1e−8。数值额度仅为新凸内层，不替换原定位优化预算。若未满足则失败，不夹断波形或偷偷加epsilon。温启动允许，仅使用同一个子问题的上一数值解。

先检验lambda=0、非零组、零组、无惩罚组、不可行半径、零惩罚最优、复尺度不变性和固定H/c的包络方向导数。随机矩阵固定种子2026110519，用来验证代数，不改变物理场景。通过后对全部24条原盲MP终态作条件求解：保留旧位置/增益/时延/路径清单，仅改变S并求乘子。旧H不可行则报告，不删例或默认先修好；旧波形的普通LS残差应是同H下最小。

这一阶段不能产生新位置，不报告新定位RMSE，不把条件时间作为完整定位时间。理论、KKT、耗时及不可行数量决定下一步。对同一完整数据的固定H残差半径不宣称严格校准；仍用G1原总噪声半径，未根据结果切换自由度。
