# 固定支持外层机制短测

外层精度控制12/12通过后，自动进入这一有界阶段。目的：检查降低新目标实际怎样移动位置，而非只证明一个下降方向存在。

输入仍为原24态中12个正乘子、可微条件态；其余4个零惩罚态和8个不可行态原样登记为本求解器不适用，不隐藏或强行恢复。保留位置、直达增益、每条反射增益和时延作为变量，但固定反射的源站归属与条数。使用全部已定的逐径幅度、时延和位置约束；无真值输入、无新支持、无删径阈值、无更严格生成器先验。

采用谱投影梯度作机制求解器：精确条件波形求解（严格精度版）、解析外层梯度、原物理集合投影、Armijo实际目标下降。初始最大坐标试探变化0.1，后续BB步长，正曲率失效则回退初始规则；步长限于[1e-12,1e12]以防数值溢出。投影梯度映射在固定单位步长的原x坐标计算，阈值1e-7。最多100次外层迭代、每次20次回溯；达到上限单列，绝不称收敛。无墙钟停止。此优化器不主张新颖性，也不用于证明3—5秒复杂度。

先保存全部终态和轨迹，再读取真值计算前后RMSE、误差尾部。没有进一步根据结果改步长、目标权重、噪声半径或容差的计划。完整代价应另计旧起点和模型构造；本轮只报新增精修代价。

若不能在这些固定支持上稳定取得收敛与位置精度证据，不自动启动完整盲初始化/阶数联合搜索；应回到目标与求解结构评估。若通过，也不能直接冻结：固定支持尚未解决未知阶数及8个不可行起点，需有明确的同目标全流程设计后再推进。
