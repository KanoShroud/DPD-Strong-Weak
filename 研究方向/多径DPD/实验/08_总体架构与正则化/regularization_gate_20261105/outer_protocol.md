# 外层导数与可行下降核验（评分诊断通过后登记）

不改噪声半径、不调正则参数。使用24条旧盲状态中条件核已经返回 interior_discrepancy 的全部12态。其他状态不强行套梯度。

外层目标 V(x)=min_S sum c_q(x)||S_q||，约束RSS<=radius²。正乘子、光滑内点时：

`dV = sum ||S_q|| dc_q + Re <HS-Y,(dH)S>/lambda`。

计算使用实际四站变量坐标及解析通道导数；不能用普通VP的LS波形梯度替代。尺度规范沿用旧参考站增益，不增加已知信道假设。归一化目标 V/||Y|| 仅改善数值尺度。

- 对位置、直达复增益、反射复增益、时延四组，固定随机种子取一个单位方向；步长1e-3与3e-4同时报告，不能事后挑步长。
- 两步的误差都应<=1e-5+0.02*max(|解析方向导数|,|差分|)。中央差分可能越过物理边界，只测试光滑延拓的导数，不称物理可行更新。若出现零幅度不可微、子问题不可行或不认证，显式标注而非修剪。
- 另用已有物理投影作一个下降步，初始步长将最大坐标改变量限于0.1，最多20次减半；Armijo系数1e-4。停止不按时间。它仅是求解器正确性检查，不是完整位置精修，不产生新算法RMSE。
- 所有状态保留。任何导数未通过或投影步无法下降，先停止完整外层自动接入并追查原因；不放宽容差寻找成功。
- 通过后再判断是否具备有限固定支持外层求解的条件；不直接启动完整盲增径或正式比较。
