# 外层差分失败的求解精度控制

首轮12态均获得物理可行下降，但6态至少一项方向差分未通过。较小差分步长放大数值误差是待检验原因，不是已确定解释。

只将内层对偶间隙容差1e-9收紧到1e-12、归一化RSS根误差1e-8收紧到1e-11，并将二分最大次数50调整为60以容纳更高精度。两份源文件隔离保存，不修改原通过/失败结果身份。

相同12态、相同随机种子、相同方向、相同步长、相同外层验收阈值和投影线搜索。仅作一次精度控制，不根据RMSE选择容差，不改变模型、噪声半径或正则准则。若仍未通过，停止自动接入并记录未决原因。若通过，只能说明首轮差分核验受内层精度影响；部署精度和完整时间仍需单独确定。
