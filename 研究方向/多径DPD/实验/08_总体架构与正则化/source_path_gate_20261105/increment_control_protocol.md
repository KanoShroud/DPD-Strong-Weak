# 失败状态的增径组织控制

阶段B发现4个DIAGNOSTIC_NEAREST三反射分支，在成组增径后未驻定。其中3个SLSQP在3轮报告约束不相容，1个用尽300轮；前一固定模型均已通过原PG门。阶段B的自动盲原型门未通过。

按主协议允许的一次针对求解环节的控制，对这4个失败状态全部纳入，并加入IN101/L3最后一次成功增径作为正控制。此前score_control仅对既有候选评分，不作新的定位求解，不能替代本项数值归因。

每例恢复前一驻定状态，使用同一IQ、同一个step的原search完整银行。GROUP完全复现原每链路最多1条的成组加入；SINGLE只取同银行中证据最大的1条，是原始逐条增径方式，不调整阈值、参数、候选集合或容量。

两臂保持原300轮、原PG1e−7、原约束和相同初始化构造，串行交错。分别评价增维后目标的非增性、原PG和可行性。两臂新增维数不同，不以它们的原始残差或RMSE直接宣布谁更优；本实验不构成完整未知阶数定位，也不能拿单步耗时替代完整耗时。

只有全部失败状态的SINGLE均恢复正常且GROUP重现失败，才支持成组加入是这些失败的重要诱因，并允许下一阶段注册完整增径组织对照。否则不扩量、不扫批大小，不把单步正常当作最终成功。保留所有负面结果；真值只用于事后位置轨迹，不参与增径选择。
