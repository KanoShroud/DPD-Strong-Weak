# 补充控制：候选组合的联合IQ评分（不新增定位求解）

仅对阶段B保存的12个盲候选池进行穷举组合诊断，不改变池、不增加Top-K、不读取未见实现。研究问题：峰覆盖排序错误时，固定候选单源秩一增益、同时重新估计两个源的波形系数，是否已经足以改善组合排序？

每个候选的跨站复增益按原rank_one从IQ估计。每个无序位置对构造H_f，计算sum_f ||(I-H_f H_f^dagger)y_f||² / sum_f||y_f||²。这是给定这些增益的联合最小二乘评分，不是同时优化未知增益的完整ML，更不是显式多径新评分。常规投影恒等式不主张创新。

全部组合评分并保存赢家/排序后，才计算真值诊断。用同数据每例32个预定组合与原矩阵pinv直接求解核对；秩退化/近共线采用原矩阵rcond=1e−12回退。没有基于真值筛选搜索集合。统计排名须同时报告候选重复导致的并列性；不据名次挑一个能覆盖真值的Top-K投入正式流程。

目的仅为排除“把峰覆盖直接替换为廉价联合LOS分数就解决”这个简单方案。若失败，不扫描增益初值、波形相干门槛或K值，不称其否定所有联合多径方法。若成功也不跳过阶段B的求解可靠性门。输出不是完整定位性能。
