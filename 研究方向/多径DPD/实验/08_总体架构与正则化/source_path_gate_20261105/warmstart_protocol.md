# 零幅度新增路径的初始化核查

完整SINGLE控制的4个三反射失败（IN101—104）都在原初始增径目标不下降后把新增幅度归零；其内层直接转SLSQP，初始目标与前一模型相同，最终大幅不可行，投影后目标恶化。属于新发现的可核对计算链路，不据此调整反射数量、阈值或拟合精度。

新增路径项为rho·exp(-jωδ)。rho=0时，对δ的导数恰为0；当前尺度采用初始Jacobian列范数下限，容易把该坐标固定在极小尺度。这个现象需要核查，不能直接认定为唯一根因。

有限控制：对全部4个失败前状态以及IN100/L2最后成功增径作正控制，重算同一搜索银行和原最强单条路径。保留选择与投影方向。若原完整幅度初值不降低目标，从新增幅度为0的可行状态，沿同一复幅度方向做已有Armijo系数1e−4、折半、最多20次的线搜索。延迟保持同一个观测候选值；其他原参数不动。

斜率为g(x_zero)^T d，只有负斜率、可行、有限目标和实际Armijo下降才接受非零幅度。先核对零幅度延迟导数、斜率有限差分和原矩阵目标，再交给不变的内层求解器。找不到步长则保留失败，不改阈值或无界重试。单条反射功率上限仍为1。

这只是避免以退化零幅度状态启动未知延迟优化的数值修正，不是新的多径模型、物理先验或论文理论创新。原停止/300轮不变。全部4个失败的同一步达到原PG且非增、正控制不受损时，才允许完整12条SINGLE_WARM诊断；否则停止自动扩展，保留负面。

若完整诊断仍有非正常、精度退化或候选覆盖问题，不能据局部通过解除正式实验锁。不会继续扫描步长参数。
