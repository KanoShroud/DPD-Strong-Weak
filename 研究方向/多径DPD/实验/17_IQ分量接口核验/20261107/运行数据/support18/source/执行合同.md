# 第17轮：真实IQ分量接口核验

用户已允许研究原型暂超3–5秒；最终耗时目标不变。只用09轮的18条冻结开发IQ，四站、双源、全内、0/1/2反射与所有原参数不变。不是独立验证，不运行正式批次。

## 固定实现及判断

1. 从原IQ保留原有效频带，计算六站对完整复跨谱，不加入Hann或分段截断。
2. 两种明确的前端近似：平坦公共谱核；观测估计公共谱核。后者取四站平均带内功率减带外噪声，使用长度ceil(sqrt(F))的频率移动平均（奇数长度），裁为非负并归一化。这是待检验的公共谱近似，不是假定已知发射谱；也不保证剥离信道频率起伏。
3. 在 |d|<=站间距离/c+20微秒 搜索路径对时差。复数正交匹配追踪，8倍原DFT网格，联合重估已选复系数。用2F log(RSS/2F)+3k log(2F)首次不下降停止，最多64分量。BIC形式仅为固定原型规则：跨谱噪声非白、频点可能相关，不声称它是校准检验或一致阶数估计。64是计算保护，不是实际路径数。
4. 不利用真实源数以外的路径数、时延、功率比、波形、符号率；两个输出臂不使用真实参数。保存盲输出后才能评价。
5. 评价端重建同一生成器的路径对标签，仅用于一对一匹配误差、直达分量覆盖和复系数闭合偏离；匹配尺度固定0.25/B，同时报告连续时差误差。此门槛只作接口诊断，不是定位成功门槛。
6. 附加诊断：在真实时差支持上分别用平坦、观测公共核拟合，检查即使消除找峰误差是否仍有复系数畸变。该控制显式标记ORACLE，不进入算法排名。若必要，使用生成器独立源分量核评估模型缺口，但不得传入盲臂。

先跑1条工程/耗时短测，再按同一版本跑18条；总预计超过1小时才交付脚本。运行预算不作为定位器正常停止条件。所有输入无缓冲复制、登记并前后核对SHA；代码和合同快照。若观测接口无法可靠满足原图假设，不自动扫描图阈值、增加路径数或扩大实验；先给出具体缺口。

## 输出边界

本轮是实际IQ前端原型和机制诊断，不是完整定位；不能报告RMSE改善或3–5秒达标。理论结构是否原创与工程接口是否能用分开判断。原公共MP源码不改。
