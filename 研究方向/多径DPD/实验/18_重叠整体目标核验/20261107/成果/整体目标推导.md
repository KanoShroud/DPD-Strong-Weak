# 保留重叠以后，目标究竟变了什么？

## 必须纠正的推进表述

第17轮否定的是独立路径对分量提取接口，不是证明旧IQ多径模型遗漏了相干重叠。原模型y_f=H_f s_f+n_f中，H的每一项已经是该链路直达与反射的复数和；两个源也在同一观测中相加。

因此，上一轮“在整体跨谱或IQ上保留重叠”的建议若被理解成需要另建一个更完整的观测模型，便不准确。旧IQ模型已经具备这项结构。真正尚未解决的是从观测构造并找到正确的源—路径—位置解释，不是再次写出联合最小二乘。

## 1. 单记录跨谱不能只写同源项

令源在各站的完整接收向量为u1、u2，含各自全部反射。在一个频点：

    yyᴴ = u1u1ᴴ + u2u2ᴴ + u1u2ᴴ + u2u1ᴴ
           + (u1+u2)nᴴ + n(u1+u2)ᴴ + nnᴴ。

零均值独立源的异源项在相应总体期望下为零，但有限单记录的实现一般不为零。第16轮路径对图对应理想同源分量接口；第17轮的公共谱稀疏拟合还面临异源项、自相关核与噪声，不应把全部误差归于路径间距。

本轮用原18条冻结生成器分量精确重建实际IQ，并验证上述恒等式。真实分量只参与评价，没有新定位器或新增先验。全频非对角项的范数比约0.8只说明异源项不是机器精度误差；它不等于定位误差、不代表相关峰附近都受同样干扰，也不证明统计平均或原IQ求解不可行。

## 2. 正确的整体投影目标等于原VP

H包含位置、所有链路增益和时延参数，P=HH†为其正交投影。波形自由未知时：

    e_f = min_s ||y_f-H_f s||² = ||(I-P_f)y_f||²。
    e_f = tr[(I-P_f)y_f y_fᴴ]。

因此，把Z_f=y_fy_fᴴ作为输入并采用迹投影，并未增加信息或产生新的估计器。秩不足时仍应使用原投影秩规则，不能通过补足秩改变目标。

## 3. 普通跨谱Frobenius误差不是同一准则

令v=P y、t=||y||²，e=||y-v||²。有

    min_(v∈range(H)) ||yyᴴ-vvᴴ||F² = t²-||Py||⁴ = 2te-e²。

推导：给定方向，最优v沿Py（允许整体相位），其范数平方等于||Py||²；代入即可。单频点在0≤e≤t时该式随e单调，但跨多个频点求和时，它按t和残差大小改变权重，可能改变候选排序。这不是新增物理信息，也不能自动获得原加性高斯IQ噪声下的似然解释。

如果用H diag(P1,P2) Hᴴ代替(Hs)(Hs)ᴴ，则又把单记录的s1 conj(s2)项删除；那是另一统计模型，必须论证快照/总体平均及源谱条件，不能直接当作当前模型的精确重写。

100组复数代数单元及18条实际IQ上冻结LOS状态核验上述等式；后者只评价已存在的H，没有重新优化或挑位置。标准投影恒等式不是原创理论贡献。

## 4. 目前能确定和不能确定的事

- 能确定：原IQ模型能够直接表示路径重叠；单独提取每条路径对系数不是定位的必要条件。
- 能确定：正确的完整跨谱迹目标等价于旧VP，未经论证的Frobenius拟合相当于换权重；不进入新算法实验。
- 不能确定：哪一种整体解释搜索能在同信息条件下显著优于旧逐次增径，同时达到3–5秒；也没有证明所有常规方法都做不到。
- 没有新增RMSE、泛化证据或论文贡献确认，正式批次继续不放行。

## 5. 后续主线应收敛到求解结构，而非再次更换模型名称

允许保留相同的正确IQ目标来提出新求解方法；不必为了创新强造新代价函数。但新增步骤必须真正改变完整解释的产生或交换，而不是只在原错误分支内继续优化。

下一候选须同时明确：

1. 哪些由观测产生的位置/路径组一起改变，如何避免只在已选LOS胜者内部增径；
2. 提案怎样满足非负额外时延、20微秒上界和逐条反射不强于直达，而不使用真实支持；
3. 如何按同一个完整IQ目标比较不同阶数解释，避免以更大模型必然更低残差作为胜出依据；
4. 每次提案与全流程成本如何控制，不能把大量多启动重新命名为联合解释。

这些仍是需要推导的技术缺口。本轮没有足够依据冻结一个新的整体更新规则，因此不自动接入优化器、添加权重或开展更大实验。这里是未通过算法实施准入，不是需要用户再次批准已经允许的原型超时，也不是建议更改场景。
