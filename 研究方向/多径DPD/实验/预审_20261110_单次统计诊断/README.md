# 单次统计可用性预审（非正式定位批次）

这是一项**仅一次固定配置**的四站未知双源多径IQ四阶统计诊断，不是第22轮正式DPD定位性能实验。完整结果见[成果/研究判断.md](成果/研究判断.md)、[成果/统计诊断汇总.json](成果/统计诊断汇总.json)。

复现：本轮对话另提供包含 **statistical_information_gate.py、README、完整原始JSON及研究判断** 的独立一键ZIP。在PyCharm中解压后直接运行该Python文件（仅需NumPy）；默认32768点、固定随机种子20261110、两个预登记窗口256/1024、固定异频四元组，直接写出成果/statistical_information_gate_results.json。已在当前独立环境执行两遍，除墙钟时间外一致。此ZIP属于对话交付件，**不是仓库中已有的脚本副本**，不得仅凭本README声称PyCharm更新仓库即可取得可执行代码。

估计器只接触四站混合IQ，真实信道与源标签仅用于事后评价；未运行双源定位器、没有位置RMSE、没有大批仿真，也未读取冻结common18或修改旧MP-DPD、scene.py。有限分窗FFT样本未证明iid，故四阶k-stat修正的无偏性不能直接继承，单种估计器的失败不是高阶统计路线整体不可能。

当前科研判断：**单个四频分窗统计在此预登记协议下未显示稳定的两个源配对子空间**；优先研究候选几何参与构造的固定低维时滞四阶累积量，不能直接套用旧的单频秩二唯一性证明。
