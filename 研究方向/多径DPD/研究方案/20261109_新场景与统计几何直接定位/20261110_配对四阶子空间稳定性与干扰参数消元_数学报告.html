01 · 稳定性定理：四阶矩阵的谱隙决定能否识别两源

理想跨频四阶矩阵可写为K=Zdiag(γ₁,γ₂)Zᴴ，其中Z的两列是两个源的同源跨频响应。允许γ为负数，必须按照特征值绝对值选取源子空间。

δ = min |非零特征值(K)| η = ‖K_hat − K‖₂，要求 η < δ/2 ‖P_hat − P‖F ≤ 2η/(δ−η)

这个经典Hermitian扰动界说明：若四阶矩阵估计误差接近最弱的源特异谱强度，原本精确可辨识的两个源在有限样本中仍可能不稳定。

02 · 为什么弱源与信道接近共线都很困难？

源强度

若源的四阶统计系数很小，最小非零特征值可能很小。对iid独立创新线性调制，四阶统计项通常按接收功率平方缩放；但有限样本方差还取决于强源、噪声及统计滤波。

几何通道相似

若两个源在锚频和工作频率的四站通道方向都几乎一致，跨频配对子空间的两列难以区分。满秩但近共线并不保证抗噪。

若各源通道列归一化： δ ≥ min(|γ₁|,|γ₂|) · (1−|ρ_anchor · ρ_work|) ρ_f = h₁(f)ᴴ h₂(f)

代数检查：δ=0.11555，理论下界0.09827；加入谱范数0.01618的Hermitian扰动后，实测子空间投影误差0.09844，严格上界0.32558。只检验矩阵代数，不是6dB IQ性能。

03 · 从统计误差走向双源位置错误概率

对于前轮C0的完整双源位置profile准则，如果所有离真实双位置至少ε的错误位置与真实统计子空间之间具有正间隔Δε，那么：

eP = [Σ_k w_k ‖P_hat,k − P_k‖F²]^(1/2) eP < Δε/2 ⇒ 任何全局最优解的双源位置误差 < ε

将上一节的子空间误差界代入，即得到“统计估计误差→位置错误”的条件充分性公式。但当前尚无实际IQ可计算的统计误差常数，也没有可用的Δε数值下界；不能据此宣布定位精度。

04 · C2：两路源的四阶统计系数可以精确消元

保留同一对候选位置及其全部合法有限反射信道，直接将观测四阶矩阵与物理预测矩阵拟合。给定位置与信道参数，未知每个源的四阶统计系数γ₁、γ₂是线性参数：

min_{γ real} ‖K_hat − γ₁ z₁z₁ᴴ − γ₂ z₂z₂ᴴ‖F² G_rs = |z_rᴴ z_s|² b_r = Re(z_rᴴ K_hat z_r) γ_hat = G⁻¹ b profile RSS = ‖K_hat‖F² − bᵀ G⁻¹ b

因此每频率的两个源统计系数只需解2×2实线性方程。它避免了将源谱系数加入高维外层优化，但不能消掉复信道增益、反射时延与位置本身。C2可作为利用统计幅度信息的备选目标，原C0仍是有完整两源覆盖约束的主要理论准则。

代数检查：γ真值[-2.1,0.35]，解析最优解约[-2.09884,0.34961]；最优残差0.20927不高于代入真值时的0.21193。此消元是成熟最小二乘方法，不是独立原创。

05 · 对于源特异跨频方向：复增益还有一个小矩阵消元接口

若能由跨频四阶配对子空间获得某源的各站方向v(f)，在候选位置和每条反射时延固定时，四站物理信道对每站LOS与反射的两个复增益是线性的。

H_m(f) = exp(−i2π f τ_m(p)) [a_m + b_m exp(−i2π f δ_m)] v_m(f) H_ref(f) − v_ref(f) H_m(f) = 0 ⇒ A(p, δ; v) · g = 0 M=4, F=18：A为54×8复矩阵

在‖g‖₂=1的无约束情况下，最小残差为σmin(A)²；但真实物理模型仍要求LOS非零、合法反射功率/时延等约束。若SVD给出不合法复增益，它只是合法模型残差的下界，不能直接当成定位决策。

独立代数核验：真位置、真反射时延下的交叉关系残差约1.51×10⁻¹³；某个错误位置固定相同时延时的最小奇异值约1.81。该结果不证明错误位置在自由重选反射时延后仍不能解释数据。
