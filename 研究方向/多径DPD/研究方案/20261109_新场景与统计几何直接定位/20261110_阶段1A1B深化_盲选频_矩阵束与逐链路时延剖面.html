01 · 1A：不输入真实符号率的异频选取

用公开频段内预先随机生成的锚频、工作频率间隔和异频偏移量，构造满足和频守恒的四频组。对于任何固定、未知的离散循环频率集合，若选择参数具有连续密度，则落入低阶谱奇异子流形的概率为零。

f_k = f_a + k·Δf ν = (f_a, f_k, −f_a−ε, −f_k+ε) Σ ν = 0 K_off = Z_left · Γ · Z_rightᴴ

在相关循环频率集合局部有限时，单次泛型选频还能获得严格正的数学保护距离。但若离散采样导致无限循环频率模采样率密集，就不能据此推断存在统一有限样本保护间隔。

最重要的限制：避免精确低阶谱碰撞并不等于可靠估计四阶多谱。单次FFT四阶乘积仍高方差；需要多维平滑或正确的时间域累积量估计，并明确统计误差和频率积分偏差。

纯算术检查：8个间隔12.5 kHz的左频率样本对应80 μs别名周期，可满足当前条件性交叉时延上界；右侧偏移463.5 kHz。已知循环集合仅用于检查选频，绝不作为算法输入。这些频点不代表已获得四阶谱定位精度。

02 · 1B：一个很小的矩阵束就能提取条件源方向

准确的四阶左子空间由同一个源在两个频率上的Kronecker方向张成。任意两份泛型基向量重排后，形成具有共享左右通道因子的矩阵。把这些矩阵压缩到Q×Q后，构成同时对角化矩阵束。

M_t = H_anchor · diag(c_t) · H_workᵀ B_t = A · diag(c_t) · Bᵀ B_1 B_2⁻¹ = A · diag(c_1 / c_2) · A⁻¹

在满秩、非零参考系数及不同特征值条件下，可从矩阵束特征向量恢复各源的跨站通道方向。Q=2只需要2×2核心运算；对一般Q≤M可保持Q×Q接口。无需恢复发射比特。

稳定性必须经过两个关口：四阶统计矩阵的源奇异值间隙和矩阵束的特征值分离程度。前者通过不能自动替代后者。

03 · 一条反射时的条件低维信道剖面

从内部源方向消去逐源共同频率尺度后，使用各站相对参考站的信道比值。参考站LOS增益归一化，剩余响应可表示成1个直达复系数和1个反射复系数。

r_m(f) = H_m(f) / H_ref(f) u_ref(f) = 1 + c·exp(−j2πf δ_ref) x_m(f;p,c,δ_ref) = r_m(f) exp(j2πf·TDOA_m(p)) u_ref(f) = A_m + B_m·exp(−j2πf δ_m)

对固定候选位置、参考站复反射比和参考站时延，其余3站的各自反射时延彼此独立。每站固定时延时，A_m和B_m可以严格用两列复最小二乘消去，剩余是一维延迟搜索。

E_m(δ)=min_{A_m,B_m}||W^½ [x_m − F_m(δ)·(A_m,B_m)]||² F_m(δ)=[1, exp(−j2π f δ)] J_ratio(p,c,δ_ref)=Σ(m≠ref) min_δ E_m(δ)

这是条件比值目标的精确拆分，不是原始四阶位置准则C0/C2的等价性证明。 非零LOS、参考频响不为零及全频共享复增益仍必须成立；无约束增益LS若违反物理条件，只能视为松弛下界。

05 · 下一步两道门槛仍然存在

  1. 1A：建立同符号率未知双源下可由单条混合IQ计算的真正四阶累积谱估计器，给出非Oracle偏差/方差、可用频率维数和计算量。
  2. 1B：量化带噪矩阵束方向误差；检验一维延迟剖面能否提供物理合法的候选及安全筛选，再以原混合统计C0/C2作最终双源联合判别。
  3. 扩展接口：保留一般Q与L_max，但第一版先解决Q=2、L_max=1，不强制同时自动判断未知阶数。
当前科研决定：继续现有统计—几何DPD主线；不依赖真实符号率/源标签/反射真值，不运行第22轮IQ定位调参，不将条件低维线性代数误称为已经完成的精准定位创新方法。
