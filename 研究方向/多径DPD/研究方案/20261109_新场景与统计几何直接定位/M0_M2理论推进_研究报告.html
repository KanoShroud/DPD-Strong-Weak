结果证据级别直接定位研究意义

02 · 定理T1：相位补偿不产生自由低秩位置分数

对任意候选位置r及四频元组，用酉对角矩阵D_r(f)补偿各接收站的几何时延。补偿后的张量是原四模统计的逐模可逆变换，CP秩、最优无约束秩Q近似误差和各模展开奇异值全部保持不变。

C_r = C ×₁D_r(f1) ×₂D_r(f2) ×₃D_r*(f3) ×₄D_r*(f4) rank_CP(C_r) = rank_CP(C) min_{rank(X)≤Q} ||C_r−X||_F = min_{rank(X)≤Q} ||C−X||_F

这是一个结构性No-Go定理，不应通过第22轮短测或频带数调参挽救。若使用有限子带聚焦，必须把近似误差与位置合法物理模型的差异明确分开。

03 · 定理T2：未知共同符号率不代表未知的无限循环统计维度

对于两个独立同符号周期T的未知源，如果源脉冲具有理想带宽(1+β)/T、0<β<1，则包括站间二阶矩和伪协方差在内的时相变化，只可能含有直流与±1/T三个循环频率。异址LTI多径不增加源频带，不会创造额外的二阶循环谐波。

R_ab(t) = r_{ab,−1} exp(−j2πt/T) + r_{ab,0} + r_{ab,1} exp(+j2πt/T) C̄4 = ⟨M4⟩ − Σpair Σ(k=−1,0,1) r_ab,k · r_cd,−k

这提供了不先分离源的有限维统计校正思路。**但是**真实有限长度截断RRC不再严格带限；二阶循环线也可能被两源相位和传播增益抵消。应先证明可观测的非零循环特征条件，不能从生成器提供真实符号率。

04 · 定理T3：一条混叠记录的有限统计切片可以有一致性

已知真实周期的条件定理

对固定数量的二阶与四阶乘积，如果高阶矩存在、统计序列具有有限依赖半径D或可求和协方差，则样本矩方差可按(D+1)/N缩小。以已知周期进行三谐波校正，理想情况下四阶累积量误差为Oₚ(√((D+1)/N))。

未知周期的关键精度门

用从整个混合IQ估计的角频率ω̂代替真实ω₀时，需要N|ω̂−ω₀|趋于0才能保持一致性；若要维持根N估计误差，则通常需要约N⁻³ᐟ²的频率精度。是否满足非零循环线和谐波回归条件仍待证明。

不能混用两个理想假设：严格带限RRC通常不是有限时域支持；有限截断RRC可以具有有限依赖，却会引入更高阶循环谐波泄漏。要么证明谱尾引起的偏差足够小，要么扩展有限校正谐波，不能同时默认二者完全为零。

05 · 定理T4：有限带宽LOS-TDOA的条件稳定界

对于已识别源的跨站信道比值H_m(f)/H_1(f)，任何源共同未知频率滤波因子自动消去。若单反射幅度比r_m、r_1都小于1，则反射因子1+a exp(−j2πfδ)的相位总处于不含原点的圆盘内，绝对值≤arcsin r。

|τ̃_m−(τ_m−τ_1)| ≤ [arcsin(r_m)+arcsin(r_1)] / (π B) r_m=r_1=0.5, B=12.5MHz ⇒ |时差误差| ≤26.67ns，距离差尺度≤7.99m

这一界不要求先恢复反射时延，但必须已得到可靠、连续解缠的源特异信道方向。7.99m是站间距离差尺度，不是双源位置RMSE，也不包含从混合IQ估计方向的噪声误差。

06 · 定理T5：统计精度必须转化为错误位置判别间隔

对某一有限维可估统计向量c及双位置假设p，令M(p)为同一组LOS几何与合法反射参数允许的全部理论统计。直接位置准则是统计观测到该物理模型集的距离，而不是某个自由CP分解的拟合误差。

D_c(p) = inf_{z ∈ M(p)} ||c−z|| Δ_ε = inf_{dist_permutation(p,p*)≥ε} D_c(p) 若Δ_ε>0 且 ||ĉ−c||<Δ_ε/2，则全局最小化的位置误差<ε P(位置误差≥ε) ≤ 4 E||ĉ−c||² / Δ_ε²

决定性未证条件：我们尚未证明四站双源多径模型在选取的有限统计切片下确实存在正间隔Δ_ε。若模型允许过度自由的源谱/每频通道，这个间隔可能为0。下一步需要用物理有限多径和联合跨频约束证明或否定它。

07 · 研究路线与下一个门槛

  1. 在原始混合IQ上找到至少一种非零、可测的公共时钟循环线；构造未知符号率的统计估计充分条件及截断RRC偏差界。
  2. 选取有限个二阶/四阶时滞与跨频切片，使统计向量具有可证明的有限记录误差界，不必实现巨大四阶频率张量。
  3. 证明合法双源位置模型集对错误位置存在正统计间隔，或者明确给出几何/统计反例；先分析同路线可修复的原因。
  4. 理论通过后，才设计直接以两个位置联合优化的DPD方法及最终有限样本误差和运行时间验证。
决策：继续主线，不切换到B1—B4，不启动仿真调参。数学方面已有进展，但真实混叠IQ→源特异跨站统计→两个位置的全部环节尚未闭合。
