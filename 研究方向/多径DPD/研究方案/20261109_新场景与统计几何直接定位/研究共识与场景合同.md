## 一、不可更改的核心要素

1. **多站：四个空间分离且同步的接收站**（原二维6 km方形部署）；不靠增加站数或移动阵列提高可辨识性。
2. **单天线：每站仅1个RF接收通道**；不可将Hu 2024/N23的嵌套阵列空间虚拟孔径当成已有硬件能力。
3. **双源：同时存在的两路同频、相互独立但全部数据和符号未知的源**；同一调制类型、同一标称符号率，不能通过人为设置不同循环频率预先分源；源数2可作为公开问题定义。
4. **多径：具有实际非零反射，位置同时决定四站LOS相对传播时延**。反射存在状态、具体延迟、反射增益及源—径归属均未知，不能给算法任何真实路径支持/反射点/真实波形。
5. 两源及接收站在固定二维几何内，允许源标签置换。目标是**同时完成两个源的精准直接定位**，不是先求两个完整信号再跑一个旧定位器。

### 2.1 旧BPSK是否被利用？是否要换成QPSK？

旧 `代码/mp_dpd/models/scene.py` 生成实BPSK符号和RRC成形，接收端叠加复信道与Gaussian噪声；`mp_dpd` 的确定性VP以每频率任意复源谱消元，**没有使用伪协方差E[s²]或已知BPSK星座、符号率约束**。因此不需要为了避免现成非圆算法而将主场景改成QPSK。

但在恒定载波参考及实脉冲条件下，理想BPSK基带通常非圆；新算法若显式调用二阶非圆统计，就必须公开“非圆未知源”假设，并以QPSK对照证明边界。对一般独立非高斯源的结论不能从BPSK实验自动推广；反之QPSK亦可以有非零四阶累积量。

### 2.2 旧实验究竟有没有刻意设置两源功率差？

**没有在当前四站多径主生成器中设置固定全局强弱源功率差。** 旧 `scene.py:layouts` 和 `inside_scene.py:layouts` 分别按各源的四站平均自由空间功率增益独立计算发射功率，使两源跨站平均LOS SNR均为6 dB；不存在统一+3/+6 dB源功率差。由于距离不同，单站内天然有近远效应和源功率比波动。其他研究方向/早期其他协议下的“强弱源”不能作为这一冻结银行已施加功率差的证据。

此次3/6 dB仅用于检验联合统计法在强源掩盖弱源下的稳定性，不作为证明新方法必要性的唯一依据，也不应第一阶段强制添加；四阶累积量幅度常随信号功率平方变化，过大功率差反而使弱源很难估计。

### 2.3 站点间距、20 μs与公开3 μs：不同物理量

- 站点边长6 km对应真空传播时间约**20.014 μs**；对角8.485 km对应约**28.304 μs**。这限制几何LOS站对TDOA范围，**不限制未知反射相对LOS的超额时延**。
- 单次经散射点`r`从源`p`到站`b`的额外时延：
  `δ=[|p-r|+|r-b|-|p-b|]/c`。若对散射点区域无约束，站位本身不提供有限的普适最大δ。
- **条件性物理解释**：假定研究区域的单次局部反射来自离发射源或对应接收站**400 m以内**的散射物体，不提供具体物体坐标。三角不等式给出 `0≤δ≤2R/c≈2.67 μs`；于是可公开采用比该保守上界稍宽的**3 μs搜索区间**。生成器必须确保其单次传播几何与此相容，否则不能把3 μs写成由模型保证。
- 3 μs不是由ITU/3GPP“直接规定”的普遍数值。第14轮的20 μs借自ITU-R M.1225中的环境测试信道尺度，且事实已证明仅缩至20 μs不能救回盲长尾；3GPP TR 38.901典型RMS delay spread不是硬最大时延。两类模型不得混称。标准入口：<https://www.itu.int/dms_pubrec/itu-r/rec/m/R-REC-M.1225-0-199702-I!!PDF-E.pdf>、<https://www.itecspec.com/3gpp/38.901/s/7.7.3>。
- 若后续不采纳“局部单次散射/有限散射区域”类别，则可退回公开20 μs或采用其他**事先有环境依据**的传播时延尾界；不得凭当前真值分布1.5 μs事后选择上界。
- 过短的反射限制不意味着接收站间LOS时差也变短；观测窗和信号生成前导/尾部要覆盖可达LOS时差、最大反射附加时延和滤波脉冲支撑。

### 2.4 碰撞分层，但绝不选择性剔除

设置两套不同用途的样本体系：
- **自然生成集（主结果）**：逐源—站链路独立抽取反射额外时延，不用碰撞拒绝采样，不筛难例；所有实现计入双源RMSE、错误长尾与真实端到端成本。
- **预先固定的碰撞压力集（边界）**：针对轻度/中度/严重碰撞及跨源重叠、LOS—反射近接、原同中心RR≈DD机制进行控制压力；与自然样本分开报告，不将人为配比简单相加当真实环境失败率。
- **评价端标签**：对同源站对`i,j`，`χ_{ij,q}=B|δ_{iq}-δ_{jq}|`，表征RR与DD之间的无量纲时差间隔；可在实验协议锁定`χ<0.5`、`0.5≤χ<1`、`χ≥1`等区间并统计每条观测落入近碰撞区间的站对数量。必须另计跨源及RD/DR路径对碰撞和有限带宽相关性；χ单独不是全部混叠严重度。
- **不泄漏**：这些χ、真实路径位置、分层标签只在保存盲定位决策后产生；不参与候选保留、特征选择或参数调优。总体自然分布结果和分层结果同时发布，不删除极端长尾。

## 三、首选研究方法：跨站二阶—四阶统计与几何稀疏信道**联合双源直接定位**

**状态：数学研究候选，尚未证明可行。** 不再将“高阶统计DPD”或“IVA＋传统定位”作为创新标题。创新性待证对象应是：四异址单天线、两未知同频独立源、局部单次稀疏反射下，**统计—几何耦合消除源身份/位置歧义**所新增的数学结论和估计方法。

### 3.1 观测与候选参数（禁止前置完成源分离）

```
y_m(t)=Σ_{q=1}² [g_mq,0 s_q(t−τ_m(p_q))
             + I_mq g_mq,1 s_q(t−τ_m(p_q)−δ_mq)]+w_m(t)
τ_m(p_q)=||p_q−b_m||/c
I_mq∈{0,1}, 0<δ_mq≤3μs，反射复杂度每链路≤1
```

在频域，两个源的4站响应向量`h_q(f;p_q,η_q)`共享同一源谱，但每源—站链路的反射增益/时延未知。真正待估的是`p=(p_1,p_2)∈R⁴`，其余量为干扰参数，最终不需要估计发射比特或完成全部盲分离。

二阶互谱：
`R_y(f)=Σ_q P_q(f)h_q(f)h_q(f)^H+σ² I_4`。
当两源同谱或具有近似相同功率时，单频率二阶模型具有源空间旋转/分解歧义；但这一线性代数歧义不自动等于加入跨频稀疏几何后仍不可辨识。

独立源的四阶交叉谱（取`f4=f1+f2−f3`的有效频率四元组）在合格的平稳/循环条件下具有示意形式：
`C4_y(f1,f2,f3)=Σ_q T_q(f1,f2,f3) h_q(f1) ⊗ h_q(f2) ⊗ h_q*(f3) ⊗ h_q*(f4)`。
独立Gaussian噪声的**总体**四阶累积量为0，有限样本估计方差却可能很大。未知RRC成形导致的循环统计与有限窗偏置必须在正式估计模型中处理；不能直接把普通零时差峭度或单次FFT当成已知的无偏四阶谱。

### 3.2 特别值得证明的“源空间—位置”桥梁

1. **源因子唯一性**：四阶张量的两个源分量在一般位置与非零有效四阶统计条件下，何时能在置换/复尺度歧义之外辨别？若使用4模CP分解，须逐项检查Kruskal类型的列秩与张量阶数条件，而不是引用Hu的站内嵌套阵列自由度。
2. **跨频源标签一致**：固定频率得到的两列通道向量，能否通过共同源四阶谱耦合或几何有限时延约束一致标识？不能套用Xie在长语音和多时段协方差下的已证明条件。
3. **逐源共同频率尺度消去**：如果识别的`h_q(f)`只差一个未知共同复函数`d_q(f)`，考虑跨站比值`h_mq(f)/h_1q(f)`消去该不确定性，研究它在一条自由反射条件下能否唯一确定四站LOS TDOA，进而唯一定位`p_q`。零点、近抵消、共同滤波/时移和站点参考比值病态须明确处理。
4. **位置有效信息**：对两个二维位置共4个连续参数，在正确剔除复增益、δ、源谱/四阶谱等干扰自由度后，构造有效雅可比或Schur补，给出局部满秩条件；同时给出至少一种全局错位的等价/近等价反例或相应排除条件。局部秩满不等于全局正确。
5. **高阶弱源稳定性**：四阶项在接收功率差为ΔdB时可能出现约2ΔdB的统计强度差；二阶和四阶如何有原则地加权而非事后调λ？在有限IQ估计上考虑相关时间、有效样本、脉冲与延迟窗口。
6. **最终位置估计而非分离**：若上述成立，再定义共享`p_1,p_2`的二阶/四阶加权残差，内部有限维消元源统计参数和反射系数；输出仅两位置。不得要求先完整恢复波形SIR、全部传播时延或每源固定标签。

**创新性要求**：不得以“高阶累积量抑制高斯噪声”“张量分解提高分辨率”“Taylor补偿离网格”或“几何约束IVA”单独声称原创，这些已有Hu 2024、Chai 2025、Li 2023、Xie 2020及更早文献先例。需要证明本四站同频双源未知多径条件下新增的**可辨识信息、连续位置估计法及其计算性**。

## 四、理论先行的硬退出条件：禁止第22轮变成小样本修补循环

**本次仅批准文献/公式审查和研究文档构建；没有批准新算法实现、重生成、冻结IQ短测、参数扫描或正式扩量。**

### Gate M0：信息/模型自洽

- 二阶和四阶统计是否能从**同一段真实四站有限IQ**在允许未知波形条件下定义、估计？考虑RRC成形、循环平稳/有限窗、时间移位和短记录，不假设已知符号率或无限多独立快拍。
- 不允许不加说明使用独立源高阶统计为非零、足够的循环差异或站内嵌套阵列。
- 如果统计张量只因源分离预处理给出额外波形信息，应判为不符合DPD主问题。

### Gate M1：位置可辨识

- 先在总体统计、LOS-only模型推导源身份与几何位置的唯一性边界；包含完整自由标度、置换、滤波歧义及反例。
- 再进入每链路0/1未知反射及公开δ≤3μs的模型，明确源—路径混淆、近碰撞和相同站谱条件。
- **不得只写“generic identifiability appears plausible”**。必须有完整明确的命题、假设及数学证明，或找到可复核的否定构造。若无法区分位置与自由统计谱参数，则主线停止，不进入大批仿真。

### Gate M2：可计算统计与定位准则

- 不允许先分离再定位，设计直接输出`(p1,p2)`的连续位置目标或位置搜索＋合法精修；提出源谱/反射参数的有限复杂度消元。
- 比较与现有VP目标是否只是重参数化/等价；如无新增可观测信息或新增约束，不能形成新论文主张。
- 推导计算量与统计估计方差的量级，至少说明为什么32768样本足以值得进入算法实验；可比较8192/65536，但不能先靠它们调收益。

### Gate M3：**完成M0—M2后才另行审批数值实验**

- 之后的模拟只用于检验已冻结的数学预测，并以双源位置RMSE、严重错位尾部、两源都成功比例和端到端耗时为主指标。
- 新自然环境集与压力集分离，所有数据与方法使用同一IQ；既有`common18`不删除、不用于新参数拟合或新生成器的有利挑选。
- 普通IVA-SIR、信道NMSE、四阶拟合残差、CCA特征值单独变好，不代表本DPD通过。

## 五、备选研究路线：保留，但不能同时实现一堆新算法

**B1：多块二阶协方差＋宽带几何联合直接定位。** 只有在源的短时功率轨迹具备非退化多样性（两个源始终同时工作，不能给已知纯源时隙）时才可能借联合对角化/统计分解打破同谱歧义；对平稳同功率两源这一条件可能完全失效。必须先给出统计多样性的物理解释与可辨识条件，再研究输出位置的联合目标；其创新性需要超越已有非平稳BSS和几何约束协方差分解。

**B2：几何锚定的共同子空间 / Delay-locking 位置检验。** 只考虑候选位置驱动的四站IQ对齐与可检验共同视图，绝不假设共址多阵元的整齐两路径相对时延或用户前导。需要证明错误位置不普遍产生同样CCA高相关，并证明观察矩阵的实际秩条件。否则停止，不进行独立完整源恢复。

**B3：参考源自由的全站对互谱＋受约束多源统计子空间DPD。** 借鉴Li 2023/Chai 2025的直接几何搜索和多维频率融合，但不能使用Chai的无多径参考源/其源谱归一化，也不能把单源PARAFAC唯一性定理直接套给双源；必须在混合二阶结构及有限多径类别下另证源分量的分解与位置唯一性。若必须在算法中预先给一条源独立参考通道，则不满足本合同。

**B4：几何约束源—径联合测度估计。** 只有B1—B3及主线的理论条件不成立时，才回到连续共同源结构与位置—径联合选择，必须比第10—21轮旧VP/贪婪增径具有真正新的信息约束、可证筛选或更好的可辨识类别，而不能再次成为“多候选＋更大K＋更多SLSQP”。

**退出/转向规则**：每条路线按`观测假设→总体模型→歧义反例→位置可辨识→可计算性`五步书面审查。主线数学硬门不通过，优先转B1（如果业务可支持功率轨迹多样性）；不支持则评估B2/B3，再考虑B4。不把理论未通过的模型靠反复冻结短测救活。

## 六、近邻证据及已经失败的旧路线

- 69篇近邻矩阵：[近邻文献精读矩阵.xlsx](../../文献/近邻精读_20261106/近邻文献精读矩阵.xlsx)，[综合结论](../../文献/近邻精读_20261106/精读结论与下一步.md)。新增原文Hu 2024、Chai 2025、Li 2023、Delay-locking、IVA、Coupled Frequency等均按真实模型条件核对。
- N02 Xia 2021：真实同频未知双源多径近邻，空间谱/聚类已有先例；N17 Xia 2024：不同循环频率可分源，**不允许将不同符号率作为我方主创新必要条件**。
- Li 2023（IEEE IoT J. doi:10.1109/JIOT.2022.3228810）：**单源**分段PARAFAC-DPD，不应把时间分段指标误当两个发射源；Chai 2025（Sensors doi:10.3390/s25164967）：**单源**全站对互谱及Taylor，但第5页式(7)—(12)依赖无多径参考信号。
- Hu 2024（Sensors doi:10.3390/s24123801）：多源非高斯FOC-DPD，但每站为**嵌套多天线阵列**，其虚拟孔径增益不能直接作为四个单天线站的贡献；N23高阶QAM阵列＋双原子范数也限定高阶统计“本身”的新颖性。
- Ibrahim & Sidiropoulos 2020 Delay-locking：**共址多天线**、不同源相对延迟/满秩、绝对对齐讨论涉及前导；Xie等2020跨频块张量需要多段协方差，Luo等2022 IVA主要测BER/分离，不给直接位置唯一性。
- 第12轮[独立性边界](../../实验/12_独立性统计准入/20261107/成果/理论边界.md)：仅消除源混合不消除逐源未知滤波与几何歧义；普通四阶统计混合循环相位会产生假依赖。
- 第17轮[真实IQ分量接口](../../实验/17_IQ分量接口核验/20261107/成果/机制分析.md)：同序号RR与DD可高度重叠，独立提取路径对复系数数值病态。
- 第20轮[研究判断](../../实验/20_分支可区分性核验/20261109/成果/第20轮实验结果与科研判断.md)、第21轮[研究判断](../../实验/21_候选覆盖与条件收敛核验/20261109/成果/第21轮结果与科研判断.md)：完整池近真候选存在，而旧6点/少位置对盲压缩丢失、固定位置路径条件优化未形成充分收敛分支对照。不得继续以更大K、更多候选和更多迭代为主线。
- 第14轮[公开记忆结论](../../实验/14_公开信道记忆核验/20261107/成果/结论与推进判断.md)：20 μs缩短未解决主要盲失败；此次3 μs必须有**额外明示的局部散射环境假设**，不能反过来声称“仅因缩窄窗口产生新方法”。
- 原始冻结实验、前21轮报告、数值长尾证据均继续保留；新模型与旧实验不得直接混合成一个RMSE表，也不应单方面按新物理条件修改旧近邻复现实现。
