# G10-R2：共同目标、两个候选与可检验的理论性质

本文件属于实现规格，不是已完成的创新证明。AP/NOMP均为本场景适配版本。下面恒等式与局部结论用于定义机制检验，实际收益由开发与独立实验确定。

## 1. 共同模型与波形消元

四站频域观测为 $x_f=A_f(P)s_f+n_f$，$P=(p_1,p_2)$ 包含四个实位置坐标，$s_f\in\mathbb C^2$ 是两个源未知的频域系数。$a_l(f,p)\propto d_l(p)^{-1}\exp[-j2\pi f d_l(p)/c]$；响应按站维归一化的公共比例吸收进逐频未知系数，不对混合IQ逐站归一化。沿用匹配的基带模型，不增设RF载波相位或未知站间复增益。

设 $E=\sum_f\|x_f\|^2$，等方差白噪声下的归一化集中最小二乘目标为

$$s_f^*(P)=A_f(P)^\dagger x_f,\qquad J(P)=E^{-1}\sum_f\|(I-A_f A_f^\dagger)x_f\|^2.$$

外层只有四个位置参数；每次评价仍需逐频求系数，不意味着波形估计计算消失。响应局部满列秩时，令 $r_f=x_f-A_fs_f^*$，利用 $A_f^Hr_f=0$ 得

$$\partial_{\theta}J=-\frac{2}{E}\operatorname{Re}\sum_f r_f^H(\partial_{\theta}A_f)s_f^*.$$

系数导数项在一阶梯度中因最小二乘正交性抵消，但不能据此忽略Hessian中的参数耦合。数值实现使用已经核验的小矩阵LS及自动微分，新增有限差分、SVD参考和排列不变性检查。秩变化处不能直接套用满秩微分结论。

来源：Chen/Hudson/Yao (2002), DOI [10.1109/TSP.2002.800420](https://doi.org/10.1109/TSP.2002.800420)；O'Leary/Rust (2013), [变量投影§1—2](https://www.cs.umd.edu/~oleary/software/varpro/varpro.pdf), DOI 10.1007/s10589-012-9492-9。消元本身是已有工具。

## 2. AP候选：延迟单候选决策

固定初始第一源 $\hat p_1$，候选 $q_i$ 的原目标为 $C_i=J(\hat p_1,q_i)$。对候选独立运行同一精修算子 $\mathcal R$，记 $F_i=J(\mathcal R(\hat p_1,q_i))$、$\Delta_i=C_i-F_i\ge0$。

若初始 $C_a<C_b$，则精修后 $F_b<F_a$ 当且仅当

$$\Delta_b-\Delta_a>C_b-C_a.$$

这给出可直接核验的排名翻转条件，而非假定粗谱最高峰必定对应最佳精修结果。在局部正定二次近似中，无约束联合Newton步的预测下降为 $\tfrac12 g_i^TH_i^{-1}g_i$；不同候选的梯度、曲率及交叉块会导致不同改善。真实目标非二次且有边界，实际下降必须由代码记录，不用预测值替代。

多候选集合包含单候选、共同分支采用相同起点与完整精修规则时，$\min_{i\in C_5}F_i\le F_1$。此性质针对目标值，不保证更低位置误差或等耗时优势。Top5只从同一个条件谱选取，不改变第一源、不利用真值；记录每分支初始/终止位置、目标、退出与选中排名。四格是AP短流程消融，不等同原论文完整AP；原充分AP作为冻结参考另列。

## 3. NOMP候选：固定残差更新与共同位置更新

原NOMP先在当前位置重估所有系数，再把除目标源外的估计贡献暂时固定，执行单源Newton更新；下一次外层循环重新拟合。因此它并非完全不重估波形，但一个局部更新方向并不是完整位置目标的精确块最小化。

把固定其他贡献后的局部目标记为 $Q_j(q\mid\bar P)$，仅重估第 $j$ 个源系数。在起点使用完整LS系数时，$J(\bar P)=Q_j(\bar p_j\mid\bar P)$；对任一候选位置，完整重新拟合可得到 $J(P(q))\le Q_j(q\mid\bar P)$。这解释了固定贡献目标可作局部替代目标，但其曲率与完整目标不同。实际代码还用完整 $J$ 验收，保证接受的步骤不使目标增加。

理想局部二次模型设 $H=\begin{bmatrix}H_{11}&H_{12}\\H_{21}&H_{22}\end{bmatrix}\succ0$。若每块精确最小化，一次交替扫描满足

$$e_2^{(t+1)}=H_{22}^{-1}H_{21}H_{11}^{-1}H_{12}e_2^{(t)}.$$

谱半径 $\rho$ 越接近1，渐近交替收敛越慢。联合Newton在这个理想二次模型中一次求完整方向；真实非线性问题仍需迭代，BFGS也不是精确Newton。该关系是用于解释耦合的局部参照，不直接宣称当前残差式NOMP具有同一收敛率。

代码在算法结束后计算共同起点的真实集中目标Hessian。仅在正定时报告上述理想 $\rho$，否则明确记为不适用，不人为修正矩阵来制造符合理论的结果。该诊断不进入算法控制且耗时单列。

块迭代理论参考：[Bindel, Matrix Computations, §4.2.3](https://www.cs.cornell.edu/~bindel/class/cs6210-f16/lec/2016-11-07.pdf)。联合优化相关先例包括[OFDM-ISAC NOMP §III-B](https://arxiv.org/html/2411.03191v1)、[QNOMP期刊版 §III-B/D](https://doi.org/10.1109/ACCESS.2025.3645128)；两者并非本四站未知宽带波形场景的直接复现。新增联合精修是候选适配，不把通用联合思想称作首次提出。

## 4. 计算成本与结论边界

记频点数为 $F$、站数为 $L$、初始网格点数为 $G$、源数为 $K$、AP候选数为 $B$。固定 $K=2,L=4$ 时一次全图评分随 $FG$ 增长；一次联合LS/梯度计算随 $F$ 增长（一般LS小矩阵部分为 $O(F(LK^2+K^3))$），还需计入位置响应及导数。AP四格共同两次全图搜索，后续成本由 $B$ 和每分支精修调用决定；NOMP扩展保留原前缀，只增加循环或联合局部调用，不添加全域搜索。

以实际目标/梯度、频率—响应点、全图扫描和迭代调用核对复杂度，而不把相同迭代数视作等成本。完整时间包含IQ预处理、传输、搜索、精修；预热和事后诊断单列。1/2/3/5秒取当时已经可用的最优原生目标解，不以真值选时刻或强行中断。

推导说明机制与条件；统计实验检验是否实际提高20m可靠性、RMSE或可靠性—成本取舍。新增样本不用于重新挑选参数。二者可能只有一个有效，也可能都无额外收益，不自动组合或添加控制模块。
