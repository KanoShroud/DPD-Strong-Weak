## 代数与精度

`q_f(p)=a_f/||a_f||`, `a_l=exp(-2πif d_l/c)/d_l`，所有数值用FP64/complex128。公共系数吸收到逐频未知源系数。K≤2联合LS使用1×1/2×2 Gram公式，近秩亏频点回退SVD；需对照原SVD残差、梯度和批处理。加速不抽频、不截短记录、不改变目标。

SBL: `C_f=νI+A_f diag(γ) A_f^H`, `ν=1/N`。最小化`mean_f(logdet(C_f)+x_f^H C_f^-1 x_f)`。固定点更新为

`γ_q(new)=γ_q sqrt[ sum_f |a_fq^H C_f^-1 x_f|² / sum_f a_fq^H C_f^-1 a_fq ]`。

计算与小字典直接逆逐项对照；若新γ使精确证据增加，用对数γ插值回退，仍不能接受则保留原状态。不能把对位置的联合LS改善替代SBL原生证据改善。

SBL每5轮检查一次离网位置；连续两次检查满足证据相对变化小于1e-5、γ的L1相对变化小于1e-2、最大位置变化小于0.05m时停止。默认300轮仅为迭代安全上限，命中时标记ITERATION_LIMIT，另做延长核验，不当作收敛。无噪声盲搜诊断删除观测中的噪声，但保留求解器的加载/正则强度；它用于暴露网格及适配问题，与零噪声代数恒等式测试分开。

R1初版核验尚未通过。当前去噪压力检查不等同于噪声方差完全匹配的无噪声正确性证明；SBL仍使用ν=1/N。场外单源出现从好初值逐渐偏离的案例，坐标单位缩放未解决。盲LS位置构造的一原子SBL可行解在该去噪案例中具有更低原生目标，支持存在求解不足；有噪声案例却是完整字典目标更低，不能把两者一概归为同一根因。需继续区分跨频共享γ假设、字典更新/初始化与输出提取，暂不冻结正式SBL配置。

### SBL专项核对与候选修复（2026-10-14）

- **R002原文并未要求全字典位置共同更新。** §III Algorithm 1后的Remark 2明确提出只更新Top-N谱峰以降低成本。本项目已验证这一近似在一个离网单源案例失效：其他有显著γ的邻点被排斥在活动集合外；仅提高单点优化次数或移动边界不能恢复。它是适配近似的局限，不是原文公式抄写错误。
- [Dai等，Root Sparse Bayesian Learning for Off-Grid DOA Estimation](https://arxiv.org/html/1608.07188)，§III-B、式(20)之后，将活动网格数η和源数K分开讨论，建议η≥K，指出过小集合可能遗漏待更新位置。这里借鉴活动集合思想，不使用原ULA多项式求根，不声称复现Root-SBL。试验选8个最大γ点，不做活动集合的空间排斥；最终仍输出K个峰，全字典γ继续更新，未删除其余点。
- 精确位置目标不变，按全频向量化计算；与分块完整协方差重算及方向有限差分一致。数值尺度1000m不改变物理边界；每次20m边界、局部20步、每5轮更新，停止额外检查所有实际活动点的位移。此严格停止可能增加成本，完整耗时照实保留。尚未把8点配置冻结为正式方法。
- [Nannuru等](https://arxiv.org/html/1704.00436)§II-D和§III-C区分频率相关Γ_f与共同Γ；共同支持不等于必需共同方差。当前平坦跨频先验可能不适合带限信号，仍是待验证原因。
- 新候选写作Γ_f=w_fΓ：`w_f = max(uniform_filter(sum_l |x_lf|², round(sqrt(N)))-4/N, 0)`，随后均值归一化；无正超额功率则退回全1。估计只读取观测，FFT频率轴按周期处理，不读取真实带宽或位置。令`A_tilde_f=sqrt(w_f) A_f`后沿用同一证据/固定点推导，后验物理功率需乘w_f。保留全部频点及其噪声项。该经验频谱包络约束是本场景适配，不是Nannuru的独立Γ_f原版，也不宣称新增研究贡献。
- 上述频谱模型数值检查已通过；首轮运行中断，获批降低资源负荷后完成单例对照，但未救回剩余失败。近重合字典点的权重分裂与逐点解码需进一步核验，当前仍未完成SBL整体适配。全部成绩见[最新实验记录](../../../../实验结果记录.md#g10-r1-spectral-snr-20261014)，不以当前候选替换历史证据。

显存允许时，AP/SBL可缓存完整complex128网格响应；缓存建立计入耗时，活动坐标变化后更新对应列。直接计算与缓存逐元素核验，未抽频或降低精度。所有方法均可使用同一机制；只扫描一次时通常不值得额外建立缓存。K=1的AP不会重复扫描不随其他源变化的同一张谱。

MUSIC的`excess_power`候选权重仅由混合观测`max(trace(R_f)-4ν,0)`构造；它不读取仿真频带边界。频率加权改变谱汇聚定义，须在配置与诊断中明确，不作为未标注工程修复。默认保留uniform，只有有限配对核验后才冻结其选择。

## 输出核验、版本分离与相近文献（2026-10-14）

**常规参照：**保持SBL-CC的平坦频率先验、固定点与同证据位置更新，使用8个活动点。默认输出改为`gamma`谱峰，依据Nannuru §IV-B的定义；旧`posterior_power`输出仍可显式选择。该调整是文献口径对齐，不声称新算法。两种输出都使用已登记30m候选排斥，K=1时无影响。恢复过的经验频谱包络不是默认配置。无缓存/128频点分块沿用已核验的低资源实现。

### 共同状态候选登记与定向查重（2026-10-14）

当前执行版本`G10_R1_SHARED_V1`：常规SBL使用原生证据、平坦频率先验、8活动点与γ输出，最多300轮；未收敛触顶单列，取消自动600轮续算。只读观察器保存共同状态；分组γ、相干组重建与单点后验功率辅助对照不改变内部更新或停止。使用全组直径≤0.05m及γ加权中心，不按真值选择尺度；单点组直接保持原坐标。
