## 一、项目研究背景（用于填写「与本研究的关系」列）

### 1.1 研究定位

- 学位论文题目：**基于深度学习的时频混叠多信号检测计数与被动定位方法研究**。
- 研究场景：**四站分布式被动接收，每站单天线**，站间同步接收，**发射波形未知**，观测为**短时混合 IQ**（4096 点量级），多个源在**同一频带内时频混叠**。
- 研究任务：同时恢复**源数 K**、**逐源占用频段**、**各源位置**，以及**频率—源—位置三者的对应关系**。端到端系统按 K 分流：K=0 直接结束，K=1 定位暂为空接口，K=2/3 进入细 DPD 定位。
- K 表示信源数；DPD 直接利用接收信号估计位置；TDOA 是到达时间差；DOA 只估方向；RSS 是接收功率；FDOA 是多普勒频差。**这些量及相干 IQ 不是等价输入**，比较时必须区分。

### 1.2 技术路线

```text
四站 IQ
→ 19 个重叠子带与粗 DPD
→ 第三章预测频带和源数 K
→ 对目标频带生成细 DPD
→ 第四章按 K 解码多源位置
```

- 第三章：在粗网格多子带空间谱（19×81×81）上，用共享残差 CNN + Transformer + **频率有序槽位**联合输出频带占用与源数。
- 第四章：在细网格空间谱上（401×401，小区域版本 201×201 或 41×41/10 m），用 CSPDarknet + PAN-FPN + U-Net 式解码器，以集合热力图 + offset 回归输出多源连续位置。
- E2E 统一模型工作树：核心假设是**把「完整频带报告」与「定位用频率权重」分离**，用短反馈路径让定位损失反过来影响逐源频率表示。

### 1.3 当前待证的核心创新边界（最关键）

**候选贡献必须证明：在短混合观测下，逐源定位权重相对「公共选频 + 适用传统求解器」具有独立价值。**

任何论文，如果它证明「选频有用」「多频融合有用」「学习辅助物理后端有用」「未知 K 直接处理可行」，都直接压缩本研究的创新空间，必须明确指出。

已知需要重点核验的威胁：

- 传统方法（如 R02 MVDR-DPD、R33 多频函数融合、R32 行列式谱、R27 MMSE 分布式 DPD）是否已经能在单天线多站下分开多源且不用已知 K。
- 学习式方法（如 R37 DNN 压缩相关函数、R17 SubspaceNet）是否已经在 RF 中实现了「学习中间统计 + 物理求解」。
- 未知 K 直接处理（如 R30 GLMB、R14 变源数端到端）是否已有先例。
- 频谱辅助消歧（如 R04 循环频率、R11 频谱着色）是否已覆盖「用频率差异帮助多源分辨」。

### 1.4 已建立的适用性分级体系（必须沿用）

- **直接基线候选**：观测模型接近，仍须核对源数、信道与计算预算。
- **条件适用**：满足原有条件时可比较（例如可分循环频率、单源、运动历史、已知 K）。
- **需重推适配**：思想可借鉴，但观测接口或可辨条件需要重新推导。
- **仅机制**：用于判断哪些想法已有先例，不能拿原论文精度作为同条件基线。

## 二、分析基本原则（必须严格遵守）

### 1. 准确性优先
- 所有分析必须以论文页面图像的实际内容为主要依据。
- **不得补造论文中没有出现的数据、实验、方法、结论或引用关系。**
- 无法确认的信息必须明确标记为「论文未说明」「现有信息不足」或「需要外部资料验证」。
- 不得把合理推测写成确定事实。

### 2. 区分信息性质
- **原文事实**：论文明确给出的事实、数据、公式或实验结果。
- **作者主张**：作者对方法、结果和贡献的解释。
- **分析判断**：你根据原文证据作出的独立评价。
- **信息不足**：无法仅依据论文确认的内容。

不得把作者声称的创新性、有效性或优越性直接视为成立，必须结合方法差异和实验结果核查。

### 3. 证据定位
关键内容尽可能注明：章节/小节、页码、公式编号、图号及子图号、表号、算法编号。
**你读的是渲染页面图像，页码以图像左下角/右下角的印刷页码为准**（若论文无印刷页码，用 PDF 顺序页说明）。
无法获得准确编号时明确说明，**不得虚构编号**。

### 4. 批判性分析
- 独立检查论文前提是否成立。
- 检查研究问题、理论假设、方法设计、实验设计和结论之间是否形成完整证据链。
- 对优点和缺点使用相同的证据标准。
- 不因作者使用复杂模型、较多公式或较高实验指标，就默认工作具有较强创新性。

### 5. 表达要求
- 全部使用中文。
- 专业术语第一次出现可用「中文名称（英文名称，缩写）」形式，后续统一。
- 变量名、公式符号、算法名、模型名、数据集名、指标名**不得随意翻译或改写**。
- 先给结论，再给依据。
- 表达直接、客观、专业，避免奉承、空泛评价和重复表述。
- 不要展示思考过程，只给出可核查的分析、判断依据。

## 三、输出格式（严格按此模板写入 fragment 文件）

每个 R 编号写一个文件，路径：
`F:\SourceCount_DPD_E2E\研究方向\强弱源混叠DPD\文献\原文图像\_frag\<R编号>.md`

### 3.1 格式规则（务必严格遵守，否则无法解析）

- 每个字段独占一行起始，以 `@@字段名:` 开头（两个 @ 符号）。
- 字段内容可以跨多行，直到下一个 `@@` 开头的行或文件结束。
- **不要**在正文中使用行首 `@@`，需要分层时用 `1.` `-` `·` 或全角符号。
- 不要写 Markdown 表格，不要写代码块围栏。
- 每个字段都必须填写；确实无法确认的写「论文未说明」。

### 3.2 字段模板

```
@@编号: R02
@@标题: 论文英文原题（保持原文，不要翻译）
@@作者年份: 第一作者姓 等（或全部作者），期刊/会议简称，年份，卷(期)，页码
@@一句话概括: 作者针对什么问题，在什么条件/场景下，提出了什么方法，取得了什么主要结果。避免「效果良好」「具有重要意义」等空泛表述。1—2 句。
@@研究对象与场景: 具体研究对象的信号类型、几何配置、源的数量与运动性质、应用背景。写清论文所考虑的关键约束。
@@信号与观测模型: 论文的接收模型：每站阵元数、观测域（时域/频域/协方差/张量）、未知量（波形/增益/相位/噪声）、快拍或分段数。要能让读者判断输入信息层级。
@@是否已知源数: 从下列取值中选择并补充依据：已知K / 已知K（由MDL等模型阶数估计） / 未知K直接处理 / 需另定阈值后处理取峰 / 论文回避未讨论。必须注明算法何处使用了K，附章节/公式编号。
@@核心方法: 整体思路、主要组成模块、模块间关系、最关键的技术机制。不要陷入次要实现细节，但不能省略决定方法性质的关键步骤。要明确「与已有方法的主要差异」。
@@对混合IQ的适用性: 先写 4 级适用等级之一（直接基线候选 / 条件适用 / 需重推适配 / 仅机制），再写「；输入信息层级：」，然后写实际输入属于哪一层（原始混合IQ / 已提取时延或协方差 / 已估DOA / 已关联量测 / 理想量测 等）。必须注明触发该判定的具体条件，说明在什么条件下失效。
@@实验条件: 数据来源（仿真/实测/公开数据集）、几何配置与站数阵元数、源数与间距、SNR与带宽、样本量/Monte Carlo次数、对比方法名单、评价指标。要给出可复现判断所需的关键数值。
@@主要结果: 最重要的定量或定性结果，保留关键数值，注明对应图/表/章节位置。必须说明结果在哪些条件下成立、在哪些条件下不成立或未测试。
@@可复现性: 是否公开代码/数据；超参数、初始化、停止准则是否给全；仿真设置是否足以复现；实测是否有原始数据说明；作者自评的局限。无法判断写「论文未说明」。
@@论文结论与支持边界: 分两层写。第一层：作者最终得出的结论。第二层：实验实际能够支持的结论，以及结论存在的适用条件或外推限制。两层必须明确区分。
@@主要贡献: 2—4 项。不得照抄作者自我陈述，须结合方法差异和实验结果判断。
@@主要局限: 2—4 项。不得使用缺乏论文依据的通用批评（如「未做实测」若论文确实没要求）。须指出具体缺口。
@@总体评价: 一个自然段，客观评价问题价值、方法合理性、创新程度、实验证据强度、实际应用价值。先给判断，再给依据。
```
