> 这是**改写任务，不是重新读论文**。原文的 PDF 图像不必再看；但**事实准确性要求不变**。

## 一、核心目标

读者是博士生导师级研究者，但他要的是**快速领会**，不是逐条核验。

- **先让人看懂，再谈精确。** 一句话能说清的，不要写三句。
- **不写公式。** 不出现 `$...$`、`w^H`、`e_1^H Q^{-1}`、`Φ_q(p)` 这类符号串，也不写"式(23) 的广义特征值形式"这种推导描述。
- **不写实现细节。** 不写"分块 FFT 后按 K 个不重叠时间窗分段、每窗 J 个快照"——只写"把长观测切成若干段分别估协方差再融合"。
- **保留关键数字。** 站数、阵元数、源数、SNR 范围、误差数值这类"一眼判断量级"的数字要留，但不要堆砌。
- **保留方法与算法名。** MVDR、MUSIC、PARAFAC、GLMB、SubspaceNet、GCC-PHAT、CSPDarknet 等专有名词保留原样，不翻译。
- **变量名、指标名保留原样**（RMSE、GOSPA、K 等），但不展开公式。

## 二、各字段篇幅与写法

| 字段 | 目标篇幅 | 写法要求 |
|---|---|---|
| 编号 | — | 照抄 |
| 标题 | — | 照抄英文原题，不翻译 |
| 作者年份 | ≤40字 | 只留「第一作者 等, 期刊简称, 年份」，删卷期页码 |
| 一句话概括 | 60–110字 | 1–2句。什么问题、什么条件、什么方法、什么结果。不用"效果良好"这类空话 |
| 研究对象与场景 | 80–150字 | 2–3句。信号类型、几何配置、源数、关键约束 |
| 信号与观测模型 | 80–150字 | 2–3句。**重点说清"每站几根天线、算法实际吃进去的是什么"**——这决定它能不能和本项目比较 |
| 是否已知源数 | 30–70字 | 一句结论 + 半句依据。从：已知K（直接给定）／已知K（需模型阶数估计）／未知K直接处理／需阈值后处理取峰／论文回避 |
| 核心方法 | 180–300字 | 3–5句。说清「整体怎么做的、最关键的一步是什么、跟已有方法差在哪」。不写公式，不写推导 |
| 对混合IQ的适用性 | 80–140字 | 「4级等级；输入层级：xxx」+ 一句失效条件。等级取值：直接基线候选／条件适用／需重推适配／仅机制。输入层级取值：原始混合IQ／已提取时延或协方差／已估DOA／已关联量测／理想量测 |
| 实验条件 | 120–200字 | 2–3句。仿真还是实测、站数与源数、对比了谁、指标是什么。关键数字保留 |
| 主要结果 | 150–250字 | 3–4句。最重要的数字结论，括号里给图表位置。说清"在什么条件下成立" |
| 可复现性 | 50–100字 | 1–2句。有无开源、参数给全没有、作者自评局限 |
| 论文结论与支持边界 | 120–200字 | 2–3句。**先写作者的主张，再写证据实际能支持到哪一步**，两者用「作者结论：… 证据边界：…」分开 |
| 主要贡献 | 120–200字 | 2–4条，每条一句短句。不照抄作者自我陈述 |
| 主要局限 | 120–200字 | 2–4条，每条一句短句。必须是论文里能指认的具体缺口 |
| 总体评价 | 120–200字 | 3–4句。问题价值、方法合理性、创新程度、证据强度、实用价值 |

| 证据定位 | ≤120字 | **只给最关键的 3–5 项**，如「§III-B 式(12)–(15), p.194；图3；表II」。不要逐条罗列十几个位置 |

**单行总字数控制在 1800–2600 字**（详细版中位数约 11000 字，即压到 1/5 左右）。

## 三、改写示例（照这个风格写）

**详细版（要避免）**：
> 整体思路是「先用协方差矩阵的几何平均把间歇干扰从统计量层面抹掉，再在无干扰的协方差模型上做多频联合协方差拟合定位」。…对同一频点 q 的 K 个逐窗协方差做黎曼均值 R_RM^q = arg min_{R∈M} Σ_k d_RM²(R, R_k^q)（式(16)）…作者明确指出多于两个 HPD 矩阵的黎曼均值没有闭式解…

**白话版（要写成这样）**：
> 把长观测切成若干段，每段单独算一个协方差矩阵；因为期望源全程都在、干扰源只是偶尔出现，所以对多段的协方差取「几何平均」就能把干扰稀释掉，而不必显式找出干扰方向。然后用平均后的协方差去匹配每个候选位置的理论协方差，匹配最好处即源位置。关键一步是用黎曼距离（而不是常规欧氏距离）来度量两个协方差矩阵的差异，因为协方差矩阵是正定矩阵、欧氏度量会破坏其几何结构。与已有单频做法相比，它把多个频点上的失配聚合成一个代价，从而用上了宽带 TDOA 信息。

## 四、格式规则（与详细版一致）

- 每字段一行起始，以 `@@字段名:` 开头，内容可跨多行。
- 正文中不要出现行首 `@@`。不要用 Markdown 表格、代码块围栏。
- 18 个字段全部填写。确实无法确认写「论文未说明」。

## 五、红线

- **不得新增详细版中没有的事实、数字、结论。**
- 压缩时如果某条信息拿不准，**宁可写「论文未说明」，不要为了通顺而自行补全**。
- 不得把作者主张写成已成立的事实；「作者结论」与「证据边界」必须分开。
- 数字要照抄，不要四舍五入或换成约数。
