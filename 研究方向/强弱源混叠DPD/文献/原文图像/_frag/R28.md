@@编号: R28
@@标题: Bandpass Signal Design for Passive Time Delay Estimation
@@作者年份: Nanzer J. A., Sharp M. D., Brown III D. R., IEEE Asilomar Conference on Signals, Systems and Computers (ACSSC)，2016，第 1086–1091 页
@@一句话概括: 针对「带通信号的频谱形状如何影响被动时延估计精度」这一问题，作者在 Weiss–Weinstein 的平坦带通模型（式(1)）基础上引入「分裂带通（split bandpass）」谱模型——在总带宽 W 的两端各取宽 B 的对称子带、把 B/W 作为可控设计参数——用修正 Ziv-Zakai 下界（MZZLB）与 Monte Carlo 最大似然时延估计器分析了三个工作区间的迁移，结论是：增大均方带宽 β² 可在中高后处理 SNR 下改善时延估计精度并让无模糊区间提前到来，但在中低 SNR 下会因新增的 B-模糊（错误峰）而使性能显著恶化（本例中相对 MSE 可差 3 个数量级以上）。
@@研究对象与场景: 对象为两个接收点之间单一未知时延 τ 的被动估计（Section III 的观测模型 y(t) = a s(t−τ) + w(t)，0 ≤ τ ≤ D），信号为带通（bandpass）雷达／同步／分布式波束形成等系统使用的确定性已知模板波形 s(t)。关键约束：时延上界 D 已知（先验位于 [0, D]）；信号与噪声带宽受限（模板谱在支撑外为零）；时间带宽积 2BT（或 TW/2π）显著大于 1；信噪比以后处理 SNR R 参数化。论文明确考虑的信号是「设计出来的」信号（本机已知模板），不是未知辐照源波形；全文只处理单源、单时延，不含多源、不含阵列、不含空间位置。
@@信号与观测模型: 观测为单通道连续／离散时间信号 y(t) = a s(t−τ) + w(t)（第 1089 页 §III 开头），s(t) = cos(Ω₀t)u(t) 为已知带通模板（式(20) 前一行），u(t) 为带限基带信号（|Ω| ≥ Ω₀ 时 U(Ω)=0）；w(t) 在模板谱支撑内为平坦谱噪声。离散观测 y[k] = y(kT_s)，s[k] = s(kT_s)，采样率 T_s = 1/f_s，离散时延 k̂ ∈ [−D/(2T_s), D/(2T_s)]。频域模型由 SNR(Ω) 描述：平坦带通为 SNR(Ω) = SNR（|Ω±Ω₀| ≤ W/2）、其余为 0（式(1)）；分裂带通为在 [Ω₀−W/2, Ω₀−W/2+B] ∪ [Ω₀+W/2−B, Ω₀+W/2] 上非零（第 1088 页 §II-2）。未知量为单个标量时延 τ（及幅度 a）；噪声统计已知（平坦谱）。不含多普勒、不含多源叠加、不含阵列相位。
@@是否已知源数: 论文回避未讨论。全文只存在一个时延参数（单一 y(t) = a s(t−τ) + w(t)，第 1089 页式(19) 之前的观测方程），不存在源数这一变量的定义、估计或使用；第 1—2 页摘要、Introduction、Section II—V 与图 1—5 均未出现 K/Q 或模型阶数选择的内容。因此「源数」概念在本文框架内不存在，属论文未讨论。
@@核心方法: 三层结构。第一层，理论下界：以修正 Ziv-Zakai 下界（MZZLB，式(5)：σ² ≥ (1/D)∫₀^D x G[(D−x)P_e(x)]dx，其中 G[f(x)] = max_{x≤t≤D} f(t) 为式(6) 的「填谷」算子；P_e(x) ≥ P̄_e(x) = exp{−d(x)}·Q(√(c(x)))）为统一工具。对平坦带通信号解析算出 c_flat(x) = R(1 − S_W(x/2)cos(Ω₀x)) 与 d_flat(x) = πR²/(8WT)·[3 − 4S_W(x/2)cos(Ω₀x) + S_W(x)cos(2Ω₀x)]；对分裂带通算出 c_split(x) = R(1 − S_B(x/2)cos((W−B)x/2)cos(Ω₀x)) 与 d_split(x) = πR²/(16BT)·[3 − 4S_B(x/2)cos((W−B)x/2)cos(Ω₀x) + S_B(x)cos((W−B)x)cos(2Ω₀x)]。关键机制：把 c(x)、d(x) 在 x→0 用 Maclaurin 展开得到 c ≈ c̄²x²（c̄² = RΩ₀²/2）与 d ≈ d̄⁴x⁴（d̄⁴ = R²(2π/·)Ω₀⁴/4），再在 x = x_n = 2πn/Ω₀ 处取上界（式(9)(10) 与式(15)），得到 ĉ² 与 d̂⁴，把式(5) 化成式(11) 的闭式积分——这是全文的关键技术步骤：c̄、ĉ 承载「模糊度」（相关函数的旁瓣结构），d̄、d̂ 承载「均方带宽」，两者分别主导低 SNR 与高 SNR 区间。第二层，区间刻画：由式(11) 三项（第一项含 c̄ 与 d̄、第二项含 ĉ 与 d̂、第三项为 D²/6·Q(√R) 的 no-information 项）分别占优，解析出平坦带通的三段区间（第 1087 页末至 1088 页）：R ≪ 1 时 σ² ≈ D²/12（no information）；1 ≪ R ≪ （含 1/(W²ĉ⁴) 量级）时 σ² ≈ 6/(W²R)（ambiguity-dominated，相当于 Barankin 界 σ² ≥ 6/(W²R)，式(4)）；R 很大时 σ² ≈ 1/(2Ω₀²R)（ambiguity-free，等于 CRLB）。转换区阈值由式(13) R'_flat = f'(Ω₀/W) 与式(14) R''_flat = f''(Ω₀/W) 给出。第三层，把平坦带通结果平移到分裂带通：只需把 W²/12 替换为 β²。论文由式(15) 的推导给出分裂带通的均方带宽闭式 β² = (B² + 3(W−B)²)/12，并定义相对均方带宽 α ≜ β²/(W²/12) ∈ [1, 3)；式(16)(17) 给出 R'_split = f'(Ω₀/(√12β)) 与 R''_split = f''(Ω₀/(√12β))，从而 R'_split/R'_flat = 1/α，R''_split/R''_flat = (1/α)·[Q^{-1}(αW²/(24Ω₀²))/Q^{-1}(W²/(24Ω₀²))]²。与已有方法的主要差异：不提出新的估计器，而是把 [1][2] 仅适用于「平坦谱 + 带内 SNR 恒定」（式(1)）的经典结论推广到可调的非平坦谱形；并额外发现分裂带通在低 SNR 下存在「B-模糊主导」这一平坦带通所没有的第四个子区间。第四层，估计器实现（§III）：先用离散相关取峰 τ̂ = k̂T_s（式(20)(21)），再用式(22)(23) 的两路正余弦相关 z_i[k]、z_q[k] 做 θ = ω₀(τf_s − k̂) 的精化 τ̂ = (k̂ + θ/ω₀)T_s；针对式(24) |k̂ − τf_s| ≤ π/ω₀ 不满足时会选错相关峰的问题，提出保留 N 个候选离散时延 τ̂₁…τ̂_N 并取式(25) 的 ML 最大者。
@@对混合IQ的适用性: 仅机制；输入信息层级：理想量测之上的「已知模板波形 + 纯时延参数」层——比原始混合 IQ 更高层，属于单源双站时延估计的性能界分析，连「已提取时延」都不是（它分析的是提取时延所能达到的精度界）。触发该判定的具体条件：1. 波形已知——s(t) = cos(Ω₀t)u(t) 是本机生成的模板（式(20) 前的定义），本项目发射波形未知，模板相关式(19)(20)(25) 全部不可用；2. 单源单时延——式(19) 的 y(t) = a s(t−τ) + w(t) 只含一个 τ，无多源叠加、无源数概念；3. 无阵列——只给了单通道模型，不含空间导向矢量，无法直接给出位置；4. 谱形确定——SNR(Ω) 是设计者指定的确定性分段函数（式(1) 与 §II-2），而本项目各源占用频段未知且时频混叠，SNR(Ω) 不是可控设计量。失效条件：只要波形未知、或存在第二个源、或需要把时延界转成位置界（几何精度因子 GDOP 与站间几何未在文中出现），论文的式(11)、区间划分与图 3—5 的结论都不再直接适用。可迁移的只是其定界方法与「均方带宽 ↔ 模糊度」的权衡定性结论。
@@实验条件: 全部为自造仿真（无实测、无公开数据集；资助来源为 Naval Sea Systems Command 与 NSF，但正文未提到实测验证）。统一仿真参数（第 1090 页 §IV 与图 3 图注）：载频 Ω₀ = 2π·4000（归一化后 Ω₀ = 2π×4000 rad/s）、分数带宽 W/Ω₀ = 1/100、时间带宽积 TW/2π = 50、最大时延 D = 10⁵ T₀（T₀ = 2π/Ω₀）、采样率 f_s = 16 kHz。曲线构成：数值积分得到的 MZZLB（分别对应 conv. bandpass model 与 split bandpass model）；Monte-Carlo 最大似然估计器四种实现——纯离散时间相关、精化相关 + 1 个候选时延、+2 个候选、+10 个候选。图 5 为相对 MSE（分裂带通 MZZLB 与平坦带通 MZZLB 之比），扫描 B = W/100、W/50、W/20、W/10、W/2，横轴为后处理 SNR（dB），纵轴比值范围约 10⁻⁴—10⁴。论文未给出 Monte Carlo 次数、仿真时长、噪声样本量等具体数值（论文未说明）。对比对象只有「同一 MZZLB 框架下 B = W/2 的平坦带通」这一自我对照，无与其他时延估计器（如广义互相关 GCC、MUSIC 时延估计）的横向对比。评价指标为时延估计 MSE（TOA error variance bound，单位 sec²）与相对 MSE。
@@主要结果: 1) 平坦带通（图 3，第 1090 页）：数值积分的 MZZLB 与 Monte-Carlo MLE 三条曲线在三个区间内贴合，验证 §II-1 的区间划分与阈值式(13)(14)；离散时间相关（无精化）在约 55 dB 后出现明显误差地板，作者归因于 f_s = 16 kHz 采样对时延估计的量化效应；加 1、2、10 个候选时延的精化后，MLE 在约 45–50 dB 区间达到无模糊区间，且候选数越多到达略早。2) 分裂带通（图 4，第 1090 页，参数同图 3 且 B/W = 1/10）：MZZLB 与 MLE 同样贴合，并清楚显示出**两个**模糊主导子区间——低 SNR 的 B-模糊主导（MSE ≈ 6/(B²R)）与较高 SNR 的 β-模糊主导（MSE ≈ 1/(2β²R) ≈ 2/((W−B)²R)），两者之间的转换发生在约 25–30 dB（第 1090 页右栏原文：“the transition from B-ambiguity-dominated to β-ambiguity dominated behavior between 25–30 dB post-integration SNR”）。3) 分裂带通相对平坦带通的净增益（图 4、图 5 与第 1090 页右栏）：在约 30 dB 到 50 dB 之间分裂带通更好，且「特别是在分裂带通已进入无模糊区间、而平坦带通仍处于模糊主导区间的约 45–50 dB 区间」增益显著；图 5 的措辞给出「significant gains (exceeding three orders of magnitude in this example)」。4) 代价（图 5 与 §V）：在中低 SNR 下分裂带通显著更差——B/W 越小，均方带宽 β² 越大（β² = (B²+3(W−B)²)/12），但 B-模糊越强，分裂带通优于平坦带通的 SNR 区间反而收窄；B/W 极小时 B-模糊「dominates the performance except at very high and very low post-integration SNRs」（第 1091 页左栏）。5) 数值例（第 1088 页右栏）：W/Ω₀ = 1/100、B/W = 1/10 时 α = 2.44，转换区起点左移约 3.9 dB、终点左移约 4.3 dB。上述结果全部在单源、已知模板、确定性 SNR(Ω) 谱形、理想平坦噪声的仿真条件下成立；论文未测试宽带多径、波形失配、多源、阵列等情形。
@@可复现性: 论文未提供代码或数据链接。仿真参数的数值给得较完整：Ω₀、W/Ω₀、TW/2π、D、f_s、B/W 扫描值、图 5 的相对 MSE 定义均可读到，理论上可复现主要曲线。未给全的部分：Monte Carlo 次数与仿真时长未说明；ML 估计器式(20)(25) 中候选时延 N 的取值虽有 1/2/10 三档，但候选时延的选取规则（如何挑出这 N 个）论文只给了原则性描述（“The number of candidate delays is a parameter that can be selected...”），未给具体算法；基带信号 u(t) 的具体形状未明确给出（只说 bandlimited），而 u(t) 决定相关函数旁瓣结构，对 B-模糊的实际表现有影响，属可复现性缺口。作者自评的局限：第 1089 页明确离散相关法在准周期相关函数下「may select an incorrect correlation peak ... even at infinite SNR」，并指出精化与过采样会增加计算复杂度；第 1091 页指出极小的 B/W 会使 B-模糊在除极高／极低 SNR 外主导性能。
@@论文结论与支持边界: 第一层（作者结论，§V 第 1091 页）：带通信号设计给出四个工作区间——(i) no-information、(ii) B-ambiguity-dominated、(iii) β-ambiguity-dominated、(iv) ambiguity-free；在保持固定且远大于 1 的时间带宽积的前提下增大分裂带通信号的均方带宽，可在中高后处理 SNR 下改善时延估计性能，并让从模糊主导到无模糊的转换在更低 SNR 处发生；代价是在低 SNR 下因 B-模糊主导区间的新增模糊而变差；B = W/2 时退化为 Weiss–Weinstein 的经典结果。第二层（实验实际支持的结论）：(a) 「增大 β² 提升高 SNR 精度」直接由经典界式(2) σ² ≥ 1/(2β²ℰ/N₀) 给出，本质是已知结论的重新参数化，其新意只在于把 β² 与可控的谱形参数 B 显式联系起来；(b) 「分裂谱带来额外模糊、低 SNR 变差」在仿真中体现明确（图 5 的相对 MSE 在低 SNR 达 10³—10⁴ 量级），但仅有自造仿真、无实测；(c) 转换区左右移的 3.9 dB / 4.3 dB 只在 W/Ω₀ = 1/100、B/W = 1/10、TW/2π = 50 这一具体参数点验证，不能外推到其他带宽比与时间带宽积；(d) 结论依赖模板完全已知、噪声谱平坦、单一无模糊先验 D 这些条件，对波形失配、有色噪声、多源均未测试；(e) 由于全文不含源数、阵列与位置参数，其结论不能外推到「多源定位」场景。
@@主要贡献: 1. 提出「分裂带通」谱模型并给出其均方带宽的闭式 β² = (B² + 3(W−B)²)/12 与相对均方带宽 α = β²/(W²/12) ∈ [1,3)，把「频谱形状设计」这一自由度写成单一标量 B，使「谱形 ↔ 时延估计精度」可解析讨论。2. 用 MZZLB 闭式积分（式(5)(11)）刻画出分裂带通特有的四个工作区间，识别出平坦带通所没有的「B-模糊主导」区间以及 B-模糊→β-模糊的转换（约 25–30 dB），这是对 [1][2] 结论的实质扩展。3. 给出转换区阈值的解析平移关系（式(16)(17)：R' ∝ f'(Ω₀/(√12β)) 等，以及 R'_split/R'_flat = 1/α），把「增益多少 dB」变成可计算的量而非经验观察。4. 提出带候选时延保留（式(25)）的时延精化流程，缓解带通信号准周期相关函数导致的错误峰选择（式(24) 条件）。
@@主要局限: 1. 只处理「波形已知的单源单时延」：观测方程 y(t) = a s(t−τ) + w(t) 中没有第二个源、没有未知波形、没有阵列，因此其结论无法直接支撑任何多源或多站定位的判断；作者也从未把结果与定位（位置）误差联系起来。2. SNR(Ω) 谱形被当作可由设计者自由指定的确定性函数，而本文并未讨论当谱形由外部环境或未知源决定时如何得知它——这正是本项目「各源占用频段未知且混叠」场景下最关键的前提缺口。3. 定量结论参数覆盖窄：图 3—5 只扫了 B/W 一个维度，W/Ω₀ 固定为 1/100、TW/2π 固定为 50；论文正文明确说「the performance gains are significant especially in range of post-integration SNRs ... @@总体评价: 这是一篇定位清晰的「性能界推广」类会议论文，问题价值明确：它回答的是一个设计问题（带通谱形怎么影响时延估计精度），而不是提出新算法。方法合理性高——在 MZZLB 这一公认的紧界框架内做 Maclaurin 展开与上界替换，推导链条完整，式(11) 的三项分解把「模糊度」与「均方带宽」拆成可分别操控的因子，是其最有价值的技术内容；式(15) 得到 β² 的闭式也把「谱形参数化」落实到一个可用标量。创新程度中等：以 B/W = 1/2 退化为 Weiss–Weinstein 结果是明确的自我定位，增量在于把经典结论推广到非平坦谱并发现额外的 B-模糊区间；但「高 SNR 下界由均方带宽决定」这一核心机理在 1983 年 [1] 中已经给出（式(2) 即为本文重述），因此本文不宜被当作新机理。实验证据强度中偏弱：全文为纯仿真、参数只覆盖单一 W/Ω₀ 与 TW/2π 点、没有与其他时延估计算法对比，且未公开代码；但作为「下界与区间划分」的验证性仿真，其目标本就不是算法竞赛，图 3—4 中数值积分界与 MLE 良好贴合这一点是有说服力的自洽性证据。实际应用价值在于给分布式相参系统（distributed beamforming、同步）的信号波形设计提供量化设计曲线。
@@与本研究的关系: (1) 覆盖程度：R28 完全不覆盖本项目的核心问题（源数 K、逐源占用频段、逐源位置、频率—源—位置对应）。它既不涉及多源，也不涉及定位，只做单源已知模板的双点时延精度界。但它覆盖了本项目的**候选创新点所依赖的那条机理**：即「对接收谱做加权选择」能带来什么、代价是什么。(2) 同条件基线：不能作为同条件基线——输入层级完全不同（它需要已知模板波形，本项目波形未知；它只有单源）。严格来说它连「条件适用」都构不上，只能作为理论判据引用。(3) 创新空间压缩：**压缩明显，且是四篇中压缩最直接的一篇**。第一，「把权重集中到可用频段以提升定位精度」这一思想的收益上限早已被式(2) σ² ≥ 1/(2β²ℰ/N₀) 定量刻画，β² 是均方带宽，是 1983 年经典结果；若本项目把「学习权重提升定位精度」作为主要卖点，必须说清它与「提升均方带宽」这一已知机理的差别，否则审稿人会直接引 [1][2] 或本文。第二，本文第 1091 页明确给出低 SNR 下选频的代价：把谱能量推到带边缘虽然增大 β²，却制造周期性相关旁瓣，导致 B-模糊主导区间 MSE ≈ 6/(B²R)，本例中相对 MSE 可差 3 个数量级以上——这意味着「学习到的稀疏／边缘化权重」在低 SNR 或短观测下很可能反而制造错误峰，本项目的短时混合 IQ（4096 点、K=2/3 多源）恰好处在这一危险区。第三，唯一未被本文覆盖、因此仍可能构成创新的是：本文的 B/W 是由设计者选择的**全局单一标量**，谱形对两个接收点相同、且假定已知模板；而本项目要做到的是**逐源、数据驱动、在源谱未知且互相混叠的条件下**给出权重，并且权重只对某个源有效（其他源在该权重下被抑制），这是本文结构中不存在的自由度。(4) 可直接借鉴的机制与须避开的陷阱：可借鉴——把「定位用频率权重」的有效性论证放在均方带宽 β² 这一可计算量上，用 σ² ≥ 1/(2β²ℰ/N₀)（式(2)）给出权重方案的**理论上界对照**，即在相同 β² 下学习权重不应超过该界，这可以作为「学习权重是否有独立价值」的定量检验而不是仅凭端到端指标；式(24)(25) 的候选峰保留机制可直接用于本项目细 DPD 阶段的多峰（多源）输出筛选，避免只取全局最大峰。须避开的陷阱——(a) 不要把「加权后精度提升」直接当作创新，先算 β² 的变化并与式(2)/(4) 对照，若改善可由 β² 增大解释就不是新机理；(b) 不要在低 SNR／短观测下使用过度集中的稀疏权重，本文已证明此时会进入模糊主导区间并产生错误峰，本项目报告指标时应同时给出「错误峰率／漏源率」而不只给位置 RMSE；(c) 本项目公共选频对照（R23 的能量保留规则）与学习权重的比较，应当设计成「在相同有效 β² 或相同保留带宽比例下比较」，否则比较会被本文的 β² 效应解释掉，失去说服力。
