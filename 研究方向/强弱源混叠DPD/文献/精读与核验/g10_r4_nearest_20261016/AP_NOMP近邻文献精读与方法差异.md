# AP／NOMP近邻文献精读与方法差异

日期：2026-10-16。范围：保留的两篇期刊论文共48页，核对正文、附录、关键公式与实验，并与当前定位代码静态对应。按用户要求，文献目录及本报告不再单列QNOMP预印本。本轮没有运行定位实验或改变冻结方法。

## 1. 结论先行

两篇论文对应两项研究。Yang等的BNOMP-CB是当前块NOMP最接近的模型参照；Zeng等的QNOMP已有联合BFGS精修，统一引用2025年期刊版。

这次精读不要求推翻现有AP/NOMP路线，但修正了两个判断：

1. “未知宽带波形、逐频系数块、二维位置、消强后找弱源”已经有相当接近的完整方法，不能仅把它们合在一起作为新贡献。
2. “在NOMP后追加联合BFGS”已有直接先例。我们的研究价值应落在当前少站强弱混叠场景中的具体处理、候选保留机制、稳定收益和完整成本，而非联合优化这个名称。

建议继续保留AP多候选联合精修与NOMP联合精修两个候选，但不预先要求它们都成为独立贡献。下一步先完成近邻方法的代码对应，再一次性冻结扩大验证版本，避免随少量样本的输赢反复增删方法。

## 3. R117：多频二维离网压缩波束形成

### 3.1 它解决什么问题

多个声源同时被任意平面几何的麦克风阵列接收。不同频率分别定位可能分不清相邻源，也容易受其他源干扰；固定网格还存在位置量化误差。作者让不同频率共享源位置，同时保留每个源在各频率的独立复系数，通过块NOMP找位置和源谱。

“同步多频”指多个频率共同估计同一组位置，不要求已知发射信号，也不要求所有频率具有相同复幅度。

### 3.2 观测模型为什么与我们很接近

论文§2、式(1)—(5)，p.3：

\[
p_{m,l}=\sum_{s=1}^{S}\frac{e^{-j2\pi f_l d_{ms}/c}}{d_{ms}}q_{s,l}+n_{m,l}.
\]

其中位置决定距离、幅度和相位；\(q_{s,l}\)是待估计的逐源、逐频复系数。每个源对应一个跨频率的块原子，不同频率有不同传播响应。源所在平面距阵列平面固定高度\(h\)，二维坐标未知。

我们的共同目标也可写成：

\[
J(P)=\sum_f\|x_f-A_f(P)\widehat s_f(P)\|^2,
\qquad \widehat s_f(P)=A_f(P)^\dagger x_f.
\]

论文§4.1、式(8)—(11)，p.5，已经给出这一类最小二乘消元与投影目标。它不是“只会测DOA、已知波形、同字典多快拍”的远亲。

差别主要在声学／RF物理量、传感器数量和布局、已知高度平面／当前二维场景、声频／基带频率、强弱功率设计和计算规模。当前归一化响应列与未归一化列，在自由逐频源系数的精确LS消元下张成同一子空间；这不等于原数据被逐站RMS归一化，也不保证固定系数Newton步骤完全相同。

### 3.3 算法实际做了什么

按§4.2、p.5、7及附录II、p.26—27：

1. 从当前残差的全网格块匹配能量中，选择一个新源候选。
2. 对这个源的二维位置做局部Newton修正，再重估其逐频系数。
3. 轮流把已发现源加回残差，更新其位置和系数，使先前的误差可以被纠正。
4. 对所有已发现源做一次联合LS系数重估，再继续找下一个源。

论文中的“global cyclic feedback”指回访所有已发现源，不是对所有位置完成全局最优搜索。其联合步骤主要是源系数LS；位置更新仍是逐源进行。式(17)与附录II对当前位置下的系数作固定参数求位置偏导，位置更新后再按式(15)重估系数。

循环停止检查相邻两轮的残差能量差是否小于等于\(10^{-4}\)；这是其信号幅度和单位下的设置，不应直接复制到归一化RF目标。源数\(S\)用于终止外层发现，正文没有建立我们所需的未知源数流程。

### 3.4 实验和结论

- §5，p.7—17：36麦克风、0.65 m孔径，源平面距阵列1 m；1 m×1 m区域，0.05 m网格。包含多正弦、非平稳高斯脉冲、离网、多源干扰和蒙特卡洛实验。
- §5.1，p.11及Fig.4—5：一个源在4000 Hz的幅度为0.4 Pa，另有1 Pa分量；低SNR时单频处理对弱源偏差明显，BNOMP-CB更稳。因而“此前未研究弱源受强分量干扰”不成立。不过，这不是我们固定弱源SNR、扫描六档整体功率差的试验设计。
- §5.3，p.16—17：500对随机双源、至少0.1 m间距，逐频幅度0.5—1.5 Pa，扫描SNR，并比较宽频与窄频组合。
- §6，p.18—24：36麦克风、三扬声器实测。位置实验包含同时播放；为量化源谱，另用三次单扬声器测量相加构造可比较观测，不能把全部量化实验写成同时实测。
- p.18报告BNOMP-CB在5频率时求解0.539 s、81频率时240.108 s，硬件为Xeon E5-1650 v3，且只统计求解。该数字说明原实现的大块计算可能昂贵，不能与我们GPU、不同频点数的完整时间直接相除宣称加速。

### 3.5 对当前研究的意义

它应该替代“普通一维NOMP是唯一近邻”的比较方式。当前代码已经具备逐频块系数、二维残差搜索、Newton和循环LS，但不属于该论文逐行复现：本项目每次局部Newton评价消去当前源系数，并用完整联合目标接受更新；论文推导的局部Hessian固定当前系数，联合系数LS的安排也不同。需要把这些差别写明，不能将当前适配版直接改名为BNOMP-CB原版。

其逐源搜索与回访是合理参照。我们可以在此基础上研究不同的候选保留和联合位置更新，但“二维化、多频化、未知源谱”本身已经有先例。

## 4. R118：QNOMP期刊版

### 4.1 观测前提和目标

期刊版§II，p.3—4，式(1)—(7)：用户发送已知、单位模导频，基站使用ULA接收；先去除已知导频，得到带噪信道观测。每条路径用一个跨频共享的复增益\(\beta_i\)、时延\(\tau_i\)和角度\(\theta_i\)表示，响应为频率与阵列导向向量的Kronecker积。

这与我们“两个独立未知发射波形”不同。我们每个源需要一整块逐频系数，不能直接把混合IQ当成已去除导频的CSI，更不能给算法额外真实波形。

### 4.2 核心算法

期刊版§III、Algorithms 1—3，p.4—7：

1. OMP从残差中选一条新路径，并用局部多分辨率网格改善粗初值。
2. 每发现一条路径，用少量BFGS步骤同时调整已发现路径的时延和角度；每次位置参数变化后，重新LS估计增益。
3. 通过CFAR判断是否继续发现路径。
4. 路径数确定后，再做末端联合BFGS精修；此阶段含增益高斯先验对应的二次正则项。

所以，“NOMP之后增加一次联合精修调用”并非尚无人使用的结构。我们的NOMP_JOINT则保留原逐源Newton与循环过程，只在末端增加无正则、逐频块系数消元的联合位置精修；不能把它直接写成QNOMP原版。

文中§III-E、p.7已经提到可以保留多个最大相关候选，但其实验采用最高候选足够。该段没有给出我们“AP条件谱多分支分别联合精修、按最终目标择优”的同配置验证。它是概念先例，不能直接证明当前多分支设计没有价值，也不能称文献从未想到多候选。

### 4.3 哪些部件适合借鉴，哪些不用带进来

| 部件 | 在当前任务中的处理 |
|---|---|
| LS消元后联合BFGS | 可借鉴，并重推逐频块响应的位置梯度与成本 |
| 网格候选后连续精修 | 可复用现有实现；统一网格下单独登记局部加密是否计入成本 |
| 每次发现后的小步联合修正＋末端精修 | 是值得核对的近邻策略；不假装等同仅末端追加 |
| DFT正交字典CFAR | 依赖正交性及白噪声，不能原样套到不规则位置字典；当前已知K，无需引入 |
| 末端正则化／LMMSE | 会改变统计目标，不在本轮悄悄加入共同无正则LS比较 |
| LOX、Slepian低秩外推 | 服务信道外推，当前定位不需要 |
| 角簇block reweighting | 利用一个簇共享时延、具有角扩展的先验；不是我们两源未知频谱的同一种“块”，暂不采用 |

### 4.4 实验与实现要点

期刊版§III-B式(12)，p.5明确使用拼接参数的\(2k\times2k\)逆Hessian近似，可容纳时延—角度交叉项。§V包含一维七路径、二维角簇和CDL-A/C实验，比较NOMP、MUSIC类、AST及贝叶斯等适用方法，报告100次随机试验、中位数和四分位区间。不同场景的NOMP末端循环不同：CDL为0，其他场景有40轮设置，引用性能时需同时登记配置。

期刊版Table 3统计100次试验CPU时间，不是单例时间。其Time×NMSE指标用于自身信道任务；我们继续使用成功率、RMSE、尾部和完整耗时，不改用一个乘积掩盖定位失败。

### 4.5 阅读中发现的实现注意点

期刊式(12)印为“正梯度加上正步长”，但正文定义\(g=\nabla L\)、\(H\)近似正定逆Hessian，且最小化\(L\)。按这些定义应使用下降方向\(-Hg\)。关键页面已目视确认，不是文本抽取的符号丢失。复现应以目标下降、有限差分和线搜索验证，不能照抄这一符号。

论文联合BFGS、LOX及复杂度论证不构成所有场景都优于NOMP的定理。其FFT/Kronecker加速依赖规则阵列；当前四站几何不能直接套用那组复杂度。现有项目L-BFGS-B无需因原文符号问题修改。

## 6. 对候选贡献的收敛判断

### 6.1 AP保留为主要候选

合适的表述是：针对少站未知宽带强弱源，在共同联合拟合目标下保留少量条件候选，通过联合连续精修完成分支比较，以较低成本降低单候选的错误区域选择风险。

已有结果支持多候选有恢复作用、联合精修有成本作用，详细事实统一引用[实验记录](F:/DPD_Strong_Weak/研究方向/强弱源混叠DPD/研究记录/实验结果记录.md#g10-r3-top5-20261016)。这些作用在扩大数据上是否稳定，是接下来要回答的问题。最终贡献可以是一套有依据、可解释且实用的算法，不要求每个工具都原创。

### 6.2 NOMP联合精修可以加回，但保留原NOMP

合理。少量批次没有出现增益，不能据此删去可能有价值的精修；同样，早期有收益也不能预设它必然胜过原NOMP。

扩大实验中固定保留原NOMP与NOMP_JOINT。两者共享相同原生前缀、候选和循环规则，附加联合精修才是唯一改动；报告改对、改错、尾部误差和额外成本。若原NOMP已足够，直接选更简单版本，不另造适配需求。仅降低原生拟合目标不保证真值误差下降。

### 6.3 两个算法可以进一篇论文，不必先指定两个独立贡献

AP条件搜索和NOMP残差发现提供不同初始化。可以在同一个物理模型、消元目标和精修框架下研究两种低成本求解路线。若二者各有稳定适用优势，就形成互补算法；若一条一直没有额外价值，则把它作为对照／消融即可。

不新增自动切换器。先用预先定义的几何、功率差和实际调用次数解释适用范围，不在看完结果后专挑一类胜例。

### 6.4 理论工作聚焦可验证的差别

1. 写清逐频波形消元与归一化不改变位置子空间的条件。
2. 从相同残差和响应出发，解释NOMP残差块评分与AP条件评分的差别。单个已知源时，令\(r_f=P^\perp_{A_f}x_f\)，NOMP使用\(\sum_f|a_f^Hr_f|^2/\|a_f\|^2\)，AP使用\(\sum_f|a_f^Hr_f|^2/\|P^\perp_{A_f}a_f\|^2\)。后者对应新增源后重新拟合的精确收益，却可能改变粗候选排序；二者均是已有准则，当前要解释哪种排序造成实际失误。
3. 对完整位置目标推导梯度和局部耦合，说明逐源／联合位置更新的区别；“局部充分下降”“更大候选集合最优拟合不劣”只约束优化目标，不等于定位成功率保证。
4. 统计全图响应点数、目标／梯度调用和实际完整时间。固定四站双源时，大体为\(O(FG)\)搜索加\(O(TF)\)精修；多分支主要增加后者。贡献可以在常数和调用数，不虚称复杂度阶下降。
