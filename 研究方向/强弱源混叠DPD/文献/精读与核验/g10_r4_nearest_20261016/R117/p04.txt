3. Multi-frequency synchronous two-dimensional on-grid compressive beamforming

   Grid-based compressive beamforming discretizes the target source area into N (N >> M) grid points. The nth gird point’s co­
ordinates are denoted as (xGn, yGn, h), and let rGn ≡[xGn, yGn]T. Then the grid point coordinates can be stacked as ΩG = [rG1, rG2, ⋯,
rGN] ∈R2×N. Grid-based compressive beamforming assumes that each grid point corresponds to a potential source and utilizes the
transfer matrix between the grid points and the microphones to establish the underdetermined equations between the measured sound
pressure vector and the unknown source strength vector. Solving these underdetermined equations can obtain the estimate of source
location and strength [26].

   In the multi-frequency synchronous compressive beamforming model (Eq. (7)), the dimension of the unknown source strength
vector is increased to NL from N in the single-frequency compressive beamforming model (Eq. (6)). Since every L adjacent source
strengths in qG correspond to different frequencies of one source, the non-zero elements in qG present S blocks that are aggregated per L
elements. The source strength vector can be regarded as S-block sparse. Accordingly, the multi-frequency synchronous compressive
beamforming model (Eq. (7)) can be regarded as a block sparse compressive sensing problem of finding the most suitable S blocks
A(rGn),n = 1,⋯,Nfrom the sensing matrixA(ΩG). In other words, with Eq. (7), the source identification problem of sparsely distributed
S sources is transformed into a block sparse recovery problem. It can be solved by the existing block sparse recovery algorithms, such as
convex relaxation algorithm [38], greedy algorithms (e.g., block-matching pursuit (BMP) and block-orthogonal matching pursuit
(BOMP)) [48], and sparse Bayesian algorithm [49].
   However, the above models assume that the source lies on the grid point. When the source lies off the grid point, i.e., when basis
mismatch occurs, the linear combination of support sets (priori vectors or priori blocks of the sensing matrix) selected from the finite-
dimensional discrete dictionary cannot accurately represent the measurement vector, and the grid points cannot represent the real
locations of the sources. Thus, the acoustic source identification performance is degraded.
