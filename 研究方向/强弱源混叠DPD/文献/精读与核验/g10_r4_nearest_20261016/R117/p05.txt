4.2. Synchronous solution

   To synchronously estimate the coordinates of all sources in the entire 2D continuous plane is hard. Therefore, the proposed
BNOMP-CB has two simplifications. ◆ Discretize the continuous plane and initially estimate the source coordinates based on the
multi-frequency synchronous compressive beamforming model (Eq. (7)). ◆Identify each source sequentially. The proposed method
includes 4 processing steps to identify a new source. (a) Initial estimation based on the multi-frequency synchronous compressive
beamforming model with the discretized grids. (b) Local Newtonian optimization within the local 2D continuous plane near the initial
estimated coordinates. (c) Global cyclic feedback optimization for all the identified sources using the Newtonian method. (d)
Orthogonal solution for the estimated sources’ strengths at all frequencies. The following is the equation derivation and description for
the initial estimation, local Newtonian optimization, global cyclic feedback optimization, and source strength orthogonal solution.
