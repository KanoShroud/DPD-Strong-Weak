Abstract—Based
on
the
orthogonal
frequency
division
multiplexing
(OFDM)
system,
a
computationally
attractive
implementation for the traditional single source maximum like-
lihood (SML) direct position determination (DPD) algorithm
is proposed. The proposed algorithm implements fast Fourier
transform (FFT) to the received frequency-domain signals after
deconvolution. Then, the cost function for all points can be
obtained from the same FFT output set. As a consequence,
some repeated calculation in the traditional SML DPD algorithm
is avoided. Simulation results demonstrate that the proposed
modiﬁed SML DPD algorithm can achieve a comparable per-
formance to traditional SML-DPD while signiﬁcantly reducing
the computational complexity.
Index Terms—Time delay, direct position determination, fast
Fourier transform, maximum likelihood estimation, orthogonal
frequency division multiplexing.
I. INTRODUCTION
H
IGH-ACCURACY localization gradually become nec-
essary for communication infrastructures to enhance
quality of service. Hence, the integrated sensing and commu-
nication (ISAC) framework is emerging in many commercial
ﬁelds [1], [2], [3], such as nursing home management, virtual
reality and autonomous driving. In general, two steps are
required for source localization in ISAC systems. In the
ﬁrst step intermediate parameters are estimated, which are
then transferred to a central processing station to determine
the source position. However, due to the constraint that all
measurements must correspond to the same source position
and transmitting signal is ignored, two-step approaches are
always sub-optimal.
Different with conventional two-step methods, the direct
position determination (DPD) approach estimates the source
position from received signals directly without the information
loss caused by estimating intermediate parameters. Thus it
performs better than its two-step counterpart, especially under
large noise conditions. Based on the orthogonal frequency

been studied extensively [4], [5], [6]. Using angle of arrival
(AOA) and time of arrival (TOA), a work about DPD for a
stationary source was proposed in [7], where positions of sen-
sor arrays are also ﬁxed. Then for the scenario with multiple
sources (target and scatterers), [8] proposed a subspace data
fusion (SDF) DPD approach. However, this subspace-based
algorithm suffers from severe performance degradation at low
signal-to-noise ratio (SNR) levels, while it is well-known
that the maximum likelihood (ML) estimator could achieve
Cramér-Rao lower bound (CRLB) even if the SNR is low. [9]
proposed a decoupled ML DPD algorithm, which is iterative
in nature and possibly trapped by the local maxima. Recently,
a globally-optimal importance sampling (IS)-based ML DPD
method is proposed in [10]. Aforementioned feasible ML DPD
algorithms always have the optimal estimation performance for
solving the DPD problem. Nevertheless, their computational
complexity is still not acceptable for real-time processing,
especially when a large number of sources exist since single
source ML (SML) DPD estimator [11], [12] is inevitably
utilized for position estimation of each source repetitively,
which is implemented by exhaustive search. Furthermore,
on an ISAC device, the computational resource distributed for
localization is extremely limited. Hence, in order to estimate
position with ML concept using communication infrastruc-
tures, a computationally efﬁcient implementation of SML DPD
estimator must be researched.
A widely applied technology to reduce the computational
time in solving many parameter ML estimation problems
is the fast Fourier transform (FFT). For the ML estimation
of time differences of arrival (TDOA) [13], sinusoidal fre-
quency [14] and direction of arrival (DOA) [15], FFT resulted
in remarkable improvement from computational complexity
viewpoints. Referring to [12], the cost function of SML DPD
estimator is a combination of multiple ML cost functions for
estimating intermediate parameters from different receiving
sensors, which could be fast realized by FFT. It motivates us
to leverage the FFT for a faster implementation of SML DPD.
In this letter, we focus on the position estimation prob-
lem with static sensors and source based on the
OFDM
system. A modiﬁed SML DPD algorithm using time delays
is proposed by exploiting FFT, which enjoys prominently
high computational efﬁciency. When the transmitted signal
is unknown, the proposed method operates the FFT to a
series of frequency-domain sequences, which are obtained by
deconvoluting a received frequency-domain signal with that
from other sensors. While the transmitted signal is a prior
knowledge but the transmitting time is still unknown, FFT
is operated to received signals after deconvolution with the

V. CONCLUSION
In this letter, we proposed a computationally efﬁcient
implementation of the single source DPD algorithm based on
OFDM system. In the proposed algorithm, FFT is performed
to the received frequency-domain signals after deconvolution.
Then, for each candidate grid point, the DPD cost function
is calculated based on a speciﬁc FFT outputs subset that
corresponds to the point position. Thus, a large number of
repetitive computations in the traditional SML DPD algo-
rithm are eliminated. Simulation results show that with the
comparable accuracy, the proposed MSML-DPD has the clear
superiority over the traditional SML-DPD in terms of the
computational efﬁciency.
