## 2. 模型和数学接口

生成器按自由空间传播生成混合信号；固定载频下幅度与距离的倒数成正比，功率与距离平方的倒数成正比。估计器只获得站址、传播速度、同步关系、源数、统一噪声信息和共同搜索区域，不获得真实增益、真实位置附近区域、逐源频带或波形真值。

统一频域模型为

\[
\mathbf x_m=\mathbf A_m(\theta,\mathbf B)\mathbf s_m+\mathbf n_m,
\quad
\mathbf A_m=[\mathbf D_m(\mathbf p_1)\mathbf b_1,\ldots,\mathbf D_m(\mathbf p_K)\mathbf b_K].
\]

增益向量在所用频带和单次记录内不变。采用单位范数和非零参考分量实正的相位约束，调整增益时同步补偿源系数，保持拟合信号不变。不能为每站每频点分别引入自由增益。生成器的传播幅度与估计器的未知增益分别处理；位置导数不得偷偷使用生成器的幅度真值。

共同的波形消元目标为

\[
J(\theta,\mathbf B)=\sum_m\|[\mathbf I-\mathbf A_m\mathbf A_m^\dagger]\mathbf x_m\|^2.
\]

四站双源在消去波形并处理增益歧义后，有4个实位置参数及12个实增益自由度。通用优化器默认比较同一目标下的位置与增益联合求解。若改用四维位置外层加增益内层，必须固定内层初值、精度、停止规则和重启方式，标记近似剖面求解，并计入全部耗时；不能把不同精度的内层解当成相同精确目标。

允许的常规交替基线是：固定其他源的位置、增益和波形，减去它们的拟合分量，在当前源残差上构造最大特征值谱，更新位置、增益和波形，再联合重估全部源系数。它与投影后重拟合其他波形的条件评分不同，不能共用名称而不说明固定量。保留原解并逐步检查原始联合残差不增。

主比较不作逐站混合观测RMS归一化。若评价该变体，独立标记其数据缩放、噪声权重与目标，不把它写成经典论文的原版。显示谱的最大值归一化或相对dB仅属于画图。

## 3. 文献方法筛选与优先级

| 候选 | 观测与目标 | 承接动作 |

| Weiss–Amar MUSIC型DPD | 多源子空间及跨频增益约束 | 核验M=1、子空间秩、片段数与总时长；不能只取单频特征值 |
| Tirer–Weiss DPD-HR/MVDR | 逆协方差评分 | 核验分段、秩及正则化；输入不足须明确报告，不暗中增加快拍 |

| 未知增益版本A—D | 原搜索策略适配至新目标 | 主比较完成后补充；重新验证，不复用已知增益成绩 |

- Wang等 DPD-PDL（2026），[DOI](https://doi.org/10.1109/JSEN.2026.3693237)：本地文献R002，Zotero `5VI34FEP`；第II—III节、Algorithm 1、Remark 2及第V节。原仿真包含预设局部区域，不能给它额外真值区域；应检查复数转置、参数维度、功率谱定义和公式交叉编号，再从复高斯模型确认实现。对原公式的必要纠正须记录，不能静默宣称逐式复现。

- Fan与Liu全局—局部自校准DPD（2026），[DOI](https://doi.org/10.1109/LCOMM.2026.3675651)：R096，原观测依赖移动多阵元阵列，不能直接令M=1当作静态多站TDOA基线；可作全局初始化及局部求解的参考。
- 非圆稀疏DPD（2024），[DOI](https://doi.org/10.1016/j.dsp.2024.104564)：R093，原模型依赖多阵元及非圆性条件。BPSK波形本身不足以证明其全部先验可用于当前观测，暂不进入主比较。

## 4. 首轮数据与功率差协议

主条件已确认：四站单天线、K=2、N=16384、采样率100 MHz、完全频谱重叠（IoU=1）；独立BPSK/RRC波形、符号率10 MHz、滚降0.25。站址沿用当前四站系统，搜索区域沿用报告中的全区域；开发与正式评价使用不同源布局和随机实现，不针对混合评价结果选择布局。

功率差只取0、3、6、9、12、15 dB，定义

\[
\gamma=\overline P_{\rm weak}/\overline P_{\rm strong},\qquad
\Delta P=-10\log_{10}\gamma.
\]

功率为无噪声分量在全网的记录平均接收功率。固定源身份，0 dB不重新排序。每个基础样本只缩放强源，保持弱源、站间传播关系及噪声不变。每档保存实际分量功率以复核γ，不能仅保存配置名。

每个混合样本配对生成弱源单独存在、当档强源单独存在两种参照，使用相同噪声。弱源单源观测在各档复用，统计时不能把重复引用当作更多独立试次。单源K=1，混合K=2；频率预处理须来自相同观测规则，不能使用逐源频带真值。

弱源SNR通过独立开发集单源校准后冻结。先排除实现和明显漏搜问题，再选接近饱和的最低合适档位；不直接沿用旧3 dB，也不为弥补某个不适配方法无限提高功率。“接近饱和”的具体阈值、样本数和置信区间须在正式扫描前写入协议。开发未达到校准要求时，只提交诊断和待决策项，不进入混合主扫描。

待主场景完成后，再考虑N=4096和IoU=0.5。不得在本轮指导文档授权下自动扩大正式运行范围。

## 5. 执行顺序及进入正式运行的条件

1. **理论与接口核验。** 给出统一生成器/估计器接口、DFT与噪声约定、增益参数化、位置与增益的导数；复核单源及残差块LS—最大特征值恒等式、投影增量和退化频点。无噪声代数检查只证明公式和实现关系。
2. **小规模算法适配。** 核验候选方法能在相同短记录上执行。记录不适用原因，不把输入不足当成可比较的低成功率；不得从多个评价试次拼接协方差。
3. **单源校准与先导计时。** 冻结弱源功率、算法参数、频率处理、搜索初值及预算规则。随机优化器多种子稳定性与观测重复分开统计。
4. **提交具体配置。** 在正式运行前交付布局清单、每布局重复次数、种子清单、成功阈值、单源校准证据、预估总时间、设备内存/显存及输出目录。用户确认后由其在PyCharm/MATLAB执行，除非另行明确授权Codex运行。
5. **正式六档配对比较。** 冻结配置后运行；保存未完成和失败记录。不同准则比较完整算法；同目标求解器另报等时间结果，不只比较迭代次数。
6. **结果回读与有限补充。** 先形成主曲线，再以固定求解器比较谱初始化与空间覆盖初值，以及原始观测与RMS变体。是否进一步比较短记录、部分重叠或A—D，由主结果决定。

正式运行遵循仓库AGENTS.md：重新解析和核验输入身份；读写根隔离；新输出在 `outputs_e2e/` 下使用全新目录；冻结参考根只读；不训练、不访问独立test、不覆盖旧成绩。历史未使用布局是否纳入新评价集须在配置中明示，不能凭旧对话推断授权。

## 6. 输出字段与评价口径

逐样本记录至少包含：布局/观测/优化种子、源身份、N、IoU、实际γ与功率差、弱源SNR、方法及版本、观测预处理、估计位置、输出状态、匹配规则、逐源误差、成功标记、最终目标、停止原因、完整耗时与分阶段耗时。真值字段只供生成和独立评价；估计器接口不得接收这些字段。

有效双源输出使用最小总平方位置误差的一对一匹配，再按固定源身份统计。误差超过20 m仍属于有效位置输出，其误差必须保留在RMSE与CDF中。缺失输出或非有限位置单独统计，不得静默删除：成功率分母采用全部试次；CDF中缺失输出置于无穷误差；RMSE在有效输出上计算并同时报告覆盖率。无缺失输出时即为包含全部定位失败的总体RMSE。GOSPA可补充，但其截断值与20 m成功半径分开说明。

完整时间包含候选生成、频域/协方差处理、增益求解、局部精修、数据传输；GPU计时需同步。一次性编译、缓存建立和预热单列。各方法使用相同硬件、精度及线程约定；共享缓存的建立成本和复用范围必须对称。报告均值、中位数、P95，并给出超时比例；任何超时均保留当时可用输出和状态。
