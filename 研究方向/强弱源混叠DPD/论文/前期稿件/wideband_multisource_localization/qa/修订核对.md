## 举一反三的核对项目

| 项目 | 已补充或明确的内容 | 依据 |
| --- | --- | --- |
| 幅度模型 | 自由空间功率比、幅度平方根、公共系数并入波形；远场、天线与链路标定条件 | ITU-R P.525-5，附录2.3；不将其扩展为对基带相位模型的证明 |
| 频域模型 | DFT定义、原始点数归一化、带符号频率、有限观测窗的时延近似、频点筛选后噪声方差 | 既有生成器/物理代码；DFT代数及宽带ML文献 |
| 数值响应 | 站点处距离下限为1 m，导数适用于保护区外 | `g10/physics.py::atom`与`r4/bnomp.py`只读核对 |
| 信噪比 | 名义带宽与处理带宽区分、站均值定义、只改变另一源功率 | 现有50 MHz生成器与冻结结果配置 |
| ML与LS | 独立等方差复高斯噪声下的负对数似然；归一化不改变极小点 | 模型自身推导；Chen等（2002） |
| 波形消元 | 伪逆、投影残差、列缩放、梯度正交关系 | Golub--Pereyra（1973）；现有小矩阵核验 |
| 曲率解释 | 二阶光滑、局部唯一系数、Hessian分块；局部收缩所需正定/内部点/完整步条件 | 链式求导及Schur补；有限差分核验 |
| MUSIC | 片段快拍、零均值协方差、源秩/响应独立/白噪声条件、频点能量权重 | Weiss--Amar及既有宽带适配代码 |
| MVDR | 约束问题到逆谱的关系、加载相对尺度、逐频汇聚与DPD-HR命名区别 | Capon（1969）；既有适配公式 |
| SBL | 字典、非负功率先验、后验均值、负对数边际似然、更新与停止含义 | Nannuru等（2019）；冻结SBL代码 |
| 评价 | 门槛匹配与平方距离指派的不同用途；RMSE/CDF定义；GOSPA基数项与截断单位 | 已定评价协议；Kuhn、GOSPA原文 |
| 实验论断 | 不同批次不合并，候选案例和机制诊断各自标明样本范围 | 既有逐例JSON与审计，未读取运行中排名 |
