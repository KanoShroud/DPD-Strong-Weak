# G11-P2：固定Hann窗的实际定位效果

## 1. 结论

**常规Hann窗已经恢复了本批强弱不平衡条件下的大部分精度损失，完整运行时间基本不变；但它不是所有条件下都更好。** 等功率混合及孤立弱源的整体RMSE略有上升，表明减轻有限窗模型偏差与改变数据利用权重之间存在取舍。

这进一步支持P1的归因：当前少数构型的主要精度退化来自有限窗观测与逐频模型的偏差，不应继续归结为搜索不足。Hann是常规处理，本轮不是新算法创新证据；后续候选方法应面对经过合理有限窗处理的AP参照。

## 2. 执行范围

- 沿用P1的70条混合观测：零基困难布局13/14/15，对照布局0/4/8/12，每布局1000—1004五次实现，0/15dB两档。
- 另从同批数据提取35条不同弱源单独观测，弱源及噪声不变，不跨功率档重复计数。
- 固定比较矩形窗与周期Hann窗`hann(8192, sym=False)`，不扫描参数，不按真值选择窗。
- 混合观测直接调用冻结`AP_1_JOINT`，从20m全域网格开始搜索；单源对照使用同一AP第一源搜索和精修步骤。定位接口仅接收IQ、源数、公共配置及窗类型，不接收真实位置、逐源分量或历史输出。
- 两窗交错运行，采样率50MHz、8192点、±7MHz处理频带、全部原优化配置及20m评价保持一致。原观测不重新定标，Hann作用于所有接收站的同一时间索引。
- 完成105对、210次求解；完整批次约62.52秒，含单列1.07秒公共预热、检查和保存。先导为2条混合/1条孤立、6次求解，单独保存，不增加统计样本数。
- 数据用于机制验证，并非新的独立几何泛化集；所有结果保留，不按定位成绩剔除样本。

## 4. 噪声统计与模型口径

加窗后使用的频域数据是

\[
\widetilde x_k=\frac1N\sum_{n=0}^{N-1}w_nx_ne^{-j2\pi kn/N},\qquad N=8192.
\]

没有将FFT分母换成保留频点数，也没有人为恢复窗后信号功率。时间域白噪声方差为1时，频域协方差为

\[
C_{kl}=\frac{1}{N^2}\sum_nw_n^2e^{-j2\pi(k-l)n/N}.
\]

周期Hann窗下，各频点噪声方差为`3/(8N)`，相邻频点相关系数为`-2/3`，相隔两个频点为`1/6`；对应选频集合取上述协方差的子矩阵。直接DFT矩阵与解析核、原始FFT缩放和Parseval检查一致。

本轮保留原投影LS计算作为**加窗后的常规近似准则**。AP求解路径不使用噪声方差参数，没有把旧的独立噪声似然套到加窗数据上，也不把这个分频求和目标宣称为精确GLS/ML。后续若研究精确统计模型，必须同时处理频间相关与有限窗响应；不能仅补一个方差倍数便声称完成。

Hann压低两端样本，改善边界不一致，也改变了信息权重和噪声相关结构。本轮观察到的低功率差代价与这种取舍相符；不将35次实现的RMSE变化单独等同于严格方差定理。

## 5. 成本和数值正确性

- 70条混合观测平均完整算法时间：矩形窗0.36866s，Hann0.36938s；配对平均差约0.00072s。配对中位差为负，故不据此主张小幅加速或显著减速。
- 平均梯度调用27.83→27.96；两窗均评价20402个粗候选点。新增窗构造与乘法为`O(LN)`，本批Hann处理平均约0.14ms。主计算量没有实质变化。
- 所有70条矩形窗输出与历史AP保存位置完全复现，最大位置差0m。
- 140个混合终态的目标与解析梯度复核通过，Hessian均正定，最大剩余Newton修正约0.01092m。结果差异不是米级精修未完成造成的。
- 213项输入/证据身份通过，冻结源码与两篇论文源/PDF前后不变；评价重放、逐例JSON与汇总一致。新脚本语法编译与Ruff F/E9通过。

运行时间是当前设备、当前配对批次的描述；不跨批与P1诊断求解计时比较算法加速。单次计时不用于宣称亚毫秒差异。

## 6. 研究决策

状态：`G11_P2_COMPLETED / HANN_RECOVERY_WITH_PRECISION_TRADEOFF`。

1. 不再把矩形窗AP的这部分精度损失直接当作必须依靠新搜索方法解决的缺口。
2. 将固定Hann处理后的AP纳入下一轮必要参照，保留矩形窗结果以解释收益与代价；本轮不自动替换历史论文的模型或成绩。
3. 若继续研究，问题应集中为：如何处理有限记录边界，同时尽量保留低功率差、单源和不同构型下的有效定位信息。先核对已有常规处理能做到什么，不直接把换窗或调窗参数列为创新。
4. 当前只验证了既定70条混合观测，没有启动新场景、八方法重跑或更复杂的补偿器。进一步方法开发和独立验证另行制定方案。
