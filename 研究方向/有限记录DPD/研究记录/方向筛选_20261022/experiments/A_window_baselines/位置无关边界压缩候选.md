# 候选：位置无关、有误差控制的有限记录边界消元

状态：2026-10-23，已完成第一轮固定点数值验证，未完成盲定位、独立复核及最近邻新颖性核对。暂不计入已验收方向。

## 要解决的具体问题

有限记录模型能避免将强源的边界残差误认成弱源，但未知多源位置变化时，需要反复消去大量波形系数。直接解析Gram-Cholesky在短记录上已经便宜；随着记录变长，系数数目近似随记录长度增长，其稠密分解成本快速增加。

候选不是更换波形模型或换一个通用优化器，而是利用固定站间最大时延对应的有限缺失时间段，将反复求解转为逐频小块加一个由边界长度主导的修正。所用SVD、Schur/Woodbury均为已有工具。拟议贡献是否成立，取决于这一消元结构相对已有有限窗定位/快速Slepian求解的实质区别及完整性能证据。

## 位置无关压缩与误差界

使用[精确边界分解](F:/DPD_Strong_Weak/研究方向/有限记录DPD/研究记录/方向筛选_20261022/experiments/A_window_baselines/有限记录原理差异与边界Schur核对.md)中的H=D−VᴴV，其中H=BᴴB+λI。本文件λ为正规阵中的ridge值1e-6，而不是damp=1e-3。

每站缺失时间部分对源k是V0 diag(h_lk)，V0只由N、延拓周期P和频率集合决定。取V0的固定左奇异子空间Q_r，记T=(I−Q_rQ_rᴴ)V0；h_lk=g_lk exp(−j2πfτ_lk)，归一化满足Σ_l g_lk²=1/N。

将全部站的缺失行分别投影到Q_r，得到V_r。压缩丢失部分记为E，因为Q_r是正交投影：

    VᴴV = V_rᴴV_r + EᴴE，
    H_r = D−V_rᴴV_r = H+EᴴE。

各相位对角矩阵酉性给出

    ||E||²₂ ≤ ||E||²F = (K/N)||T||²F = η。

因此H_r≥H≥λI。设c=H⁻¹b、c_r=H_r⁻¹b，则

    c_r−c = −H_r⁻¹EᴴE c，
    ||c_r−c||₂ / ||c||₂ ≤ η/λ。

该界与具体位置和观测波形无关；可按给定λ与容许系数相对误差，在搜索开始前选择一次r。它使用标准正交分解与扰动工具，不将推导中的通用工具称为新定理。浮点舍入、分块求解的稳定性仍需实际核验；该界仅对当前有限Fourier模型成立，不覆盖其对真实连续波形的建模误差。

## 第一轮数值证据

预先选择旧holdout布局0、实现24000、15dB，仅比较两个记录长度1024和4096；每个长度检查真实位置及固定偏移位置。真值只用于设定数值核验点，不参与一个盲定位算法。每点两次交错运行，固定η/λ≤1e-6。

|---|---:|---:|---:|---:|---:|---:|---:|
|1024|762|1336|110|440|0.0235—0.0260s|0.0325—0.0706s|0.0350s|
|4096|2482|1336|110|440|0.328—0.377s|0.0919—0.103s|0.189s|

表中包含所有已测重复，无删除冷启动记录。1024点候选更慢，不能宣传普遍加速。4096点下仅一次求解的速度优势仍应计入准备成本；在反复更新位置时才有摊销空间。真实完整定位收益尚未测试。

四个点实际系数相对误差1.60e-8—8.07e-8，均低于目标1e-6；回代原FFT算子的相对正规残差不超过3.04e-13。两类解的目标值在保存精度内一致。实际控制界约4.34e-7和4.78e-7，保留其与实测误差的区别。

## 下一轮只验证三个问题

1. 独立审公式与代码，并定向核对缺失时间边界/Schur求解的最近邻；不以没查到相同名称证明新颖。
2. 在其他旧开发构型、位置与记录长度上比较固定点误差、稳定性和完整准备成本，加入相同精度的矩阵无关迭代参照，确认实际有利区间。
3. 前两项通过后再接入盲定位，验证完整耗时和定位质量；最终冻结版本后才使用新布局和随机实现。不同长度需要明确场景需求及有限窗失配是否仍造成实际损失，不能为提速单纯扩张矩阵规模。

若强常规实现已同样快，或真实定位任务不需要这一规模的有限记录模型，停止该计算候选。已获得的有限窗机制和可靠性证据仍保留。
