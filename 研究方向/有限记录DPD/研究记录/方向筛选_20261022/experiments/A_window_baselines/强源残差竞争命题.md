# 待验证机制：有限窗残差如何改变第二源排序

以下是条件评分的代数推导，不宣称基本投影或二次型为原创。它用于把现有现象变成可检验预测。

固定第一源位置，各频率用其响应的正交补P投影。弱源加噪声记为b，单位幅度强源在该投影后的残差记为e，强源幅度缩放为ρ。则条件数据为r=ρe+b。候选p的投影后单位响应为u(p)，条件增益为Q(p)=Σ_f |u_f(p)^H r_f|²。

对一个错误位置v与真实弱源位置w，令D_f=u_f(v)u_f(v)^H−u_f(w)u_f(w)^H，有

    Q(v)−Q(w) = ρ² A + 2ρ B + C,
    A=Σ e_f^H D_f e_f,
    B=Re Σ e_f^H D_f b_f,
    C=Σ b_f^H D_f b_f。

A、B、C在固定波形、记录窗、噪声及位置时与强源功率缩放无关。如果A>0，则存在有限幅度以上错误位置优于真实弱源位置。这不需要弱源SNR下降，也不要求第一源位置估错。完全匹配的强源响应使e=0，从而消除该直接随ρ增长的竞争项；其他搜索、噪声和可辨识性问题仍可能存在。

数值验证事前固定：沿用第十四轮八条基础观测，矩形/Hann/Tukey三窗，第一源固定真值用于隔离机制，错误探针固定为四个接收站坐标各加(1,1)m。不挑最大误差案例，不优化探针位置。在0/3/6/9/12/15/20/25/30dB核对二次式与真实条件评分的差值（乘回输入能量后）是否一致；另记录A>0以及排序反转情况。近站探针是机制诊断，不代表实际源在站边，也不作为新算法输入。

该恒等式并不自动构成论文创新。若要成为贡献的一部分，需要结合明确有限窗模型，给出可计算的偏差控制或复杂度改进，并完成最近邻核验。不能把目标函数代数展开本身包装成新的通用定理。
