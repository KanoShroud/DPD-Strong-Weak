## Chen–Hudson–Yao 2002

DOI 10.1109/TSP.2002.800420，Zotero YX23XVTW。已核对引言及II-A相关推导，论文明确讨论有限DFT的循环/线性时移边缘差异，零填充与相关噪声问题，并称近似最大似然。未知波形消元和AP已有明确来源。因而“发现有限窗导致DFT模型误差”不能作为本项目首次提出的理论贡献。

## DeLude等2023 Iterative Broadband Source Localization

DOI 10.1109/JSAIT.2023.3317094，Zotero 9LA8KRFN，arXiv 2210.11669。已读核心建模、迭代方法和多天线扩展。Slepian低维波形、贪心发现、最小二乘、多窗谱和压缩观测已经结合使用。一维部分存在频带可分假设，但空间扩展明确包含同中心频率，不得将整篇概括为不能处理同频源。其平面波阵列模型和空间—时间可分近似与本项目四站近场未知位置不同；这种差别目前仅构成适配差异，尚不是独立创新证明。

## 后续 Slepian Beamforming: Broadband Beamforming using Streaming Least Squares

https://arxiv.org/html/2312.03922v1 。本轮续读至3.1式9—13：按已知假设方向建立A[m,n,k]=载波相位×连续Slepian函数(t_n−tau_m)，联合空间时间快拍，以LS恢复未知波形系数。方向已知/给定的波束形成与本项目未知多源位置不是同一估计任务，但非可分连续时间建模与批量LS本身已有来源。后续干扰处理与流式章节仍需继续精读。

因此下一步应先实现或映射合理已有有限记录波形LS参照，再判断是否存在有价值的新求解结构，而不是将“用Slepian修复边缘”直接登记为创新。

## 第五轮追溯：未知方向也已有双线性建模

预先登记round5_query_plan.json，随后在公开搜索中发现Singh等2024《Robust Broadband Beamforming using Bilinear Programming》，作者页与arXiv 2406.16304v1一致。已核对原文II-A/B式1—4及未知角度区间的低秩算子表示：未知波形系数与未知方向对应的系数共同进入双线性逆问题。当前已读范围不能支持“此前Slepian方法都要求方向精确已知”的笼统说法。该文已进入近邻清单，尚待核对完整求解和实验；全文：https://arxiv.org/html/2406.16304v1 。

同时续读2312.03922v1至3.4/3.5：作者明确分解波形截断偏差、观测模型失配及噪声方差；其计算复杂度低的重要前提之一是固定方向的伪逆可预计算。未知二维多源位置下重复构造/消元的成本不能直接引用该固定方向成本。这里只提出待验证计算问题，未认定已有文献没有解决。

查询原始返回保存于round5_web.json、round5_followup.json；搜索引擎混合返回不是数据库穷尽检索，也不能用未命中证明不存在文献。硬件Slepian、量子成像、单LFM参数估计等旁支仅作筛选线索，不混入当前未知独立宽带双源证据。

## 第十四轮：Hao–Wan 2021全文解除一项关键歧义

《Importance sampling based direct maximum likelihood position determination of multiple emitters using finite measurements》，Signal Processing 186:108111，DOI 10.1016/j.sigpro.2021.108111。Zotero FHDNNWB3，PDF附件M9X23UIB，本轮已取得正文并核对第1—5节，原文保存FHDNNWB3_fulltext.json。该工作此前仅有出版社摘要，现不再列作全文缺失。

重要模型前提：第2节式3后明确假设发射波形已知（例如蜂窝前导序列），发射时刻未知；每站有阵列，逐源逐站复衰减未知。式12消去的是有限个链路系数，而不是每个源的未知宽带波形。其有限测量问题强调协方差/源间独立近似在有限样本下不足，仍使用分段DFT的逐频时移式2；没有据此验证本项目短窗边缘残差修复。

因此该文是有限样本多源联合目标及全局求解的重要参照，但不能从题名的finite measurements推断它已经采用本次有限时间未知波形模型，也不能直接当作同信息条件的算法复现。重要性采样与Pincus极限不等于任意有限样本数下都已获得全局解；实现若引用，须区分极限结论与数值近似。
