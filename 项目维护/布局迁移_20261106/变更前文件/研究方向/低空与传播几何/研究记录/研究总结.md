# 研究总结

按研究方向摘分；标题中的“当前”指当时状态，不代表新的运行授权。

2026-10-27二维收敛：当前研究为分布式单天线、未知同频双源与参数化多径，暂不涉及无人机、高度、墙面或环境恢复。Xia等2021年IEEE Systems Journal论文已覆盖上述主要组合，潜在贡献需落在其合理实现后的具体剩余困难，不能仅称场景首创。复现规则存在说明缺口不代表算法无效，不当作创新或性能证据；当前核验见[实验记录](实验结果记录.md#xia-preflight-20261027)。

2026-10-25研究任务收缩：用户明确聚焦多个单天线站、双无人机目标、DPD、同频混叠与多径，不再把未知墙面恢复作为主任务。生成器使用反射几何，不意味着估计器必须重建几何。基础验证先确保直达信息足够，再区分单源反射分量、源间混叠与接收功率下降。近延迟反射分量与高度参数的补偿是本轮得到的具体线索，但普通自由双径拟合尚未稳定，不将它直接写成理论创新。全LOS基础场景的结果不替代旧部分LOS问题。证据和当前边界见[实验记录](实验结果记录.md#core-multipath-20261025)。下方保留旧阶段认识。

2026-10-25机制归因修订：共同反射面的约束作用不必依赖跨源协同。本固定例中，三LOS的A单独也局部满秩；双源混合时结构作用保留，但不能包装为“另一源提供环境信息才使A可定位”。任意每频路径复增益会吸收时延，而未知常复增益仍可保留局部位置约束。下一研究价值需要落在实际未知源—路径关联与求解的必要缺口，而非把局部可辨识性当成新方法。见[机制拆分报告](outputs_e2e/research_admission_20261025/reduced_oracle/多轮核验报告.md)。

2026-10-25未知环境补充：不知道反射面参数不等于各条反射时延可以独立自由变化。共同环境可以产生跨站、跨源约束；本固定例在理想路径条件下支持其补足位置约束的可能性，但不构成实际盲混合定位或新颖性证据。完整面片尺寸可以不唯一而位置仍受到约束，应分开讨论“定位”和“重建地图”。依据与额外信息权限见[未知环境核验](outputs_e2e/research_admission_20261025/unknown_environment/未知环境核验报告.md)。

2026-10-25有限几何的稳定认识：直达被某个不透射平面挡住意味着源、站分处该平面两侧；该面单次镜面反射却要求二者同侧。因此，遮挡面与提供绕路的反射面可能不是同一面，不能给每个缺LOS链路自动补一条“同墙反射”。有限面片的范围、反射点与其他面遮挡应由统一环境决定；零路径和多反射都要保留。固定生成器通过不等于无地图定位可辨识，也不是理论创新。见[几何核验](outputs_e2e/research_admission_20261025/finite_scene/有限立面核验报告.md)。

2026-10-25三批19篇精读后的收敛：研究部分直达可见、未知混合波形下的源—路径关联与位置估计，而非重新包装共同支持、无公共参考或有限窗加速。低空遮挡有实测依据，但现有公开探测CIR并非当前任务的实测验证。循环一致、几何自洽与真实源身份必须分开；波形/信道分解歧义、支持模型自由度和允许先验应在小实验前明确。先查能否解，再查合理常规方法剩余不足，最后只推导一个机制驱动改动。详见[证据链](outputs_e2e/research_admission_20261024/bc_reading_20261025/研究依据与主张边界.md)与[收敛方案](outputs_e2e/research_admission_20261024/bc_reading_20261025/研究目标与后续计划.md)。本轮完成B/C10篇137页、累计284页；不构成新算法已成立或创新风险低的证明。

新方向准入认识（2026-10-24）：低空、三维、多普勒和逐源未知增益均已有原理近邻；单纯缺失可由零增益表示。更值得核验的是无干净逐源参考时，源相关反射时延与未知混合波形造成的可靠信息利用问题。任意自由信道可吸收位置，必须先明确可辨识约束；条件准入不等于创新成立。旧工具按需复用，不要求保住原论文算法，见[本轮准入报告](outputs_e2e/research_admission_20261024/准入报告.md)。
