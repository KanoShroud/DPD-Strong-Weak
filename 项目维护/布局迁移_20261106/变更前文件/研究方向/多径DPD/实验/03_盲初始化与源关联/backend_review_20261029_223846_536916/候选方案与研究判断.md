# 本轮结论：盲起点已经接通，多径精度收益在新布局得到复核

## 一句话

已形成一个可继续收敛的候选：**先用允许漏峰、避免重复解释的几何共识找到两个位置，再用同一段原始IQ联合处理两源及其多径。** 本轮不再依赖真位置附近起点、真实波形或真实信道。它已经能运行并有独立小批验证，但各工具均有来源，尚未完成与最强近邻的同信息条件比较。

## 这轮怎么走到这里

1. **先核对后端能不能接。** 用8个旧条件做仅用于诊断的真信道控制。有限记录确有模型残差，但已检查的真信道拟合位置仍较准，因此没有重开Hann/有限窗模型支线。真信道不进入后续盲算法。
2. **跑通8条旧案例的盲后端。** 几何起点、未知增益初始化、LOS拟合、反射初始化、共同多径拟合全部只接观测；多径4例整体RMSE从几何1.121m、LOS拟合0.700m降到0.450m。
3. **新布局暴露前端缺口。** 原前端在4个新布局×3实现的24条配对中出现公里级误选。全边平方误差可能把真附近候选拉走，再把同一源附近的两个解当作两个目标。多做末端精修无济于事。
4. **排除常规处理能否解决。** 同一解析候选池下，固定舍弃两条边有所改善，但遇到超过两条漏峰仍失败。截断误差使漏峰不再无限支配位置；共同覆盖使同一观测峰不能为两个重复位置重复加分。这两项有文献基础，不被包装成新优化理论。
5. **用全部开发观测接后端，而非只救失败例。** 12条多径记录的RMSE由几何0.718m、LOS拟合0.904m降为多径DPD的0.205m；12条直达控制未出现多径模型的额外精度优势。
6. **冻结后再生成4个新布局、每布局3次实现。** 不根据成绩挑构型，不改峰数、时延范围、阈值和迭代上限。最终24条全部输出可用双源位置。完整数值见[自动重算汇总](F:/DPD_Strong_Weak/outputs_e2e/mp_dpd/history/02_盲初始化与源关联/backend_review_20261029_223846_536916/核验汇总.md)。

## 独立复核的主要结果

|信道|观测数|稳健几何RMSE|同起点LOS-DPD RMSE|同起点多径DPD RMSE|
|---|---:|---:|---:|---:|
|无反射控制|12|0.662m|0.378m|0.386m|
|每链路两反射|12|0.914m|1.985m|0.445m|

多径组中11/12条观测的双源均方误差低于LOS-DPD，也有11/12低于几何输出；保留1例退化。四个新布局的多径DPD RMSE分别约0.246、0.439、0.466、0.566m，均低于对应的几何与LOS拟合结果。整体RMSE包含所有案例，不截断、不剔除异常值。最大单源误差约0.967m。

原全边几何在该独立批的直达/多径分别仅9/12、3/12双源20m成功；固定裁剪两边分别12/12、11/12；截断误差但仍独立选两峰，在多径为10/12；共同覆盖为12/12。这是前端机制对照，不代表完整OT或所有经典TDOA方法的上限。

成功率已饱和也不等于后端无价值：本轮后端价值体现在RMSE。反过来，多径模型并非在无反射时也更准，不能写成全条件支配。

## 具体机制与公式

对站对e=(m,n)，同源路径产生的相关时差为 `τ_nq0−τ_mq0+δ_nqr−δ_mqℓ`。所以反射相关峰可以在直达时差两侧，不能选最早相关峰作为直达。期望互相关包含同源各路径的复系数叠加；有限记录还保留源间交叉项。直达功率大于反射功率和，仍不保证混合相关图中每条直达峰都排进前六。

一个直观上界：若两站反射/直达功率比为ρ_m、ρ_n、反射数L_m、L_n，则同源非直达配对系数的模之和，相对直达配对系数不超过 `(1+sqrt(L_mρ_m))(1+sqrt(L_nρ_n))−1`。这是Cauchy–Schwarz直接给出的保守系数界，不是实际峰高或发生概率。本实验L=2、ρ≈0.251时该界约1.92，说明“直达功率占优”不能推出“所有反射相关项总影响小于直达”。不把这个基础不等式主张为新定理。

设候选位置p的几何距离差为d_e(p)，该边观测峰集合为T_e，`r_e(p)=min_{t∈T_e}|d_e(p)−t|`。旧全边目标是 `sum_e r_e²`：一条漏峰产生几千米残差，就可能压过其他正确边。诊断改用 `sum_e min(r_e²,h²)`，h=c/B固定约23.98m；残差超过h后不再产生位置梯度。h是带宽尺度，不是位置成功阈值，也非已证明的最优选取。

对每个实际观测峰i，只给候选p与该站对最近峰的匹配记分 `w_i(p)=max(0,1−r_e²/h²)`，其余峰为0。两个位置一起最大化 `Q(p1,p2)=sum_i max(w_i(p1),w_i(p2))`。同一个峰只计一次支持，因此两个同源近邻不能重复领取同一批证据。它是常规最大覆盖思想的具体适配，不是原OT论文的复现；共享TDOA仍被允许。

随后回到观测 `Y_f=H_f(p,η)S_f+N_f`。η包含未知复增益与正反射额外时延；同源反射共享同一未知波形。用 `S_hat_f=H_f^†Y_f` 消去波形，最小化 `sum_f ||(I−H_f H_f^†)Y_f||²`，并保留直达占优和时延约束。这里只借助几何找起点，最终位置仍由原始IQ联合拟合，不能把后端叫作只基于TDOA的两步定位。波形消元/约束GN本身不是原创。

## 对论文贡献的判断

**可发展的主线：无地图、未知复多径下的同频双源盲DPD，通过稳健几何共同关联取得可用起点，再用物理约束联合拟合消除多径引起的精度损失。**

已经形成的闭环是：真实有限IQ中的漏峰/重复解释 → 允许缺失且不重复计分的初始化 → 相同起点下的原IQ多径建模 → 新布局下的定位精度收益。不是通过反复扩大候选、提高迭代上限、筛掉坏构型获得的收益。

但创新边界必须清楚：Xia已研究非常接近的场景；Flood已有候选与缺失TDOA联合关联；Du已有未知波形多径ML消元。**本轮并未证明常规充分适配的MP-ML无法取得这些结果，也未证明共同覆盖优于完整OT。** 因此可以推进组合方法候选，不能宣告“已证明全新理论/低创新风险/达到SP录用标准”。[定向原文复核与链接](F:/DPD_Strong_Weak/outputs_e2e/mp_dpd/history/05_近邻复现与比较/backend_literature_20261029_223339_617632/定向文献复核.md)给出了具体重合处。

下一步只剩一个紧凑的准入问题：在同一观测和同一后端下，最近邻的充分实现能否替代当前前端；以及与Xia的同信息条件比较能否体现完整方法的必要价值。若近邻已经同样有效，就采用更简洁的常规版本，不为保留某个模块而调场景。此对比尚未执行，不能将本轮简化几何对照冒称该文原方法。
