### 1.1 如何判断一篇论文是否适合比较

核心文献按“候选发现／连续精修／联合更新／计算成本”组织，同时保留接收配置、实际输入和迁移条件。该流程不是方法分类全集；还需区分联合似然、贝叶斯联合估计、协方差拟合、贪心消除、区域覆盖及整图加速，避免只沿NOMP引用链选择对照。其他文献按用途压缩或归档：

- **直接基线候选**：观测模型接近，仍须核对源数、信道与计算预算。
- **条件适用**：满足原有条件时可比较，例如可分循环频率、单源或运动历史。
- **需重推适配**：思想可借鉴，但观测接口或可辨条件需要重新推导。
- **仅机制**：主要借鉴方法设计，原论文的精度不用于同条件排名。

研究用途与适用等级分开标记，同一篇文献可有多个用途：

| 研究用途 | 阅读时回答的问题 |
| --- | --- |
| 任务近邻 | 已有任务或联合输出与我们接近到什么程度，还缺哪项实际能力 |
| 性能对照 | 哪些方法适合原样使用或做合理适配，作为系统或模块比较的代表 |
| 方法来源 | 哪些表示、物理接口、训练或关联设计可以借鉴 |
| 场景扩展 | 增加运动、传播失配、局部污染等条件时，哪些工作值得继续使用 |

三级精读等级表示研究优先级，不表示阅读完成度；摘要近邻也可能需要优先补全文。逐篇用途见第2章与CSV的“研究用途”列。用途允许交叉；“性能对照”包含条件适用和机制适配候选，具体选择见§6，不等于首轮全部实现。

K表示信源数；DPD直接利用接收信号估计位置；TDOA是到达时间差；DOA只估方向；RSS是接收功率。这些量及相干IQ不是等价输入。标题链接指向原论文或专利，最后一列保留全文版本、证据位置和可用的Zotero检索key。R036为出版商完整网页，R113补读在线授权文本，R069已核读正式期刊版；有全文不等于库内一定有PDF。

### 1.2 阵列方法能否迁移到多站单天线

声学与RF标签不能代替模型比较。先检查方法真正使用的信息：单麦的跨站时差通常可借鉴，多阵元角度、语音先验、已知导频和运动历史则需要单独处理。实值声音的半谱公式迁移到复IQ时，应重写双边频谱和幅相关系；R025阵列部分本身使用光速，不能笼统归为声学方法。

判断的第一步，是检查位置变量出现在模型的哪一部分：

$$
\mathbf x_l(f)=\sum_k g_{lk}\,\mathbf a_l(\theta_{lk})\,S_k(f)e^{-j2\pi f\tau_l(\mathbf p_k)}+\mathbf n_l(f).
$$

令每站阵元数为1，站内角度响应可能变为常数，但跨站时延项不一定消失。**只依赖角度响应的方法不能原样迁移；保留跨站延迟的方法可以继续推导，但仍需验证可辨性。** 还应检查跨站相关是否被丢弃、同步与带宽是否足够、逐频任意增益是否吸收了时延，以及快拍、秩和源数条件是否成立。不能把“公式还含位置”当作“多个源一定能分开”。

“单个阵列”不一定是每站多天线。R001把空间分离的全向标量传感器组成网络，其球面时延模型可与多个单天线站点对应；全网的near-field也不等于单根RF天线的反应近场。R021/R001的AP机制应与仅靠站内角度响应的方法分开判断。

迁移难度按实际模型判断。有的方法需要重建物理接口，有的只需替换导向模型、调整输入并重新训练。二者都可以提供有用的适配，但应如实说明改动规模及作用。

### 1.3 本研究采用的创新判断标准

按“具体场景—关键假设—迁移障碍—针对性改动—验证结果”判断贡献。场景适配、任务扩展和系统整合都可以成立，不要求每个部件或定位原理全新。应用需求只能说明问题值得研究；还需说明针对性适配怎样改善明确场景下的可靠性、精度或成本。已有方法能工作，不等于这些取舍已经没有改善空间。

| 判断项 | 需要说明什么 |
| --- | --- |
| 现实需求 | 为什么需要少量单天线站点、有限观测和逐源频谱—位置对应 |
| 已有能力 | 最接近文献已经完成什么，在我们的观测和任务条件下还缺什么 |
| 适配或扩展 | 哪些改动保留时延信息、改善源身份关联，或增加有实际用途的输出 |
| 实际收益 | 联合质量、弱源可靠性、观测需求或在线成本中，至少有一项值得采用的收益 |

场景名称和输出头数量本身不说明价值。新增输出若解决了实际缺失，并与原任务可靠对应，可以构成任务扩展；已有思想通过必要适配解决新场景问题，也可以形成贡献。相似文献用于确定可借鉴内容和比较对象，不据此直接否定路线。具体贡献以验证结果为准。

### 1.4 迁移判断与证据强度

研究用途说明“这篇文献怎样帮助我们”，迁移判断说明“在候选场景中怎样使用”。二者分开记录。

| 迁移判断 | 含义 |
| --- | --- |
| 可直接使用 | 定位核心或指定组件的模型适用，主要需校准参数；不表示已完成全部联合任务 |
| 常规适配即可 | 替换导向模型、调整输入、重新训练或接入常规前后端，可先建立合理代表 |
| 需针对性改造 | 原方法依赖的信息缺失，或关键假设确实不成立，需要改变表示、统计量或求解方式 |
| 尚待核验 | 缺少模型推导或同条件实验，当前不能确定常规适配是否足够 |

判断范围和条件见逐篇说明。原文没有测试某个条件，不等于方法不能迁移；已有传播模型过于简化，也不等于网络在新模型上重训后仍无效。模型适用与实际质量达标分别核验。CSV的“迁移判断”“关键障碍与依据”对应本候选场景，文献原始事实仍以模型、实验及证据定位列为准。

判断时区分四层证据：现实需求说明问题值得做；原文未验证说明适用性尚待核验；普通适配不足需要同条件实验；针对性改动的收益通过同等可靠性或同等预算比较确认。不要求已有方法完全失效，也不要求所有部件全新。

## 3. 已有方法的能力与当前可改进之处

### 3.1 联合拟合与连续精修已有充分基础

R001、R021的AP／AML已经能够消去未知波形、逐源更新位置并联合重估源分量。R009、R010进一步提供逐源发现、连续精修和循环更新的求解结构。R011、R027也直接讨论强弱分量恢复。**“粗搜索＋连续精修＋循环消强”应作为方法基础，不能单独作为本研究的贡献。**

迁移时需要区分未知量：普通NOMP为每个分量估计一个复系数，R010的块来自互耦；但新增R117已经使用不同频率的传播响应、未知逐频系数和二维位置，不能再笼统说块NOMP缺少这一模型。R118也已研究联合BFGS，不过原生观测是去除已知导频后的CSI。R001、R117与R118共同构成当前方法关系的主要参照，具体差别见[近邻精读报告](outputs_e2e/literature/g10_r4_nearest_20261016/AP_NOMP近邻文献精读与方法差异.md)。

当前保留AP多候选联合精修为主候选，NOMP及其末端联合版本并列验证。场景适配可以构成贡献，但应解释候选排序、系数消元和位置更新带来的具体收益；不把“多频二维化”或“追加联合BFGS”单独写成首次提出。QNOMP统一引用R118期刊版。

局部求解还应保留非NOMP分支。R007结合AP初始化与EM更新，R008利用几何约束下的时延搜索更新位置，R014结合相关域估计和连续位置优化。后两者主要研究单源，可用于构建独立的初始化或局部求解参照；不能直接视为已经解决盲多源混合。

### 3.2 离网修正、候选发现与联合更新要分开判断

| 问题 | 已有能力 | 当前需要核验的部分 |
| --- | --- | --- |
| 真位置不在网格上 | R002、R009—R014等提供连续参数或字典修正 | 是否以较低成本达到所需精度 |
| 正确区域未进入候选 | R018、R030采用区域搜索或自适应网格；R012允许发现新候选、停用和重新激活 | 有限预算下，低粗网格得分的弱源区域能否被及时发现 |
| 强源估计误差留下残余 | AP、循环NOMP、R004消除和R005稳健投影均有处理思路 | 位置误差、抑制方式和候选遗漏各自造成多大影响 |
| 联合估计代价较高 | R002、R012、R013从参数字典和贝叶斯更新减少无效计算 | 多频未知谱和少站条件下的完整成本 |

离网量化误差与漏掉整个候选区域可能同时出现。连续精修能够修正已有候选，却不能保证发现没有合适初值的窄峰。候选回补同样已有先例，研究重点应是**依据什么信息分配计算、何时值得重新搜索，以及是否比普通增加初值更有效**。

R002是直接场景近邻：单天线多站、未知波形及链路增益、连续修正位置。它使用已知源数，只更新当前前N个峰的坐标，但全网格后验仍可重新排序，不能描述为永久删除其他候选。R012包含活动候选管理与重新发现，R013提供轻量贝叶斯更新；这些方法应与贪心消除共同覆盖，避免把研究局限在NOMP一条路线。

### 3.3 强弱源处理已有先例，少站与未知波形仍需核对

| 方法来源 | 借鉴价值 | 迁移时的关键条件 |
| --- | --- | --- |
| R004宽带互相关消除 | 在相关域消除强源，不要求时频稀疏 | 完整式与低成本近似分开；复IQ、跨站幅相和时延模型需对齐 |
| R005轮流定位与稳健投影 | 考虑强源位置不确定性，并限制对其他源的损伤 | 多传感器的投影自由度不能直接用于少站；宽带相干实验使用的跨频幅度关系也不能当作未知谱 |
| R006组稀疏拟合 | 从多源混合统计量联合估计空间与频率系数 | 不依赖单源占优时频单元，但源相关性和短记录统计误差需核验 |
| R003高分辨DPD | 支持单天线站点，提高空间谱分辨率 | 总记录长度、分段、协方差估计和加载必须合理 |
| R022循环特征定位 | 可分循环特征下分离同频RF源，包含实测 | 特征可分时应纳入适用方法；短记录能否可靠估计需要量化 |

R005已经讨论投影归一化分母接近零时产生尖峰的问题。分母随位置变化说明加速和搜索需要适配，不自动构成新缺口。少站下扩大零陷范围还可能损失可用定位信息，应同时关注抑强与保弱。

R026的重加权SRP与弱源恢复相关，但目前只有摘要。不能据此认定它依赖时频稀疏，也不能宣称其重合风险已被全文排除。

### 3.4 既要比较减少搜索，也要比较快速计算完整图

| 分支 | 代表文献 | 对当前路线的意义 |
| --- | --- | --- |
| FFT、插值与映射加速 | R015、R016、R017 | 完整细网格可能已经足够便宜，应先检查普通加速的能力 |
| 区域覆盖与自适应细分 | R018、R030 | 区域搜索已有先例，新的预算分配应与普通细分比较 |
| 连续局部求解 | R007、R008、R014及AP／NOMP | 少算网格之外，还可以降低精修代价 |
| 低秩补全 | R028 | 减少评分点数，但全图误差小不代表保留了微弱窄峰 |

R015包含未知波形分支，不能因OFDM标题而把它一概排除。R016、R017主要加速相关量到空间图的映射；当前多源条件投影评分含随位置和频率变化的归一化，不能直接用普通SRP或GCC替代并称为等价加速。可以用便宜图提出候选，再由原物理目标判断。

区域上界、停止误差能够增强方法，但其计算也有成本。没有严格区域界时，可以研究有效的搜索排序；不必把全局最优证明设为研究成立的前提。

### 3.5 条件补充与历史归档的作用

条件补充用于特定问题出现时调用：R019、R020提供DPD与相关估计基础；R023补充每点计算简化；R024、R027的参考波形条件用于判断优化方法如何迁移；R025服务有限窗建模；R029服务未知源数检测；R031服务学习式定位比较；R032服务有信道先验的增益估计。R032主要改善固定候选处的信道估计，不直接解决连续位置搜索。

历史归档保留学习联合任务、运动阵列、特殊传播和检测关联等阅读成果，不纳入当前全部必做对照。阵列、声学或RF标签都不能代替模型判断：依赖站内角度、已知共同波形或长时间积累的方法，须说明缺失信息如何处理；保留跨站时延的方法则继续评估常规适配的价值。

## 4. 研究场景、目标与证据边界

### 4.1 场景与现实需求

同频干扰排查需要发现被强信号掩盖的发射源。R022的同频RF实测及R112的间歇发射工作支持这一需求。当前聚焦**少量同步单天线站点、一次短时截获、多个独立未知RF波形、强弱不均且频谱重叠**，主要利用跨站时延信息定位。

短截获可对应间歇发射或共同可用记录有限。具体可用时长及处理预算仍需结合应用说明；当前采样点数是项目配置，不能直接写成业务硬限制。没有明确时限时，报告可靠性、耗时与内存的关系。

首先研究已知两源、静态直达传播和匹配链路。未知链路作为独立验证因素，随后再扩展未知源数与频谱—位置对应。不同站点由不同源主导可作为条件分层，不预设它就是主要失效原因。

### 4.2 研究目标与候选缺口

> 在少量同步单天线站点的短时混合IQ中，以给定计算预算提高强弱重叠源的定位可靠性，并降低联合连续精修的代价。

当前候选缺口是：**盲多源条件下，候选发现与连续更新之间仍可能存在可改善的弱源可靠性—成本取舍。** 关注的机制是粗搜索漏过窄峰，以及源估计变化后原有候选判断失效。强源残余是否加剧这些问题，由控制实验判断。

已有方法成功定位并不否定这项研究。贡献可以是相同可靠性下更省计算，也可以是相同预算下更少漏弱源；需要证明收益来自针对性处理，而不只是增加计算或削弱对照。

### 4.3 当前证据支持什么

G8-R6保持投影评分不变，增加搜索充分程度后恢复了部分失败，说明当前实现存在搜索损失。它来自选出的长记录诊断条件，尚不能代表完整检查集或原短记录表现。真实位置评分更高也不等于已经证明连续联合目标的最优解位于真位置。

因此，下一步优先研究搜索与求解成本；有限窗误差、强源残余和信息不足保留为待区分原因。旧DPD／HR谱的诊断结论不直接外推到当前投影评分。

实验事实以[实验结果记录](实验结果记录.md)为准，阶段方法见[实现文档](统一端到端模型研究.md)，执行状态见[当前任务](当前任务.md)。

## 5. 拟采用的方法方向

### 5.1 总体思路

**优先考察“按投影后响应分配搜索预算，允许候选回访，再做联合连续精修”。** 波形消元、AP、块NOMP和联合系数重估作为已有方法基础，重点研究候选发现与后续精修如何配合。

普通粗网格主要根据已采到的峰值选择初值。拟议处理还关注区域内响应变化：某个区域中心得分不高，但投影后的响应变化很快，中心点可能不足以代表整个区域。这类区域值得进一步检查，而不是仅因未进入前几个峰就永久忽略。

这是当前优先验证的设计方向。其价值要与普通多初值、自适应细分、贝叶斯候选更新和整图加速比较后确定。

### 5.2 方法应具备的三项能力

| 能力 | 设计重点 | 需要证明的作用 |
| --- | --- | --- |
| 有依据地分配搜索成本 | 结合几何、带宽及投影后的响应变化判断哪里值得细搜 | 相同评分次数或耗时下，更可靠地覆盖有效候选 |
| 允许重新发现候选 | 源位置或残差发生变化后，重新检查有价值的区域 | 减少早期选择错误造成的持续遗漏 |
| 候选与联合精修保持一致 | 用同一物理目标复核候选，并联合修正位置与源系数 | 防止便宜近似或孤立局部更新破坏完整定位结果 |

几何和带宽尺度是简单参照，投影后响应是否提供额外价值需要消融。回访、连续精修都已有先例，贡献应落在具体判断方式及其可靠性—成本收益上。

只使用局部变化估计时，将其作为搜索排序依据。只有获得有效区域界，才报告相应的剪枝或停止保证；条件位置更新的保证不扩大为整个多源问题的全局保证。

### 5.3 方法选择的约束

- **保持信息条件一致。** 未知波形不能替换成真实源谱或已知导频；未知增益需要合理跨频约束，避免吸收时延信息。
- **先优化常规计算。** 提前评估缓存、批量评分与完整图加速，避免用复杂搜索解决普通实现低效。
- **区分提案与最终判断。** 便宜相关图、时延估计或插值可生成候选，最终结果仍由所选联合物理目标评价。
- **少站下保留可用信息。** 稳健投影和源数扩展须考虑自由度与可辨性，不能只靠残差持续下降增加源。

具体评分推导、区域准则、候选更新规则、数值处理和停止参数由实现文档确定。本综述给出选择这些细节的依据与评价标准。

### 5.4 后续扩展与备选方向

核心定位机制成立后，再加入未知源数、空场、三源和频谱—位置对应，并保留“传统定位＋轻量关联”的系统对照。

有限窗建模仅在搜索充分后仍出现可归因的短窗拟合误差时启动。R025的带限波形表示可借鉴，同时比较普通窗口处理，避免把换一种表示本身当作贡献。

现有E2E模型保留为系统基线。若候选排序、可靠性判断或重复求解确有学习收益，再引入网络，并说明训练成本和分布外表现；不预设必须端到端训练。

## 6. 对照方法与公平比较

### 6.1 核心对照覆盖的方法分支

| 分支 | 代表选择 | 比较目的 |
| --- | --- | --- |
| 联合似然与连续求解 | R001／R021的充分AP／AML | 判断当前物理目标在充分求解时能达到什么程度 |
| 贪心发现与循环精修 | R009／R010的合理块NOMP适配 | 比较候选发现、连续更新与联合重估 |
| 联合稀疏／贝叶斯估计 | R002或R012选一个主要代表，R013按需补充 | 避免结论只建立在硬消除方法上 |
| 搜索与映射加速 | R015—R018中选择适合当前目标的代表 | 比较普通区域搜索与快速完整图的成本 |
| 强源处理 | R004完整宽带消除；R003作为高分辨谱法参照 | 区分搜索改善和抑制机制的收益 |
| 非NOMP局部求解 | R007／R008／R014中选择适用组件 | 检查几何约束或相关域更新能否更简单地解决问题 |

这是一组能力覆盖要求，不要求逐篇复现。具体代表、适配范围和实现顺序在阶段方案中确定。R005、R025、R029分别随稳健投影、有限窗和未知源数主张启用。

### 6.2 比较原则

研究搜索时保持评分不变；比较不同完整方法时，允许各方法采用合理的原生初始化和求解流程。不能强迫所有对照使用本项目的候选模块。

各方法使用同一总记录、搜索区域、链路知识和硬件条件。已知K与未知K、已知增益与估计增益、已知参考与盲观测分别比较。采样点数不等于独立快拍数。

计入预处理、候选生成、复评分、投影或字典更新及连续求解的完整成本；离线预计算与在线处理分开报告。失败、超时和预算耗尽也纳入结果。

### 6.3 必须排除的简单解释

| 拟议收益 | 必要对照 |
| --- | --- |
| 更少遗漏弱源候选 | 扩大Top-K、增加初值、普通区域细分 |
| 联合精修更有效 | 充分AP或普通循环NOMP |
| 搜索更省计算 | 优化后的批量评分、缓存和完整图加速 |
| 投影后响应准则有用 | 仅用几何／带宽或当前得分的准则 |
| 候选回访有用 | 相同总预算下的不回访版本及常规重新搜索 |

若简单处理达到同样效果，采用简单版本。研究收益不以所有已有方法失效为前提。

## 7. 验证路线与决策依据

### 7.1 从机制到完整系统

| 研究环节 | 主要问题 | 对后续选择的作用 |
| --- | --- | --- |
| 建立可信求解参照 | 只改善求解和普通加速，能恢复多少失败、需要多少成本 | 确认是否仍有值得改进的可靠性—成本问题 |
| 核验针对性搜索 | 响应变化、候选回访与联合精修分别贡献多少 | 选择一项主要改动，删除无独立收益的部件 |
| 检查适用范围 | 原短记录和独立几何、波形、功率差下是否仍有效 | 确定方法边界，避免依赖挑选的长窗案例 |
| 扩展联合任务 | 未知源数和频谱—位置对应能否保持可靠 | 形成完整系统及相应检测评价 |

短记录验证贯穿核心方法选择，不在方法全部定型后才补做。阶段划分、数据清单、资源预算、运行入口和验收阈值由实现文档记录，执行状态由当前任务记录。

### 7.2 评价应回答什么

已知K阶段主要评价弱源定位成功率、源集合误差、尾部失败与完整成本；未知K阶段再校准空场虚警，并在固定虚警水平下比较弱源召回。不能直接照搬固定栅格下的CFAR门限用于自适应位置搜索。

过程证据关注候选覆盖、精修是否改善结果，以及源更新后是否出现新的有效候选。近似图或补全方法还需检查弱峰保留，不能只看整图平均误差。

分别改变记录长度、网格偏移、功率差、几何和频谱重叠。研究强弱干扰时固定弱源接收质量，避免把弱源自身变差混入结论。采用配对重复和不确定性区间，调参与独立验证分开，封存test不参与方法选择。

### 7.3 继续、简化与转向

| 验证结果 | 研究决定 |
| --- | --- |
| 相同可靠性下更省计算，或相同预算下更少漏弱源 | 保留贡献，并明确适用条件 |
| 普通适配有效，专用处理仍有稳定额外收益 | 继续研究，贡献定位为针对性改进 |
| 普通加速或充分求解已达到同等效果与成本 | 简化系统，停止该项改进主张 |
| 搜索充分后仍有明确有限窗误差 | 再启动有限窗模型方向 |
| 可用观测不足以支持目标 | 调整观测或目标范围，不以增加模型复杂度替代信息 |

## 8. 预期贡献与文档分工

论文拟围绕一个贡献展开：**针对少站短时盲观测中的强弱重叠源，利用投影后响应指导候选搜索，并与联合连续精修配合，改善弱源定位的可靠性—成本取舍。** 具体改进幅度和适用边界由验证确定。

AP、块NOMP、贝叶斯更新和区域搜索是方法来源。一般离网修正、循环消强、候选重新激活，以及归一化分母的存在，都不单独作为新贡献。允许方法改动幅度适中，但必须说明场景困难、技术选择与实际收益之间的关系。

后续按“可信参照 → 针对性改动 → 短记录与独立条件验证 → 完整任务扩展”推进。问题机制、强代表比较、关键消融和完整成本构成面向目标期刊的证据主体。
