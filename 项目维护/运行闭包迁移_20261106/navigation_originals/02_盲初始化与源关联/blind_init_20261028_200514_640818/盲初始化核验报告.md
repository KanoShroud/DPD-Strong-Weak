# 仅凭观测能否找到可用起点？

2026-10-28。结论：已从近真值局部测试走到观测驱动全域初始化；两个无反射控制成功，一个多径案例得到亚米结果，另一个仍未获得可靠起点。尚不具备扩大性能统计的条件。

## 1. 本轮做了什么

复用原两个构型，每个构型生成无反射和两反射的配对观测。两组的源波形、LOS增益和功率完全相同，只删除或保留反射。五站、未知同频双源、二维位置，每链路最多两反射，直达功率大于反射分量功率和；没有引入地图、已知比特、干净参考或真实路径信息。

仍使用96个理想频率点的无噪模型，不是有限记录IQ实验。所有观测均允许最多两反射，求解器不知道哪条观测实际没有反射。生成和事后评价使用真值；求解接口只接收混合观测和频率，使用公共站点、范围及路径约束。源标签通过最小平方距离匹配，真值不参与筛选、步长或停止。

流程：**全域单源评分 → 3个首源候选 → 各自从拟合残差找3个第二源 → 9对LOS联合拟合 → 按观测目标保留3对 → 估计路径起点 → 同目标多径局部更新。**

20m网格错开半格，不包含这批真实位置；100m候选去重不作为真实源最小间距先验。LOS阶段最多100次函数计算，多径阶段最多60步、每步12次阻尼试探。参数未依据本轮结果修改，见[冻结协议](../盲初始化核验协议.md)。

“初始”是最终选中分支在LOS联合拟合后的结果，“最终”是同一分支的多径更新结果。RMSE为单案例两源平方位置误差均值开根号，不是多次独立统计。

无反射控制说明未知波形和未知站间复增益没有阻止当前流程仅凭观测找到两个位置。多径构型0说明这个案例的观测驱动起点可用。但构型1未通过，不能进入大规模方法排名。

四条完整求解共55.82秒，单条13.09—14.70秒；另有约14.02秒单例前缀，不计独立样本。不与历史不同流程作严格计时比较，也不宣称达到最终算法的速度要求。

## 3. 困难案例的两个问题

构型1真位置为(2100,1700)m与(2500,2150)m，仅供事后解释。首峰(2090,1710)m接近源A，但扣除其近似贡献后，三个第二源候选为(2510,2910)、(2230,2070)、(2450,2730)m，没有覆盖源B附近。第二首源分支(2550,2110)m与(2090,1690)m构成九对中最接近真值的一对，粗双源RMSE仍为46.37m。

这对位置在LOS连续拟合后，A误差2.87m、B误差49.73m；也是九对中误差最小的一对，最终按观测目标选中。因此不是“正确分支已经存在，只是最后选错”。只能说本残差候选/LOS初始化没有给出同时准确的两源位置，不能推广为所有观测评分均失效。

另一个问题来自后续求解：所选终点最大反射/直达功率比0.9999999999999998，接近约束边界；缩放梯度约0.0259，未达到1e-7。提高阻尼并拒绝越界步，不保证能够沿边界调整。

离线将负梯度方向投到约束闭包，再取0.5倍内部可行步，原目标从0.020410805降到0.020304667。说明仍有可行下降方向；不能把“本次没有找到可接受步”写成“目标已充分收敛而定位失败”。该试探未替换保存位置，也未继续优化。

12个保留分支中，2个达到梯度条件、1个达到60步上限、9个因试探预算内无可行下降步停止。固定离线探测在10个非梯度终点找到超过1e-12的目标下降；其中构型0所选分支下降仅约1.28e-12，不能夸大为明显优化不足；构型1的下降清楚可见。

## 4. 公平性与正确性检查

- 最大特征值评分与直接SVD/最佳秩一重建一致；未使用生成器1/d幅度当已知响应。
- 位置导数保留波形消元的两项，与有限差分一致；阻尼分块约化与同一联立线性子问题一致。
- 基础12项、正式21项和事后45项身份/目标重放/单调接受/重复检查通过；前缀与完整批首例的输入、最终位置、选分支和分支目标完全相同。
- 保存观测及协议/依赖源码，运行前后核对哈希。求解调用链不读取真值文件；静态字符串检查仅为人工调用链检查的补充，不单独作为泄漏证明。
- 所有失败/触顶分支保留。原result.json与离线audit.json分开，不将诊断步当最终算法输出。
- 96点理想频率容量、有限IQ及有噪统计尚未验证，不将此处旁峰直接推广到实际接收系统。

**数值检查通过不等于性能通过。边界处理限制已经暴露，本批不是充分适配强基线的最终成绩。**

## 5. 下一步边界

已有进展是：不使用真实波形、增益、位置，常规流程在无反射及一个多径案例中形成可用起点。不再只有近真值单步测试；但还没有完成可靠盲双源多径定位，也没有证明新的理论瓶颈或算法贡献。

建议保持当前观测及候选，补一次能够处理边界可行方向的常规局部求解核验。不能通过提高DRR下限、避开难样本、增加候选或无限加迭代换取通过。若恢复，先前有求解实现不足；若仍失败，再判断候选/路径初始化是否存在值得研究的稳定机制。暂不扩大有噪统计，不返回真值附近起点。
