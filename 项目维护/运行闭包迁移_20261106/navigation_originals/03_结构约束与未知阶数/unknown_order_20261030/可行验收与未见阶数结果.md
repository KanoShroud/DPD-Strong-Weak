# 可行终态验收与未见阶数核验结果

2026-10-30。**获准的数值验收修正及后续小批核验均已完成。最新12条记录全部正常统计停止，随后两条未见3路径新观测也通过。没有启动640条，未改变模型、先验、容量、种子、梯度门槛或迭代预算。**

## 1. 实施及正确性

保留`reference.py`、`reference_pg.py`、`cross_order.py`及其全部历史证据。新增`reference_feasible.py`：对原优化器返回点作原集合投影，在实际变量坐标重新计算可行性、原目标和原投影梯度。要求不劣于本次拟合的可行初值，沿用原1e-10下降数值容差、1e-7可行性及1e-7驻点门槛。若仍未驻点，最多执行一次已批准的下降PG步，仍计入原300轮。没有新增KKT工具，也没有改变原优化器内部迭代。

新验收对每次调用统一适用。真实位置、真实波形、真实路径数/间隔/支持和总反射功率均未进入求解或验收。`feasible_gate.py`显式替换旧驱动的后端函数，复用冻结的前端、搜索与生成器，未修改这些源文件。

- 最终验收重放：1,098项检查通过，耗时19.281秒。首次预检后补充了断言与生成输入快照登记，再重新预检；最终依据是`feasible_audit_20261030_215804_594959`，不把较早预检冒充当前版本验证。
- 12条中仅L20_HIGH返回轨迹发生改变，完整从原IQ重跑。其余11条所有已存调用的变量和停止判断精确一致，按确定性分支等价复用。
- 重跑合并批：8,481项运行/身份检查通过；67项复核通过，包括受影响案例原盲初始化、IQ身份及第13项之前的精确轨迹一致性。所有12条正常统计停止。
- 按原条件自动执行两条未见3路径：2,177项运行检查、14项复核全部通过。没有在12条后调整参数。
- 本轮Python文件的语法编译、Ruff F/E9通过；冻结模块和输入SHA核对通过。

## 2. 定位结果

每行均为两个既有几何、每几何一个实现，包含四个匹配后的源误差。RMSE未截断；样本少，不作高置信泛化或显著性结论。原六条件各几何共享波形/噪声/路径池，彼此不是完全独立重复；未见3路径使用另外的波形、噪声、信道随机实现，但几何仍为原预登记的20/40。

无反射两条仍轻微损害；其余12条多径观测的成对平方位置误差均较各自LOS降低。这是逐观测的描述，不是12个独立统计重复。

原截停的L20_HIGH现在选到40项后停止，两个源误差0.110998、0.238457 m，终态梯度映射2.86968e-8。这次没有采用旧截停位置作为初始化；数值修正本身没有直接把误差变好，而是让后续正常候选检测和拟合得以执行。

## 3. 计算成本与公平性

L20_HIGH完整重跑871.103秒，约14.5分钟。其中重复联合拟合849.174秒，新验收评价约4.511秒；40次增项拟合累计2,766轮，单次最高273轮，没有突破300轮上限。该例成本主要不是投影或增加验收检查，而是重复联合拟合。

两条未见3路径合计批次205.537秒，完整单例均值101.499秒；联合拟合分别91.652、80.385秒，验收评价分别3.347、2.998秒。计时含IQ盲前端、搜索/检查、拟合及结果记录，数据生成单列在批次时间中，不混为单例求解成本。

11条复用记录保留历史墙钟值，不能把这些数值平均成“新版本同批完整耗时”。例如同一L20_HIGH完全相同的前12步，旧拟合计时25.527秒，本次60.667秒；这表明跨批墙钟不可直接用来归因包装器提速/减速。报告没有把旧约4分钟的另一个HIGH案例与本次14.5分钟的不同案例当作受控速度比较。

本轮只建立/修正同信息未知阶数常规参照。胜过忽略多径的LOS-DPD说明显式多径处理有价值，不等价于胜过现有多径强基线。旧48条历史结果仍按原版本解释，没有拼接成新版48条正式统计。

## 4. 与定位目标直接相关的轨迹证据

按预定全局分量预算0、5、10、20、40重放保存状态，较早结束的记录沿用其终态并标记实际阶数。没有据真值选取中间最优点，也没有新增提前停止算法。

4反射条件的两条观测中，从10项增至20项：

- L20_L4归一化拟合目标0.100987→0.083685，但两源误差由0.3130/0.6025 m变为0.4884/0.6089 m。
- L40_L4目标0.099867→0.084572，两源误差由0.1971/0.3061 m变为0.3298/0.2604 m。
- 两条总体RMSE由0.3852 m增至0.4433 m；继续到终态又降至0.2074 m。

**因此，拟合目标单调改善不意味着位置误差单调改善，也不能简单据一次位置修正幅度决定增径/停止。** 这里的位置误差仅在事后评价时可知；不能把这张轨迹表直接转化为算法可用的真值规则，更不能据此设置“固定在10项停止”。它支持位置导向复杂度研究的动机，不证明新准则已存在或必然胜过完整拟合。

## 5. 当前研究判断与下一决策

### 已获得的实质进展

1. 取消真实路径条数、间隔和支持信息后，常规增项拟合依然在多种条数和未见条数的新IQ中改善定位。
2. 总反射功率可以超过LOS，算法不需要把“LOS大于全部反射之和”作为先验；仍保持每条反射弱于LOS的公开假设。
3. 原数值截停已按统一规则解决，未靠放宽门槛、改生成器或减少难例来过关。
4. 进一步确认了精度—计算代价及拟合—定位不一致这两个值得解释的现象。

### 尚未完成的论文增量

本轮没有提出新的统计选阶理论，也未证明未知双源/估计波形条件下的检验校准。通用逐项拟合、变量投影、既有约束求解和可行性验收仍是常规工具。位置风险单步评分的既有失败仍保留，不因本轮常规参照成功就把它重新称为有效候选。最近邻边界沿用[已核对材料](文献与方法映射.md)，本轮没有新取得全文或新完成查重。

当前已达到**预定小批数值和条件迁移准入**，但不自动等价于大规模正式实验、SP论文贡献或位置风险创新准入。尤其不能用更大样本量替代尚未成立的观测驱动位置风险估计。

### 建议下一关及需确认的科研取舍

建议冻结当前版本为常规未知阶数参照，结束数值修补；下一关只检查：**在不知道真实位置、真实路径数且可能遗漏多个耦合分量时，能否从观测估计“增添这些分量对位置MSE的收益”，并给出可检验的适用条件。**

应明确纳入原风险公式遗漏的偏差交叉项与非零残差问题，不以残差下降或位置变化量替代风险。先给出可计算量、所需假设和能否定它的小验证，再设计算法；如果这一步不成立，不应自动转为扫阈值或堆叠增删模块。

需要用户确认的取舍是：继续把上述**位置导向复杂度**作为创新主线，还是接受当前完整常规流程的场景化贡献、转向同信息强近邻比较。推荐前者，但仅推进理论可行性关，不承诺必能得到新算法，也不在此轮擅自制定新的偏差估计或验证协议。640条仍不启动。
