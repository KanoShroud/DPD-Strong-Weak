# 常规未知阶数多径参照：结果与下一关

日期：2026-10-30。当前结论：不提供真实路径数、最小间隔或生成时延范围，常规递增多径拟合已在本批获得明确定位改善；尚未完成跨阶数验证，也没有据此确认新的理论贡献。自动推进停在数值停止衔接的协议边界，而不是宣告研究路线失败。

## 执行过程

1. 定向核对阶数选择及搜索校准依据，登记[执行协议](执行协议.md)和[来源范围](文献与方法映射.md)。当前实现是常规适配参照，不是IARD/VB-SAGE原版复现。
2. 第一版4条短测：一个中间阶数的SLSQP正常结束，但共同投影梯度略超门槛；结果保留。
3. [预先登记一次数值重定尺度](数值停止核查补充.md)，不增300次总预算、不改目标/约束/阈值。重新从盲起点完成4条短测，1473项检查通过，4条均统计停止，耗时126.083秒。
4. 冻结同一源码，完成48条保存观测配对，18,455项数值/身份检查通过，耗时1545.371秒（25.76分钟）。这些重复数值断言不是18,455次独立定位实验。
5. 完成100项汇总审计和32项保存终态归因。未删除失败、未按真值挑输出时刻、未修改旧算法或输入。

48条是8个既有构型×3个实现×无反射/多径；每种输入24条。短测是其子集，不另计独立样本。多径数据仍为旧两反射生成条件，不能把本批称为不同路径条数的完整泛化证据。

## 3. 没有给算法真实路径数，但不意味着恢复了真实路径

- 各链路从零反射开始，逐次决定是否增添分量；每次同时重估两源未知波形及全部现有参数。
- 真实位置、真实波形、真实路径数/增益/间隔/支持不进入选择或求解接口。与上一轮的LOS终点逐例复核一致。
- 仅使用已知双源、站点、采样/带宽、单条反射不强于直达的共享模型；没有总反射功率上界。
- 多径组最终辅助项数11—26、平均20；其中11项是数值提前停止，不是统计选出的最终阶数。零反射组11/24仍增添1—9项，平均2.125。
- 零反射9/24、多径5/24的结果包含超过相位周期一半的时延，存在周期别名或失配吸收的解释风险。不能称这些都是物理反射。一个多径终态接近单位增益边界，最大相对功率1.000000000000708，是闭包数值容差内的边界，不作严格小于1的证据。

定位是最终目标，因此不要求辅助路径条数等于真实条数；但也不能把“有效表示”偷换成“物理信道已正确辨识”。这里仍须明确频域模型近似的适用性。本轮没有恢复Hann/周期数据比较支线，也没有偷偷收窄时延搜索域。

## 4. 为什么暂未进入跨阶数小批

47/48条由原统计准则正常停止；未触及64项容量上限。唯一例外L40_R302_MP在第11项停止：优化器内部正常结束，经一次既定重定尺度后，原坐标投影梯度仍为1.0617386e-7，略高于固定1e-7。累计18次迭代，没有用完300次预算。

有限归因表明：

- 最大梯度分量中心差分与解析值一致，没有发现梯度实现错误。
- 投影梯度和GN局部可行试探仅移动位置约3.39/2.08微米，目标下降约1.06e-14/1.65e-14。它们是局部数值尺度诊断，不是位置误差上界或全局收敛证明。
- 下一个候选分数521.44，原门槛38.72，说明它不是因为“没有可加入分量”而停止。
- 所有试探都未替换正式输出，也未执行下一次增径。

补记试探终点梯度的离线重放显示：一次单位投影梯度试探将共同梯度降至1.8745e-8，GN试探为1.6226e-8，均低于原门槛。原门槛无需放宽；这两个点仍仅是诊断，不计作正式算法结果。补记没有新增定位求解，旧诊断目录保留。

因此，不能把这一例标为完整自动选阶成功；也不能把它解释成方法无法定位。本轮已对同一数值停止问题作过一次有界修订，复现后按协议不继续自动改变设置。跨阶数协议与驱动已准备，但未放行、未运行；未见3路径检查和原640条均未启动。

建议决策：保持原1e-7门槛与300次总预算，是否允许在内部停止仍不一致时使用一次经过目标下降和可行性验收的投影梯度数值收尾，再进入已冻结跨阶数小批。优先投影梯度，因为现有检查已经计算该方向，无需额外构造GN求解。它不是新算法贡献，不按真值接受；若仍不满足，保留数值失败，不再连续叠加求解器修补。另一种选择是将不充分驻点终态作为明确预算版本继续比较，但这需要主动修改当前准入约定，不能本轮暗中执行。

## 5. 对研究主张的影响

这轮支持：旧定位改善并不全靠把真实两路径容量和间隔告诉算法；在本批中，未知阶数的常规构造也能获得接近无反射组的定位RMSE。因此不必先发明一个位置风险评分，才能处理这些样本。

它尚不支持：已经提出新的自适应理论、任意阶数可用、精确物理路径恢复、相比已发表多径盲定位方法具有优势。当前方法是一套可执行的常规参照，论文的额外贡献不能仅以胜过LOS-DPD确认。

具体的下一步仍是位置导向：收尾数值停止 → 固定规则测试0/1/2/4、链路阶数不一致及总反射功率大于LOS的条件 → 未见3路径小复核。只有这些结果能说明相同规则确实适应新条件，才判断是否存在值得开发的新机制。不再围绕旧RISK评分调参数，也不因为找到一个良好实现就宣布SP投稿条件齐备。
