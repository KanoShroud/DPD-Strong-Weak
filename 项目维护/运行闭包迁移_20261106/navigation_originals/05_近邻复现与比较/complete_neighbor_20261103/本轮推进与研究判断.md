# 完整近邻与固定清单控制：本轮推进结果

2026-11-03。已完成原生Xia流程的32条兼容性测试、真值标注的离线覆盖诊断，以及24次固定拓扑局部求解。没有启动640条、修改风险评分或启动共同外层EM/MM定位。下述结果是当前冻结观测上的核验，不是新独立性能验证。

## 1. 两项共识怎样落实

完整近邻优先保留自己的候选生成、筛选和输出方式。Xia这一轮不再使用我们的三站几何候选、未知阶数增径或DPD后端；调用已登记的公开信息重建流程。原文未公开的细节仍沿用此前登记解释，不能称为作者代码严格复现。

风险控制先执行可实现的固定组。代码核查发现现有算法只有追加路径，没有删除并重新选择全部路径的算子。因此没有擅自开发重选器，也没有用不同起点的旧结果冒充严格双臂。原先建议的完整因果对照没有全部完成；本轮得到的是固定拓扑局部响应证据。

## 2. 近邻：原流程接入了，但不能把这组失败当成强基线成绩

原文信息核验见[完整近邻信息与流程矩阵](完整近邻信息与流程矩阵.md)，具体逐条件输出见[完整近邻核验结果](完整近邻核验结果.md)。矩阵逐项区分本轮原文核读、沿用既有阅读和全文缺口。Xia保留独立流程；Flood是独立两步关联参照；Friedlander的单源/共同反射几何/固定路径结构、Du的已知转发器、阵列DOA类SBL及已知波形类方法没有被暗中改写后混入同信息排名。主责额外回核Friedlander原EM步骤、Du已知转发器段、JLSA窄带远场式及Garcia已知波形条件。

原始结果：[32条输出](native_20261103_164443_255193/summary.json)；[离线覆盖诊断](coverage_20261103_170840_884855/analysis.json)。

使用原1000个区域均匀粒子、原评分/阈值/聚类及两次重采样；观测、频率轴、源数和搜索区间按共同场景适配。四条短测通过数值和身份门禁后自动完成32条，总26.777秒。严格终态17/32完整，最近完整输出27/32；两种口径双源20m成功均0/32。缺失输出未补零，未用有利口径替换原输出。

连无多径组也失败，故继续做了不改变估计器的覆盖诊断：

- 1000粒子覆盖6km×6km区域，典型单元边长约190m。
- 保存的首轮候选到真实源最近距离为21.40–267.92m，中位82.83m。四条件复用同一组随机种子，只有8个不同随机池；不能把64个源—记录条目当64次独立试验。
- 四个R00记录中，穿过真位置的x/y局部评分剖面，中心半高交点间宽约18–28m，剖面最大值位于真值0或2m处；真位置评分是首轮随机池最大分数的2.88–49.43倍。

这些是真值标注的事后诊断，真值没有参与估计。轴向剖面不是二维吸引域面积，也不证明全域最优唯一。证据明确提示原搜索尺度与当前宽带窄峰不匹配，但没有证明这是全部失败的唯一原因。

**结论：原生流程与我们的前端已分离；充分适配的强近邻比较尚未完成。** 不能一方面拒绝给近邻合理搜索分辨率，另一方面用0/32宣布其方法不行。也不能把我们的几何初始化塞回去，继续称其原生流程。

## 3. 风险：局部公式正确，不等于实际噪声变化能够被它准确描述

详见[固定清单局部响应报告](../risk_support_control_20261103/run_20261103_165036_887173/固定清单局部响应报告.md)。

L2、L3每条件R00只提供观测得到的反射清单和局部起点，不计入受试成绩。2次donor拟合、14条R01–R07固定清单重拟合，以及8次预登记小扰动控制，共24次局部拟合，184.177秒。14条完整变化和8条小扰动均达到原投影梯度门槛，未放松预算或约束。

| 条件 | 0.01倍扰动的中心响应相对误差 | 完整噪声变化的平均四维位置响应预测误差 |
|---|---:|---:|
| L2 | 0.0307% | 0.1344m |
| L3 | 0.0665% | 0.1178m |

这里的响应误差是“预测位置变化”与“实际位置变化”之差的四维欧氏范数，不是定位RMSE，不是风险估计标准误。中心差分会抵消部分偶次非线性，不能代替单侧响应；单侧结果已保存。

冻结清单后仍有显著有限幅度响应误差。没有路径增删、时延排序变化或活跃约束，但时延本身仍可明显移动；不能排除连续局部极小盆变化。当前已采用实际非零残差Hessian，不能再把“补上Hessian”当成待实现解法。

**本轮支持：仅处理离散选路径的影响还不充分。** 本轮不支持：已分离风险排序误差的各项原因、已证明有限扰动风险估计有效、固定清单是更好的定位算法。

原自适应结果仅作描述性参照：同7条记录，固定组/原自适应RMSE为L2 0.1729/0.1644m、L3 0.2270/0.2107m。因为两者起点与选择过程不同，不能作方法胜负判断。所有差分共享同一个有噪声donor，未给出不恰当的独立样本置信区间。

## 4. 研究判断与下一边界

1. **风险路线保留，但不继续扩大当前评分。** 它尚未显示稳定净收益；新增选择惩罚并非已获验证的解法。下一理论方案必须同时说明有限幅度非线性、参照误差及计算成本，不能根据当前14条误差拟合经验系数。本轮不自行切换成bootstrap、交叉拟合或新删除器。
2. **完整近邻仍是优先项。** 原生Xia已经提供一个具体的适配问题；下一步若继续，应保持其评分、筛选和处理思想，依据公共带宽与站点几何确定搜索分辨率/计算预算，而不是按真值误差调粒子数，也不是套我们的初始化。
3. **共同前端EM/MM维持辅助角色。** 未把数学桥接包装成完整原文基线，也没有为填满对比表新增已知路径数或反射地图。
4. **尚不具备扩大独立实验或形成新贡献结论的条件。** 这不是否定完整多径DPD的已有精度价值；而是强近邻适配和风险增量仍需分别建立证据。

需要用户确认的下一项具体选择：是否允许为Xia保留原生处理流程、仅开展由公共带宽/几何推导的数值搜索尺度适配。具体规则须先推导和冻结，再短测估时；若原流程仍无法合理实现，再明确换近邻，不暗中追加我们的前端。未对该新尺度规则做参数搜索或正式运行。
